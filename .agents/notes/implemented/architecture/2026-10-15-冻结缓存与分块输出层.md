# Agent Note: 冻结缓存与分块输出层

Status: implemented

## 问题

稀疏 Top-J 缓存不会减少学生完整词表归一化或输出层工作区。完整 BPO 又需要两个 $N\times V$ 的冻结字段；若沿 prompt／padding 位置运输，会将缓存扩大到完整序列长度。只优化 logits 之后的 loss，无法控制 LM head、保存 softmax 和评分输出列表的峰值。该决定延伸[单仓与固定后端](2026-10-12-单仓交付与固定后端.md)的职责边界，保留其架构选择。

## 决策

`Memory` 将最终证据容量、评分输出 staging、投影分块和显式 profiling 作为严格 Job 配置。输入预检在预约 GPU 前检查容量，评分再次按实际有效数检查，超预算拒绝，不自动换估计器。预算限制 payload，主存拼接、运输副本、backbone、优化器与参数梯度仍需独立容量验证。

完整词表字段使用 response jagged offsets，只保留有效前驱；标量／Top-J 字段沿序列坐标运输。原生 DataProto 的行选择复用已有 nested-aware helper，防止常规高级索引破坏 jagged cache。teacher／anchor 评分按 tile 立即 detach 到 host。sampled MDPO 无诊断使用显式 action-only 合同，避免为不存在的需要保存中心或 head；其他模式保留实际依赖。

输出层与损失位于原生 FSDP forward 内，损失保留在模型返回的 logits 边，确保 backward hooks 有机会执行。在 forward 前拒绝 SP>1、关闭 remove-padding 或 fused head，临时包装标准线性 head，并在异常时恢复原方法；模型特有 logit 变换不受该合同覆盖，必须选择 eager。一般路径对 token tile 的投影及完整损失做非重入检查点；完整 BPO 无诊断用 raw-logit 中心化恒等式做 token／词表二维投影。自定义反向仅支持一阶梯度。公式与路径范围以[算法参考](../../../../docs/算法与实现.md)为准。

普通观测不初始化或同步 CUDA，不重置峰值。显式 profiling 在整个 worker train／infer 操作边界重置一次，嵌套投影不再重置；分别记录 host 与 owner CUDA 数据。teacher 参数 offload 可单独配置，默认继承已有训练设置。

## 考虑过的替代方案

- 只缩减 Top-J 或切换 sampled：会改变中心或动作积分，无法作为等价内存优化；保留为独立实验选择。
- 把 sampled action LP 换成 raw action logit、套用 k3 或裁剪 ratio：会改变 score 梯度；raw-logit 消归一化只用于完整条件 BPO。
- 仅在完整 logits 后做分块：仍保留输出层大张量；因此将投影本身纳入检查点，完整 BPO 再做二维投影。
- 先接常驻 teacher 服务、跨 batch memoization 或 NVMe：当前 outer 已冻结教师，尚无重复 prefix 命中率与运输收益证据；保留 reference 无 KV-cache 评分，优先减少当前窗口的确定性成本。
- 将完整证据直接压到 BF16：极小尾部和幂均值 reward 需要额外误差研究，当前保持概率 FP32／FP64。

## 后果

实现减少 prompt／padding 的完整缓存和训练词表中间量，完整证据本身仍随 $N\times V$ 增长。检查点与分块增加重算和调用成本。CPU 18 条件全部通过 FP32 参数梯度标准，但多数条件更慢；保存 storage 的 hook 计数不能用于 GPU 峰值结论。真实 Qwen2、温度、不同教师宽度和 jagged 运输检查已通过，固定补丁可在干净基线重放。

新增路径的 CUDA 峰值、吞吐和真实 FSDP canary 尚待验证。历史 GPU 实验不覆盖该源码，当前证据边界见[实验 7](../../../../docs/experiments/2026-10-15-幂均值镜像蒸馏实现与估计器对照.md)。后续扩大模型类型或并行策略，必须核验输出合同、FSDP 梯度边、混合精度、全局 token 归约和冻结窗口，不能只凭 loss 标量一致推广支持范围。

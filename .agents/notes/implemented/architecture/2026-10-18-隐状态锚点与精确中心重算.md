# Agent Note: 隐状态锚点与精确中心重算

Status: implemented

## 问题

完整中心与 sampled 动作更新已经实现，但冻结锚点 q 的 N×V 概率表限制了正常长度训练。调研中的 hidden 重建可以减少长期表示；只改教师缓存无法解决每次 inner 仍需 q 的依赖。原理和外部来源保留在[调研文档](../../../../docs/analysis/2026-10-18-DeepSeek-V4蒸馏显存方案与开源实现调研.md)。该记录部分延伸[冻结缓存与分块输出层](2026-10-15-冻结缓存与分块输出层.md)，不替代 full action integration 的既有实现。

## 决策

为完整中心、sampled BPO 增加显式可选的 hidden 锚点表示，保留完整概率表参照路径。缓存最终 norm 后 hidden 与归一化统计，冻结共享输出头并绑定窗口身份；教师阶段按 token／词表块计算幂均值中心，后续只保存动作证据和中心。每次 inner 用冻结锚点重算当前学生 KL，中心和完整 score 系数停止梯度，采样动作的归一化概率保留正确梯度。

第一版同步搬运，明确 head 共享的运行目录、版本、生命周期和异常行为，不在每条样本复制一个完整 head。预算同时覆盖 hidden、head 与实际标量字段，继续拒绝超限，不自动改目标或精度。保持 One-Shot 对照的 BF16 投影及 FP32 概率运算；不接入 SVD、量化、proposal、多教师服务或新编译依赖。

## 考虑过的替代方案

- 继续缓存完整 q：数值参照清楚，但正常 batch／长度需要约 259 GiB 全局概率表。
- 只保存 K_S：学生更新后数值失效，不能支持后续 inner。
- 使用当前学生输出头重建 q：输出头随更新改变，会破坏冻结窗口。
- 直接调用通用 KL loss 反向：幂均值教师中心一般不是普通 KL，BPO score 也不是直接对中心反向。
- 先做异步预取或采用 TileLang：当前没有运输瓶颈的测量证据，先验证表示与一阶更新再增加调度复杂度。

## 后果

`memory.anchor_storage=hidden` 已接入严格 Job、预检容量、typed cache、response jagged 传输、head 投影和 sampled score 反向；仅接受 BPO 完整中心＋sampled。默认 `log_probs` 保持完整概率参照，MDPO action-only 不增加 hidden。当前仍保留 Top-J／诊断字段，四卡数学上限的单份 payload 加一份保守 head 预算为无诊断 1.868 GiB、完整诊断 1.938 GiB，而非最小拟议表示的 1.760 GiB。

冻结 head 在 actor FSDP forward 中由 rank0 捕获，截取合法词表并按有效投影 dtype 拷贝到 host，用临时文件原子发布到运行目录 `cache/anchor-heads/<outer>.pt`。driver 的阻塞 anchor pass 完成是教师读取的先决条件，无 forward 内全局 barrier。读者校验完整窗口 context；每个进程缓存至多一个 host head，每次 forward 同步搬到设备。下一 outer 开始时清理旧文件；现存同版本文件拒绝覆盖，不提供等价恢复。这一选择免去 batch 每行复制 head，也增加共享磁盘 I/O 和重复 head 搬运；不能当作 DeepSeek 异步排课的完整实现。

CPU 证据覆盖完整概率参照的中心及学生 hidden／head／bias 梯度、温度和 signal 端点、非均匀正负上游权重、padding／空响应、Top-J 空支持与全支持、合法词表裁剪、真实 Qwen2 输出边、学生更新后的冻结窗口、jagged 重排／切分、预算和发布失败清理。BF16 分块梯度存在舍入差异，数值、配对缓存／RSS／时间结果及复现命令归属[实现报告](../../../../docs/analysis/2026-10-18-DeepSeek-V4蒸馏显存方案与开源实现调研.md)。

新增路径的四卡 FSDP、真实 GPU 峰值及正常长度端到端时间尚未验证，所有本机 GPU 均被其他任务使用。CPU 配对显示缓存减少，但输出层的局部前反向变慢；未计优化器或 backbone。保持显式启用；不能据 CPU canary 推广生产性能或任务成绩。后续检验须包括 FSDP 参数收集／反向、全局 token 归约和实际 head 搬运。共享运行目录、head／host 副本和概率归约顺序仍是约束；若实测 I/O 成为瓶颈，再用独立 stream／event 和有界预取替代同步搬运。

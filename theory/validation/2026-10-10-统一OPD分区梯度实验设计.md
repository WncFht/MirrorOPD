# 统一 OPD 分区梯度实验设计

## 问题与判定标准

本实验固定 prefix，检验本地书稿的分区 KL、HETS、ResOPD 和 SC-TA 是否能共享积分契约，并保留不同的随机梯度程序。词表完整枚举作为 oracle，避免把有限 Monte Carlo 偏差当成算法偏差。

第一项检验是 teacher Top-K 逐级细化时，coarse reverse KL 是否单调接近 full KL，以及梯度误差范数是否也单调。标量单调性要求所有正支持案例成立；梯度单调性通过反例判定，发现一个误差增加的案例就足以否定普遍单调声明。

第二项检验是 HETS、ResOPD、SC-TA 在 current 和 stale proposal 下采用正确 importance ratio 后是否恢复 full reverse-KL 梯度。float64 最大坐标误差必须小于 1e-10。方差定义为条件于固定 prefix 的协方差迹；不能把 prefix 之间的变化算入动作抽样方差。

第三项检验是完整数值 head 的 autograd 与 stopped tail 的错配，是否产生精确的 head-mass gradient 偏差。该偏差与公式的最大误差必须小于 1e-10；合法 head/tail 配对与此 legacy 配对分别记录。

## 配置与范围

使用 seed 20261010，词表 3、17、128、2048，每种 64 个独立案例。student、teacher、stale proposal 由独立标准正态 logits 生成，logit scale 循环取 0.5、1、3。候选 K 取 0、1、4、32、V-1、V 中合法且去重的值，支持为冻结 teacher Top-K，构成嵌套分区。current proposal 为 student 本身；stale proposal 是第三个独立分布。

实验程序为 `experiments/analysis/audit_partition_gradients.py`，完整枚举计算期望与二阶矩，用 O(V) score 恒等式避免构造 V×V covariance。另用 PyTorch 对小词表完整 KL、coarse KL 和 head 数值求导，独立核对解析梯度。

这项实验核对数学分区和梯度抽象，不证明任何上游 trainer 的分布式执行、端到端质量或 GPU 吞吐。真实上游函数、payload 和训练链路由对应代码审查与 canary 分别验证。

## 复现

```bash
uv run --with numpy --with torch python experiments/analysis/audit_partition_gradients.py --output results/analysis/2026-10-10-partition-gradient-audit.json
```

结果保存全部 case 行、梯度误差、协方差迹、最强单调性反例和配置。source commit 与程序 SHA-256 一起保存。

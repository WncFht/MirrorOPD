# 书稿重构数学核验

## 问题与判定标准

本实验检验统一归一化坐标是否精确表达四种 inner 目标，并用有限词表反例检验共同最优点、局部曲率、随机估计方差和更新场的区别。所有词表完整枚举；分布严格为正；计算使用 CPU float64。它不运行语言模型，也不比较 GSM8K 训练效果。

随机恒等式部分采用种子 20261010，词表大小 2、3、5、8，镜像系数 0.2、0.7、1、1.8、2.2，共 360 组。逐组检验商坐标逆映射、Part/BPO 差、Mean/BPO 差、MDPO 的 KL gap、四种锚点梯度与三种回归锚点 Hessian。每项最大绝对残差须小于 `1e-11`。

反例部分完整枚举三个 token 的随机结果，并直接对两维独立 logits 的更新场求 Jacobian。HETS 的标量方差和向量协方差迹分别与直接抽样比较；两个不同分布例子分别承担两个结论。近似 BPO 与 SC-TA 的 Jacobian 反对称项须与解析 curl 一致，误差小于 `1e-12`。

## 实现与结果

[实验程序](../../data/refactor-20261015/legacy-source.tar.gz#experiments/toy/book_reconstruction_audit.py) 保存源文件 SHA-256、基线 Git commit、运行命令、软件版本、输入配置和结果到 [metadata](../../results/book-reconstruction/metadata.json)。随机恒等式的最大绝对残差为 `4.44e-15`；全部通过预设容差。

三 token 的近似 BPO 例子采用锚点 `(0.5,0.3,0.2)`、教师 `(0.2,0.3,0.5)`、logits `(-0.3,0.6,0)`、镜像系数 `0.7`、单 token 头部。更新场的两个交叉偏导之差为 `-0.0095250968566`。这证明该近似生产式不能普遍解释成某个固定标量目标的梯度。它不否认精确 BPO 的二次目标。

标量 HETS 方差反例使用 `P=(0.18,0.819,0.001)`、`Q=(0.08,0.67,0.25)`，保留第二个 token。向量反例使用 `P=(0.075,0.245,0.68)`、`Q=(0.12,0.875,0.005)`，同样保留第二个 token。具体数值由 metadata 记录，比较均显示头部精确化不能保证相对直接抽样降低方差。

[绘图程序](../../data/refactor-20261015/legacy-source.tar.gz#experiments/plotting/book_reconstruction.py) 从 [loss landscape CSV](../../results/book-reconstruction/landscape.csv) 生成 [PDF 图](../../results/book-reconstruction/identities.pdf)。二元分布取锚点 `(0.5,0.5)`、冻结信号 `(2,-2)`、镜像系数 `1`。Part 与 BPO 在第一 logit 等于 `4` 时共同取零；Mean 的最优点偏离它。图与导数计算承担不同证据：曲率符号由自动微分与解析式共同核验。

## 复现

有限步对照固定锚点 `(0.5,0.3,0.2)`、教师 `(0.2,0.3,0.5)`、镜像系数 `0.8`，从锚点初始化。Part、Mean 与 `eta * BPO` 使用相同普通 logit 梯度下降，步长 `0.4`、预算 `1000` 步，初始梯度相同。Part 与 BPO 到 Gibbs 的 TV 分别降到 `3.05e-16`、`2.22e-16`；Mean 的最终梯度范数为 `2.06e-16`，到 Gibbs 的 TV 仍为 `0.0370627`。完整轨迹保存在 [finite-inner](../../results/book-reconstruction/finite-inner.csv)。

受限投影对照固定均匀三 token 锚点、教师 `(0.1,0.7,0.2)`、镜像系数 `1`，限制学生 logits 为 `(z,0,0)`。BPO 的解析最小点 `z=-1.3195286648` 处，Part 导数为 `0.03543884357`。共同 Gibbs 零误差目标无法由该学生族表达，因此不同回归几何产生不同最优投影。

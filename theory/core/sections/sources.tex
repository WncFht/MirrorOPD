\chapter*{来源对应与复现}
\addcontentsline{toc}{chapter}{来源对应与复现}
本稿将原有书稿、理论笔记、论文稿与散度材料按数学依赖重新组织。正文保持从镜像子问题到信号、加权教师和 $J$ 的主线；估计、优化及扰动的展开证明在附录维护。同一命题的多个版本合并为一份证明，旧稿目录已在内容整理后删除。历史模型实验、任务成绩及配置不纳入本稿。

\path{source-map.csv} 记录数学来源在固定 Git 版本中的路径、行号、命题标题、文件 SHA-256、Git blob 标识及新稿主题归属。其路径是历史定位信息，不是当前工作区依赖。基线版本为
\begin{center}
\texttt{8b1e1af7ab8eabece683c6800d7c84a81c93be29}。
\end{center}
可通过 \texttt{git show <版本>:<历史路径>} 只读查看对应源码。
\path{coverage-additions.csv} 将补充的二十组数学主题对应到当前稿的具体命题标签；主题数不等于独立定理数。

这些材料使用的头部集合、采样分布、中心尺度和学习率记号并不总是相同。本文统一记号后重新陈述条件并推导；来源表的主题关联不表示两版公式可以不经换算直接替换。幂散度梯度中的重加权分布 $p(T/p)^\kappa$ 用于积分测度解释，本轮目标教师 $m_{\kappa,\eta}$ 则由最优化问题确定。

附录 C 补充小步一致性、对角预条件、固定样本梯度与优化器状态分析；D 比较 Fisher 速度与矩准则；E 展开头尾估计、异分布控制及反传语义；F 处理包络中心及常数误差；G 给出锚点、访问测度、持续偏差与衰减误差的定量界。TOP-D 的比较保留在附录 H，围绕目标教师的参数退化和相关定理展开。

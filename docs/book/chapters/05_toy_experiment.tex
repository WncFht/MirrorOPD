\chapter{可枚举 Token 实验与实现边界}

\section{实验设置}

实验脚本位于 \texttt{experiments/toy\_token\_inner.py}。它只包含一个固定 history 和四个 token：
\[
 \mu=(0.62,0.23,0.10,0.05),
 \qquad
 T=(0.08,0.17,0.25,0.50).
\]
每个方法从同一个初始策略 $p_0=(0.70,0.15,0.10,0.05)$ 开始，使用 $400$ 步、学习率 $0.15$，完整枚举 vocabulary，不使用 rollout，不使用 sequence-level reward。这样可以单独检查 token-level inner 的数学对象。PMD-Part 和 PMD-Mean 用 exact weighted squared residual；BPO 使用完整词表下的中心化 residual 平方损失；MDPO 使用 exact categorical Fisher preconditioner。

\subsection{画图实验的输入数据与三层数据集}

本项目的图不能直接从一批混合的 rollout 日志中生成。每一张图都必须注明它使用的是哪一个策略、哪一个 prefix 测度以及哪一种词表访问方式。实验输入按由易到难分为三层。

第一层是可枚举的 categorical oracle。固定一个 prefix $s$，直接生成 anchor、teacher 和 student 的完整 logits，并通过 softmax 得到 $\pi_k(\cdot\mid s)$、$\pi_T(\cdot\mid s)$ 和 $\pi_{k,n}(\cdot\mid s)$。anchor 可以用随机 logits 加温度生成，teacher 可以通过独立随机 logits 或与 anchor 具有指定 KL 的混合分布生成。每个 prefix 保存完整的概率向量、两个 log-prob 向量以及 exact
\[
K_k^T(s)=\operatorname{KL}(\pi_k\Vert\pi_T),\qquad K_{k,n}^\theta(s)=\operatorname{KL}(\pi_k\Vert\pi_{k,n}),
\]
和
\[
\log Z_k(s)=\log\sum_{v\in\mathcal V}\exp\bigl((1-\eta)\log\pi_k(v\mid s)+\eta\log\pi_T(v\mid s)\bigr).
\]
这一层不需要文本数据，也不运行模型 rollout；它提供所有估计量的 ground truth，专门用于画 bias、variance、均方误差和梯度误差曲线。

第二层是真实模型产生的 prefix 数据，但仍然冻结 outer step。先选定一个不参与训练的 prompt 文件 $\mathcal X=\{x_i\}_{i=1}^{N_x}$，每个 prompt 只作为输入，不需要人工答案或 reward label。用当前 anchor $\pi_k$ 对每个 prompt 采样若干条 response，得到
\[
s_{i,t}=(x_i,y_{i,<t}),\qquad a_{i,t}=y_{i,t},\qquad a_{i,t}\sim\pi_k(\cdot\mid s_{i,t}).
\]
保存 prompt id、token ids、attention mask、response mask、prefix 长度、anchor 对采样 token 的 log-prob，以及 teacher 对同一 token 的 log-prob。KL 或 $\log Z_k$ 的估计不应把不同 prefix 混在一起：同一 prefix 的多个 next-token 样本才能用于估计条件期望；不同 prefix 只能在外层按照经验访问测度 $\widehat d_k$ 聚合。

第三层才是完整的 OPD outer loop。第 $k$ 轮只使用 $\pi_k$ 生成 rollout，缓存该轮的 prefix 集合和 anchor/teacher 的 token-level log-prob；随后固定这些数据运行 $N$ 个 inner steps，得到 $\pi_{k,N}$，再执行 hard sync 或 soft sync 得到 $\pi_{k+1}$。同步后必须重新 rollout，不能把上一轮的 prefix 和旧 anchor log-prob 继续当作新一轮数据。这样得到的序列
\[
\{(\widehat d_k,\pi_k,\pi_{k,n},\pi_T): k=0,\ldots,K_{\mathrm{outer}}-1,\ n=0,\ldots,N\}
\]
才是 outer 动力学图的输入。

为避免 top-$K$ 的整数与 KL 记号冲突，图中把保留的头部大小记为 $J$。对每个固定 prefix，同时记录 full-vocabulary oracle、sampled-token、top-$J$ 三条估计路径。建议先画以下三组图：

\begin{enumerate}
\item 在第一层 oracle 上，以 $J$ 或同 prefix 样本数 $m$ 为横轴，画 $K_k^T$、$K_{k,n}^\theta$ 和 $\log Z_k$ 的 bias、standard deviation、RMSE；
\item 在第二层真实 prefix 上，以 inner step $n$ 为横轴，画 exact-oracle 可用部分的 KL、sampled estimator 的方差、anchor--student 的 $\chi^2$ 或有效样本量；
\item 在第三层 outer loop 上，以 $k$ 为横轴，分别画 teacher KL、mirror-target KL、policy--anchor KL、token-level loss、rollout reward，以及 hard sync 与 soft sync 的差异。
\end{enumerate}

第一层的分布是唯一可以逐 prefix 得到无偏误差标签的地方，因此必须先完成。第二层用于回答估计量在真实语言模型的长尾词表上是否仍然稳定。第三层只在前两层通过后运行，否则一条性能曲线无法判断变化来自 OPD 本身、prefix 分布漂移、KL 估计偏差还是 inner 优化没有收敛。

PMD-Mean 到自身最优解的误差随优化下降，但到 Gibbs 解的距离保留了结构性差异。例如 $\eta=0.8$ 时，其有限步优化误差为 $4.11\times10^{-5}$，两个总体最优解的距离为 $0.1904$。继续优化只能消除前者。

BPO 的最优解仍为 Gibbs 分布，但本实验的固定步长与 400 步预算下，$\eta=0.8$ 时尚有 $4.53\times10^{-3}$ 的优化误差。MDPO 使用精确 categorical Fisher 自然梯度，在该四动作问题上达到浮点精度。该结果比较的是指定 optimizer 与预算下的误差，不构成一般模型上的收敛速度排序。

$\eta$ 同时影响 Gibbs target、Mean 的 Lambert-$W$ target 以及各损失的梯度尺度。Algorithm~5 中 BPO 的 $\eta^{-1}$ 已显式进入梯度权重，实验使用相同学习率时也保留这个尺度，不能把缩放后的方向当作实际梯度。

\section{正式 LLM 实验前必须通过的检查}

在 Pythia-14M/70M 上运行前，代码应先逐项通过以下 oracle tests：

\begin{enumerate}
\item 对随机 categorical logits，核对 Mean 的 Lambert-$W$ 归一化、KKT 条件与最优点梯度；核对 Mean/BPO 的损失及梯度差异恒等式；
\item 对随机 categorical logits，检查 PMD-Part 的 \texttt{logsumexp} target 与显式求和一致；
\item 对随机 $p,q$，用大量样本检查 K4 value 与 exact $\KL(p\Vert q)$ 的误差按 $O(B^{-1/2})$ 下降；
\item 用 autograd finite difference 检查 K4 gradient，而不是只检查 value；
\item 检查固定 anchor 采样的 importance correction 在 $p/q$ 接近一时无偏；
\item 人为增加 inner steps，确认 current-anchor $\chi^2$ 和估计方差同时上升；
\item hard sync 后重新 rollout，确认新一轮 residual 使用新的 anchor，而不是上一轮缓存的 log-prob。
\end{enumerate}

这些检查完成前不运行大型模型 sweep。当前仓库中的 toy 输出由
\texttt{toy\_token\_inner.py}（从本目录用 \texttt{uv run --with torch python} 运行）生成，结果保存在\path{experiments/toy_token_inner.csv}。独立的
\path{experiments/test_kl_estimators.py} 使用 200,000 个 token 样本检查 K4 的 value 与 autograd gradient；本次运行的绝对 value 误差为 $5.6\times10^{-5}$，gradient 的 $ell_2$ 误差为 $1.5\times10^{-3}$。

\path{experiments/test_mean_bpo.py} 进一步核对 Mean 与 BPO 的解析梯度、有限差分、最优点和有限样本尺度修正；它与 toy 实验分别检验推导正确性和有限步优化行为。

# 全书重构与内容迁移

## 维护入口与保留原则

旧书完整归档到 `docs/book-old/`，包括主稿、章节、样式、说明和 PDF。源文件审计以 Git 基线 `3a89c77` 为准，逐个读取原始对象并验证归档字节相同。新书在重新创建的 `docs/book/` 中维护，保留仓库固定主稿名称，Makefile 的当前书稿入口继续有效。

新书不以章节摘要替代旧推导。原有定义、四种 inner 方法、KL 估计目录、停止梯度、OPD 算法、Lambert-W 证明、同步动力学、有限 inner 分析和实验数值分别迁入独立源文件。重复定义统一到首次定义的位置；错误公式、越过假设的结论和符号冲突在相应小节修正。归档保留原始表达，便于逐项核对。

## 统一推导与章节依赖

第一章从固定 prefix 访问测度上的条件 KL 目标出发，以负熵的 Bregman 散度导出镜像子问题和 Gibbs 解。原目标、线性化目标、冻结 OPD 信号和当前 OPD 信号逐项定义。冻结 anchor 并不强迫唯一的回归范数，第二章明确把 anchor 加权平方范数作为内层投影几何选择。

第二章先建立归一化 log-density 与中心化商空间的双射，再推导 Part、Mean、BPO 和 MDPO。BPO 中的配分函数消失来自中心算子消去动作无关常数。Part/BPO 与 Mean/BPO 的差分别是不同的 KL 平方修正；它们不能因共同 target 而被当成同一个目标。Mean 的 Lambert-W 解、唯一性、误差转换与极限证明集中在这里。

第三章计算独立 logits 中的梯度、Hessian 和优化器递推。相同 Gibbs 零误差解、相同内部驻点、局部曲率、有限步轨迹和受限模型最优投影分别讨论。受限三 token 学生族给出 BPO 最小点处 Part 导数非零的解析例子。

第四章定义完整词表、Top-J、桶质量与 sampled action 查询的信息边界。KL 粗化链式分解、缺失尾部形状、可识别性和额外抽样条件先于估计量构造。第五章从一般概率测度下的残差校正定理推导标量、向量和双控制族，再分别处理行为测度、自动微分、停止梯度、固定样本复用和实际更新场。

第六章将冻结信号和各条件量代回 OPD，明确缓存、rollout、inner、同步和生产内核的对应关系。近似 BPO 的 stopped score 更新不能自动被解释为近似平方目标的梯度；三 token Jacobian 反对称项证明其一般不具有固定势函数。

第七章先证明精确 Gibbs 与正确 Mean target 的分布空间同步，再引入有限内层输出误差、随机噪声和 teacher 漂移。概率混合与参数 EMA 分开。第八章区分新数学核验、旧 toy、固定 prefix KL、历史模型记录和外部论文结果的证据范围。

## 逐项修正与证明条件

固定锚点、当前学生和教师统一为 `q,p,t`，一般 KL 查询统一为有序分布 `P,Q`。prefix 使用 `s`，logits 使用 `z`，冻结信号使用 `f`，一般 log-ratio 使用 `ell`。镜像系数、优化步长、行为测度、同步系数和控制系数分别固定，token 总量与 inner 次数分开。KL 方向由有序表达式指明。

Gibbs theorem 明确有限实值信号和正支持。Part 的唯一内部驻点不被扩展为任意优化器收敛。独立 logits 的 BPO 凸性不被扩展为神经网络参数凸性。归一化目标误差到 log-ratio 的转换写出最小 anchor 概率条件。Mean 的稳定区间、临界收敛阶和有限 inner 误差要求分别证明。

估计量修正包括 Mean 相关中心误差项的镜像系数、成对 BPO 原始期望的尺度、一般积分测度、零尾部质量的边界定义、Normalized 改变积分权重，以及满头部直接返回完整积分。头部精确化降低相对特定控制的方差，不能据此声称对直接抽样普遍占优；标量和向量分别保留反例。

随机同步矩递推写出过滤族、条件均值与条件协方差。KL 噪声底是小噪声展开，精确结论是居中 log-ratio 协方差递推。当前 OPD 与冻结 reward 的无限镜像系数极限分开。旧 Pythia 表尚无可逐项追溯的运行目录，明确标为历史记录，保留数值而不把它升级为本轮链路验证。

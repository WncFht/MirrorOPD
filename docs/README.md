# MirrorOPD 工程文档

工程文档描述当前可使用的接口、职责和验证方法。理论推导来源位于 [theory](../theory/README.md)，各稿件的正确性与合并关系由用户 review，不由工程文档或格式检查替代。

## 当前入口

| 任务                     | 入口                                                                                   | 内容                                               |

| 运行、准备或迁移实验     | [运行与复现](运行与复现.md)                                                            | 环境、配置解析、输入核验、训练、失败处理和完成审计 |
| 理解或修改执行链         | [架构](架构.md)                                                                        | 内核、运行层、后端、判分及证据的职责与边界         |

## 历史材料

`experiments/` 中的报告保留各自数据、代码、测度和评测协议，引用成绩时沿用其条件。`operations/` 中尚未完成核验的旧说明不能作为当前操作入口；其中的六算法名称、`training/` 启动脚本和建议接口需要按原文时点理解。

[旧架构与复现记录](operations/2026-10-15-旧架构与复现记录.md) 保留切换前的环境、方案和成本分析；[单仓与算法抽象历史提案](operations/2026-10-15-单仓与算法抽象历史提案.md) 保留未整体实施的设计及梯度核验。两篇记录都在开头说明与当前实现的关系。原有维护规范已并入开发维护指南，当前约束以根和分层 `AGENTS.md` 为准。

`earlier/` 仍有早期理论、笔记和实验工程，尚待归类。旧指标规范与其他历史报告尚未完成核验，保留各自原有正文；当前字段和行为以源码及当前接口为准。[延期清单](../scripts/maintenance-deferred-docs.json) 限定尚未核验的原样文件，不表示这些文件已通过事实检查。

## 复现证据

`make data` 按 [data-manifest.json](../data-manifest.json) 恢复已版本化的压缩研究数据与归档日志，校验原始路径和 SHA-256；它不下载模型或准备全部训练数据。当前运行的 `inputs.json`、冻结源码、事件及逐题结果共同决定一次实验是否完整，详见运行与复现。

历史数据重放、当前实现的链路验证和正式任务比较各有完成条件。更新量或评测协议不同的结果，需要在比较中说明，不能用统一图名掩盖差异。

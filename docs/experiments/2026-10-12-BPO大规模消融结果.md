# BPO 大规模消融结果

## 当前结论与范围

独立调参已经完成，五个确认 seed 与配对消融尚未完成。调参 pool 的结果支持降低默认学习率，并未支持当前标量候选优于充分调参的常数学习率。最终判断需要锁定参数后的独立确认数据；本报告保持这两个阶段的证据分开。

本实验固定 DeepSeek-R1-Distill-Qwen-1.5B 学生、JustRL-DeepSeek-1.5B 教师、初始 anchor、prefix、采样动作和镜像步长$\eta=0.3$。仅使用 GPU0–3。完整设置与成功判据见 [实验设计](2026-10-12-BPO标量调度实验设计.md)，初始小规模推导见 [标量调度分析](2026-10-12-BPO标量调度分析与验证.md)。

## 数据与测量

已准备六个 seed 各 128 条训练与 32 条独立验证轨迹，共 245760 个 prefix。主条件使用每个 pool 的前 64 条训练轨迹，即 16384 个 prefix；每次更新按长度比例抽取 8 条轨迹，累积固定 token 测度的无偏 minibatch 梯度。teacher 与 anchor 完整词表 log-prob 和 Top-16/64 缓存均冻结。response 上限 256 token，完整 prompt 不截断；这些设置用于固定监督优化验证，不是长预算数学准确率评测。

独立审计使用训练 pool 与验证 pool 中分别预选的 4096 个 prefix，评分保持 FP32 和完整词表。调参 seed1042 与确认 seed42、142、242、342、442 的 prompt 抽样范围互不重叠。每 20 次更新审计；全部调参分支执行 240 次更新。统计中的完整 BPO 值为目标原值，没有假定神经网络能实现零误差，也没有减去未经验证的 floor。

常数学习率$5\times10^{-7}$的曲线积分最低，$2.5\times10^{-7}$的终点误差略低。这两个分支共同进入确认，主常数基线由前者担任。默认$10^{-6}$的终点完整误差约为初始的 35.9%，两条更小常数为约 18%；继续增大学习率会恶化训练与验证误差。

候选标量中，target_rate=0.01 的相对下降率反馈在预设排序中最好，因此被锁定为主 scalar。它的几何平均完整误差仍比最佳常数高约 32.2%，终点约为初始的 21.3%。这一结果没有达到“更好”的要求，但只来自调参 pool；确认阶段继续按预先设定的五种子协议执行，不重新选择或修改其参数。

每步搜索与每 4 步搜索均出现很小或零的接受步长，额外 forward 没有保证独立完整误差下降。原始数据保留拒绝、非正 ray slope 和微小 probe，不把经验 proxy 平台直接解释成完整目标已收敛。后续监测集大小、采样方向、center、完整 batch 和精度消融用于判断这些现象的来源。

![独立调参的完整误差与验证 teacher KL 曲线](../../results/scalar-large/tune/figures/tune-seed-1042.png)

调参中八条常数分支逐步计算了用于日志的 proxy，因此该阶段的耗时含额外诊断，不能直接用作常数 lr 的最小部署成本。确认阶段只计算各算法必需的 proxy 并保留相同独立审计；CPU 测试验证移除非必需 forward 不会改变参数、moments 和 step。正式 matched-time 比较只使用确认阶段。

## 理想 Gibbs target 上的 center 偏差

对调参 pool 全部 40960 个 prefix，直接使用完整 q 和 teacher 分布构造精确 Gibbs target，检查近似 center 的更新场。Top-16 和 Top-64 分别覆盖平均 99.719% 和 99.958% 的 q 质量。即使完整 BPO residual 严格为零，Top-k 加尾部桶的近似 residual 仍存在偏差。

| center          | teacher KL 缺失量均值 | target 处 residual 偏差平方均值 | target 处 logit 更新场范数均值 |
| --------------- | --------------------: | ------------------------------: | -----------------------------: |
| Top-16 加尾部桶 |            0.00166818 |          $2.47761\times10^{-6}$ |         $9.76546\times10^{-5}$ |
| Top-64 加尾部桶 |           0.000187002 |          $6.18257\times10^{-8}$ |         $1.11286\times10^{-5}$ |

这里报告的是精确 Gibbs 分布处的 logit 更新场，不是共享网络参数的最终梯度或训练终值。它证实高 head 质量仍不能替代完整 center，但不能单独证明这项偏差解释了训练平台。center 与固定 pool 覆盖的贡献由后续配对消融判定。

## 独立确认与消融

锁定常数 lr 为 5e-7、2.5e-7，主 scalar 为 feedback、初始 lr=1e-6、target_rate=0.01，搜索每步/每 4 步作为预注册次要比较。锁定选择文件 SHA-256 为 `3efe1de50f91488812cf44f052bdfec83be16c06f2c8e564e1cf9bf6b06b0f47`。确认之前已经归档选择与全部调参数据。

五种子确认和 17 个配对消融仍待执行完成；该状态不构成任何最终成功或失败结论。成功要求五对主曲线改善方向一致、中位改善至少 10%，训练终点及验证 BPO/teacher KL 退化均不超过 5%。实际时间收益另行检验，优化收益与总体效率收益分别报告。

## 可复现数据

版本化原始调参审计、更新日志及 summary 保存在 `results/scalar-large/tune/raw/`，每个 gzip 同时记录原始内容和压缩内容的 SHA-256。排序 CSV、选择文件与图均由程序生成。原始生成 token 在 `data/scalar-large/` 的 gzip 中，恢复后从原 token 重建 q 与 teacher 全词表缓存，避免再次 rollout 改变固定监督。大 cache、参数和 optimizer checkpoint 留在 `runs/scalar-large/`。

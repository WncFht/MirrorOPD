# 数学 BPO 五十轮训练结果

## 完整运行结果

正式 BPO 完成 50 个 outer，每个 outer 执行 16 次冻结 rollout 上的全局更新，共 800 次更新。最终全量评测为 MATH-500 75.2%、AMC23 60%、AIME25 13.33%，相对本次初始化分别变化 +6、+12.5、-3.33 个百分点。训练教师对齐诊断持续下降，数学验证器分数提高；AIME25 的最终正确数从 5 道降至 4 道。

运行名为 `dapo-deepseek-bpo-o50-j16`，启动源码版本为 `ac54a612fb9ef0692b5b65d6c7dae620bdbb39a9`。实际退出码为 0，在线 W&B gp7pyuj6 为 finished，完整历史为 851 条。[完整核验](../../results/training/math-4gpu/dapo-deepseek-bpo-o50-j16-verification.json) 确认 50×16 次唯一更新、51 条 outer 记录、11 次完整 570 题评测和 GPU 0–3 的采样记录。源码解释以启动版本及启动时 SHA-256 记录为依据；运行期间仓库还接受了独立的内核与日志改动，当前工作区源码与本次启动快照分别保留。

## 共同条件与 BPO 语义

学生为 DeepSeek-R1-Distill-Qwen-1.5B，冻结教师为 JustRL-DeepSeek-1.5B。原始 DAPO 训练集为 17917 条，原始测试集为 MATH-500 500 题、AMC23 40 题和 AIME25 30 题。完整配置及预检见 [四卡数学蒸馏实验](2026-10-12-四卡数学蒸馏实验.md)。

本次全局 batch 和 mini-batch 都为 64，每题生成一条回答；actor、anchor 和 teacher 的 micro-batch 都为 1。AdamW 学习率固定为 1e-6，weight decay 为 0，梯度裁剪阈值为 2。eta 为 0.3，Tail-aware 缓存使用 Top-16。prompt、response、context 上限分别为 2048、7168、9216 token；训练 temperature=1、top-p=1、top-k=-1，测试使用 temperature=0 的 greedy 生成。

四卡使用 FSDP=4、TP=1、SP=1。FP32 参数存储配合 BF16 前向和 FP32 reduce/buffer，启用参数与优化器 offload、梯度 checkpointing。vLLM memory utilization 为 0.25，每个 replica 最多 32 条序列；验证 DataLoader 一次接收全量 570 题。数据和模型种子为 42，各生成 replica 种子为 0–3。正式运行从原始学生权重开始。

BPO 损失按冻结 rollout 的权重计算。其重要性比率与有效样本量（Effective Sample Size，ESS）仅作为当轮动作权重变化的诊断，未乘入 BPO 损失。每个 outer 起点重新生成 rollout，并冻结锚点与教师缓存；16 次 inner 更新后同步学生权重。数学验证器分数用于观察，任务奖励和策略梯度奖励开关均关闭。原算法、生产系数及 Tail-aware 近似的关系见 [算法核验](../../results/training/math-4gpu/2026-10-11-algorithm-audit.md)。

## 训练信号与数值稳定性

前后窗口各取十个 outer；KL center 和采样 reward 取对应 outer 的 inner_step=0。该索引对应更新前的冻结 rollout 快照，避免把同一个 outer 的十次缓存复用当作十次独立采样。

| 指标                         | 前十个 outer | 后十个 outer |
| ---------------------------- | -----------: | -----------: |
| Tail-aware teacher KL center |   0.04431876 |   0.00280744 |
| 冻结采样蒸馏 reward          |  -0.04730044 |  -0.00255505 |
| 数学验证器分数               |     0.478125 |    0.5640625 |
| 训练回答预算耗尽率           |     49.0625% |     39.6875% |

Tail-aware KL 将选出的 16 个 token 与尾部桶作为支持，是完整词表 KL 的下界。冻结采样 reward 为教师与锚点在采样 action 上的 log-prob 差。两者说明本次访问前缀上的教师对齐加强；生成前缀和长度同时变化，固定前缀的完整词表 KL 需要单独评测。标量 surrogate loss 作为梯度载体记录。

800 次更新的指标全部有限。每轮起点重新同步，student center 与采样 log-ratio RMS 均处于约 1e-7 的浮点误差范围；冻结缓存诊断在同一 outer 内保持一致。诊断 ESS 比例最低为 0.992093，重要性比率最大为 29.95。ESS 衡量本轮权重的集中程度，跨 outer 的累计模型变化仍由连续更新产生。

梯度范数范围为 0.0303–4.1660。唯一一次裁剪发生在 outer_call=11、inner_step=3，裁剪尺度为 0.480077，下一次梯度范数为 0.15468。实际裁剪比例为 1/800，即 0.125%。该事件未发展为连续异常，后续训练及全量评测正常完成。

## 全量测试与回答长度

| 测试集   |         初始化 |   outer50 最终 |           变化 | 初始 / 最终预算耗尽率 |
| -------- | -------------: | -------------: | -------------: | --------------------: |
| MATH-500 | 346/500，69.2% | 376/500，75.2% |    +6 个百分点 |           28.4% / 27% |
| AMC23    |   19/40，47.5% |     24/40，60% | +12.5 个百分点 |         52.5% / 52.5% |
| AIME25   |   5/30，16.67% |   4/30，13.33% | -3.33 个百分点 |          80% / 83.33% |

MATH-500 最终增加 30 道正确题，AMC23 增加 5 道，AIME25 减少 1 道。最终平均回答长度分别为 4039.002、5490.275、6860.533 token。AIME25 有 25/30 条回答耗尽 7168 token 预算，最终成绩受该统一长度设置约束。

MATH-500 在 outer30 达到 77.8%，最终为 75.2%；AMC23 在 outer20 达到 65%，outer45 回落至 47.5%，最终恢复到 60%；AIME25 在 outer20 达到 26.67%，最终回落到 13.33%。报告采用预先安排的 outer50 结果，所有评测点保留在完整曲线及数值文件中。

该实验只有一个训练种子，未保存逐题配对输出；AMC23 与 AIME25 分别只有 40 和 30 题。原始 DAPO 与三项测试的精确题目重叠分别为 2、5、0 条。聚合正确数支持本次运行的观测结果，AMC23 的重叠限制其泛化解释。

GPU 采样峰值为 36765 MiB，即 35.90 GiB，采样仅包含物理 0–3。actor 框架的 peak reserved 为 33.51 GiB，统计范围与 GPU 总占用不同。训练正常退出且未出现 OOM。训练 outer 耗时均值为 220.72 秒，该字段不包括初始化与周期评测。

# KL 统一残差框架验证

## 重构依据

原第三章依次讨论单 token 数值、稀疏数值、稀疏梯度、双控制、重要性校正和正向 KL。同一个条件均值与方差分解多次出现，实际采样分布又在较后位置引入，使读者难以区分目标变化、控制变化和反传变化。

重构后的共同对象为 $I_\nu(f)=\sum_v\nu(v)f_v$。反向 KL 的数值与梯度分别取 $(\nu,f)=(p,r)$、$(p,rs)$，正向 KL 分别取 $(q,-r)$、$(q,-s)$。实际采样始终为 $\rho$，可精确积分的近似函数为 $a$，统一构造为

$$
\widehat I=I_\nu(a)+\frac{\nu(A)}{\rho(A)}\{f_A-a_A\}.
$$

主稿入口保持不变：[第三章](../book/chapters/03_kl_estimators_and_variance.tex)。各文件按推导依赖划分：目标与微分规则、残差总定理、分区粗化、数值实例、梯度实例、双控制、自动微分、采样设计、OPD 用途、实现与论文证据。

## 从同一框架得到的分析

1. 精确积分误差、错误重要性权重和缺失支持都作用于同一个残差，给出统一偏差及 MSE 公式。
2. 线性控制的最优值由 Gram 矩阵投影给出。双控制在 on-policy 下具有块正交结构；旧 rollout 下交叉项通常不再为零，需要联合优化。
3. 固定残差时，最优采样概率与 $\nu(v)\|f_v-a_v\|$ 成正比。它是完整尾部已知时的 oracle，不能作为稀疏 teacher 数据下现成可执行的采样器。
4. 同一个粗粒度 KL 梯度具有桶内常向量与逐 token score 两种同积分近似；头部 singleton、尾部单桶时分别导出 ResOPD 与 SC-TA。
5. 尾部条件采样消去尾部事件质量的随机性，也使尾部常控制逐样本抵消。它与从完整 student 抽样后仅在尾部触发修正的 HETS 具有不同方差。
6. 固定样本的微分由 $\phi'$ 决定；补回采样测度微分后由 $\phi+\phi'$ 决定。K1--K4 的数值和反传差异因此可统一审计。
7. vOPD 是积分为零的 score 控制。独立 KL baseline 的标量偏差影响其离最优中心的距离，标量方差则按 score 二阶矩传入梯度方差；旧 rollout 对应 $p^2/\rho$ 权重。

## 验证设计

采用有限词表精确枚举与有限差分验证，不使用 Monte Carlo 近似代替恒等式。新测试为 [test_kl_unified_framework.py](../../data/refactor-20261015/legacy-source.tar.gz#tests/test_kl_unified_framework.py)，并纳入 `make test`。原有 [test_kl_theory_identities.py](../../data/refactor-20261015/legacy-source.tar.gz#tests/test_kl_theory_identities.py) 保留，用于回归旧估计量与 baseline 的公式。

新测试的随机部分使用标准库 `random.Random(128)`，32 组六元词表，三维向量被积函数，分别以 student 和参考分布作为积分权重。分布由区间内随机 logits 的 softmax 生成，按 Python 双精度计算。均值、完整协方差矩阵、MSE 与理论公式逐项对照，绝对和相对误差阈值为 $10^{-11}$；双向粗粒度 KL 的有限差分步长为 $10^{-5}$，梯度误差阈值为 $10^{-9}$。

其余确定性测试覆盖联合偏差、缺失支持、最优采样、头尾协方差、非正交 Gram 控制、条件尾部采样、自动微分变换、off-policy 控制耦合及最优 baseline。

## 反例与结果

取 $p=(0.4,0.2,0.4)$、$q=(0.7,0.1,0.2)$，头部为第一个 token。两种尾部分布均为 $(1/3,2/3)$，数值桶残差与 SC-TA 的随机残差逐点为零；ResOPD 则保留尾部 score 波动，协方差迹为

$$
\frac4{15}(\log2)^2>0.
$$

该精确枚举反例说明，同积分的梯度近似可以具有不同方差，也说明 KL 数值精确不推出所有梯度估计量零方差。

新增 10 项测试与原有 4 项测试均通过。验证程序只使用标准库，可直接复现：

```bash
python3 tests/test_kl_unified_framework.py
python3 tests/test_kl_theory_identities.py
make book
```

这些检查验证第三章的积分、分区与控制公式，不涉及生产训练语义改动，也不构成 LLM 训练效果比较。

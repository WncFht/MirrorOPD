# BPO 标量调度实验设计

## 问题与判定标准

固定 anchor、teacher、prefix 和 action pool，检验全局标量调度能否减少达到相同剩余误差阈值所需的 backward 次数。所有 AdamW 分支固定 betas、epsilon、weight decay 和梯度机制；调度只改变标量学习率。loss 变换作为独立对照，观察其改变 Adam 状态后的方向差异。

主要阈值为初始精确 BPO 平方误差的 10%、1% 和 0.1%，另记录 teacher reverse KL。每个阈值记录首次达到及连续五步保持的步数。比较常数学习率网格中的最佳分支，避免把超过保守基线写成超过常数学习率。记录 forward、backward、失败试探次数、运行时间、累计学习率、相对吸收率、末尾误差、残差平方与精确目标的差异。以相同累计学习率重绘轨迹，检查收益是否主要来自数值时间增加。

## 分层验证

1. 精确二次模型：可控谱宽、旋转坐标、多种种子，比较固定 lr、loss 倒数规则、相对下降率反馈、Polyak 型规则与沿既有更新方向的一维二次试探。梯度下降用于核验推导，AdamW 用于检验迁移；理想曲率只用于标注 oracle 对照。
2. 分类模型：冻结 q 采样动作，分别使用完整词表二次目标、完整 center 的 sampled score、生产 Top-k 加尾部桶 center。共享线性及非线性参数用于检验自由 logits 结论的边界。固定 action pool 的经验 residual 平方与总体目标分别记录。
3. 已训练语言模型：使用本地 DeepSeek-R1-Distill-Qwen-1.5B / JustRL-DeepSeek-1.5B，共享 tokenizer，冻结 q rollout 和 teacher logits。GPU 0--3 各运行独立分支；其他卡保持原有任务。小型固定 prefix benchmark 只判断优化速度，不替代数学任务正确率评测。

## 候选规则与证伪条件

相对下降率反馈以观测到的 log loss 下降率决定下步 lr，并限制增长与上限。若没有方向曲率保护，高曲率方向重新进入时出现上冲即证伪其无条件稳定性。

一维二次试探固定一次 AdamW 产生的方向，只通过额外 forward 测量不同全局步长的 residual 平方。精确二次模型中三个函数值可以恢复沿方向的二次多项式；共享参数与 Top-k 模型中只作为局部拟合，并按实测函数值接受或回退。若减少 backward 的收益不足以抵消 forward 耗时，结论应为 backward 效率改善而非总时间改善。若经验 residual 下降而总体 BPO 或 teacher KL 上升，应判定为指标失配。

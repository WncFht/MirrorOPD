# OneShot 学习率上限的历史数据验证

## 结论

历史数据支持增大学习率带来实际更新次数加速，也提供了高学习率破坏持续对齐的反例。已验证可用的最高扫描点是 1e-5；1e-4 出现明显反弹。两点之间没有训练记录，不能把该间隔写成已经定位的精确最大 lr。

以相同距离区间的每步下降量拟合二次 lr 响应后，加入全部可用分支得到的零下降率候选约为 1.5e-5–2.7e-5，最佳下降率候选约为 7.4e-6–1.35e-5。它们提供下一次扫描的位置，尚未在这些候选 lr 上运行验证。只用低 lr 的有效时间谱模型推算稳定上限，得到约 1.25e-4；这个数没有排除实际失败的 1e-4，因此不能作为 AdamW 的可靠边界。

本次是历史回顾性分析。拟合分支与检验分支分开记录，全部阶段、平滑窗口和时间口径保留；它没有声称对未知训练结果做过预注册预测。

## 原始数据与 setting

分析使用 MD-OPD 中缓存的六组 M4 W&B history，每组 279 行，step 连续覆盖 1–279。原始 history 与 metadata 的 SHA-256 保留在[来源签名](../../data/oneshot-lr-stability/source-signatures.json)，绘图和分析所需数值逐列抽取并压缩版本化，恢复关系登记在 data-manifest.json。完整已核验设置见[配置快照](../../data/oneshot-lr-stability/settings.json)。

| 项目       | 历史 M4 设置                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------- |
| 学生、教师 | DeepSeek-R1-Distill-Qwen-1.5B、JustRL-DeepSeek-1.5B                                                 |
| Prompt     | DAPO 全量 train.parquet，多 prompt；属于 One-Shot-OPD 项目的 M4，而非单 prompt 的 frozen 消融       |
| Rollout    | 每次重新采样，batch64、n=1；temperature=1、top-p=1、top-k=-1；响应上限 7168                         |
| 梯度覆盖   | ppo_mini_batch_size=64、ppo_epochs=1；完整 rollout batch 内做一次 actor 更新                        |
| 精度       | FSDP dtype=bfloat16，model_dtype=fp32；teacher 为 BF16                                              |
| 优化器     | AdamW；betas=(0.9,0.999)、weight_decay=0.01、grad_clip=1；常数 lr、无比例 warmup                    |
| 日志指标   | d=-opd/token_reward_mean，为 signed sampled-token reverse-KL Monte Carlo proxy；并非独立完整词表 KL |
| 配方       | policy_loss_mode=vanilla、teacher kl_estimator=k1；各 lr 的核心训练配置一致，另有日志诊断开关差异   |
| 原运行算力 | metadata 记录 8 GPU；本次只做 CPU 数据分析，没有启动该训练配方                                      |

在线 OPD 的 prefix 测度随 student 变化。这里的有效时间重合是观测性质，固定测度二次谱模型只作为动力学参考，不能当成这些在线训练的精确方程。

原 trainer 的 reward/teacher 距离在 actor 更新前计算，随后更新 actor，最后统一写出该 step 的日志。主分析因此使用更新前时钟 $u=(t-1)\alpha/10^{-6}$，首次 rollout 距离对应完成 0 次更新。历史绘图使用 $u=t\alpha/10^{-6}$，本次同时拟合该口径作为敏感性对照；两个拟合得到的速率和假想边界非常接近。高 lr 下一个 step 对应很大的 u，不能把这个偏移隐藏掉。

## 高学习率的实际行为

下表使用最后 30 步的中位数，不把单个 Monte Carlo 读数当作平台。最低阶段用全程 20 步滑动中位数的最小值衡量。

| run      | lr   |     末段 d | 末段 grad norm | 末段 d / 最低阶段 d |
| -------- | ---- | ---------: | -------------: | ------------------: |
| ybi7q89v | 5e-7 |  0.0136924 |       0.134847 |               1.011 |
| mdxt04lm | 1e-6 | 0.00564590 |      0.0746231 |               1.030 |
| yj2w13fq | 2e-6 | 0.00268895 |      0.0523482 |               1.000 |
| ml6mz58f | 5e-6 | 0.00129591 |      0.0417484 |               1.022 |
| l0a6rsc1 | 1e-5 | 0.00125336 |      0.0480800 |               1.020 |
| vmk256kl | 1e-4 |  0.0494056 |       0.221532 |               1.361 |

1e-4 的 raw d 在 step50 达到最小值 0.0330576，随后总体反弹。它的全部 279 个 d 与 grad norm 读数仍有限，末段 d 也低于初始化，因此应称为持续对齐失败或大步长导致的退化，不能据此声称已经发生数学意义的无界发散。

其余分支均没有同等程度的末段反弹。5e-6 与 1e-5 的末段距离接近，说明继续扩大 lr 的后期收益已经减小。这一现象本身不能唯一识别随机梯度噪声底、精度、几何或在线测度变化的贡献。

## 低 lr 的有效时间拟合与独立分支检验

只用 5e-7 与 1e-6 的 u≥30 数据，拟合两个正指数与非负常数项：

$$
\widehat D(u)=f+a_1\exp[-k_1(u-30)]+a_2\exp[-k_2(u-30)].
$$

最小化 log 距离残差，使用固定 16 组初值，选择训练误差最小的解。2e-6、5e-6、1e-5 与 1e-4 全部不参与这个模型的拟合。拟合使用的最大 u 为 278，模型以外的更长时间外推单独标识。

得到

$$
a_1=0.0642153,\quad a_2=0.0183478,\quad k_1=0.0319158,\quad k_2=0.00509165.
$$

常数项贴到所设下限 1e-8，说明训练区间未识别出可靠的渐近 floor，不能把 1e-8 报成真实最终误差。训练 log RMSE 为 0.06855。

在共同 u∈[30,139] 上，未参与拟合的 2e-6 的 log RMSE 为 0.06940，对应约 7% 的乘性误差量级。5e-6、1e-5 与 1e-4 分别为 0.21849、0.39974 与 1.83962。增大学习率时，单纯用累计时间解释路径的精度明显下降。

该模型预测未平滑 d=0.02 的有效时间约为 u=99.04，d=0.01 为 u=166.23。在 lr=1e-6 与 2e-6 下，用相同宽度 u=30 的滑动中位数平滑后，持续达到 d=0.02 的起点为 step113 与 step58，更新前 u 分别为 112 与 114。平滑引入相同量级的时间延迟，两条低 lr 曲线仍支持近似累计时间关系。

## 从拟合谱硬算稳定上限的反例

若将观测指数速率错误地当作确定性二次 GD 的全部曲率，使用

$$
k_i=2\alpha_0\lambda_i,\qquad \alpha_0=10^{-6},
$$

便得到假想全局稳定边界

$$
\alpha_{\mathrm{GD}}=\frac{2}{\lambda_{\max}}=\frac{4\alpha_0}{\max_i k_i}\approx1.2533\times10^{-4}.
$$

该边界把 1e-4 放在稳定区间内，却不能解释它的对齐反弹。因此从少数可见衰减速率推算实际 AdamW 可用上限的办法，没有通过失败分支检验。

这并未推翻确定性二次 GD 的稳定条件。观测 d 不是固定二次 excess loss，AdamW 的方向和矩状态随轨迹变化，在线 prefix 测度也在变化。弱谱权重或未被激发的快方向还会使可见速率无法识别最大曲率。只知道一个方向上的衰减曲线，不能恢复所有方向的稳定边界。

把 u=99.04 压成一步，候选 lr 为 9.904e-5，正好接近已知失败的 1e-4。它验证了此前反例的实际意义：累计小步的时间需求不能直接作为一次更新的可用步长。更换目标距离还会得到另一候选值，因此该换算没有定义一个与误差阈值无关的最大 lr。

## 从阶段平均下降量估计可用 lr 候选

沿固定方向 d 的局部二次式为

$$
Q(\theta-\alpha d)=Q(\theta)-\alpha A+\frac12\alpha^2B,
\qquad A=\nabla Q^\top d,\quad B=d^\top H_Qd.
$$

正 A、B 下，下降量随 lr 为开口向下的二次式，最佳步长为 A/B，零下降边界为 2A/B。这提供了一个经验拟合依据：在相同距离区间，计算跨越该区间的平均每步绝对下降量，再拟合 lr 响应。

$$
\overline v(\alpha)=\frac{D_{\mathrm{high}}-D_{\mathrm{low}}}{n_{\mathrm{low}}-n_{\mathrm{high}}},
\qquad x=\alpha/10^{-6},\qquad\overline v(x)\approx ax-bx^2.
$$

同一距离区间不能保证相同参数、Adam 状态与 prefix 测度。这里的 a、b 是阶段平均的经验系数，没有把它们声称为某个固定 Hessian 的精确测量。原始 grad norm 在区间内也随 lr 改变，不能以归一化距离替代 optimizer 状态控制。

使用共同 u=30 的滑动窗口并要求至少三个点，首先只用最高到 5e-6 的分支拟合，将 1e-5 与 1e-4 留出。随后将已验证可用的 1e-5 加入重新拟合，两个阶段的实际跨越时间如下。

| lr   | d 从 0.05 到 0.02 的更新数 | d 从 0.02 到 0.01 的更新数 |
| ---- | -------------------------: | -------------------------: |
| 5e-7 |                         83 |     未在预算内达到后一端点 |
| 1e-6 |                         42 |                         73 |
| 2e-6 |                         21 |                         35 |
| 5e-6 |                         12 |                         15 |
| 1e-5 |                         11 |                         11 |
| 1e-4 |              从未达到 0.02 |              从未达到 0.01 |

前两个低 lr 的更新数近似按倍数缩短，5e-6 到 1e-5 的边际收益变小。这个统计按相同有效时间宽度平滑，避免使用固定 20 步窗口给大 lr 人为增加更大的 u 延迟。

| 距离区间  | 只用最高 5e-6 的零点候选 | 加入 1e-5 后的零点候选 | 加入 1e-5 后的最佳速率 lr |
| --------- | -----------------------: | ---------------------: | ------------------------: |
| 0.05→0.02 |                 1.280e-5 |               1.559e-5 |                  7.795e-6 |
| 0.02→0.01 |                 5.938e-5 |               2.201e-5 |                  1.101e-5 |

留出 1e-5 时，两条模型都预测正下降，它的实测跨区间下降也为正，但速率预测误差约为 34% 与 33%。两个模型均预测 1e-4 超过零点；该分支全程没有进入两个距离区间的下端点，与持续对齐失败相容。由于 1e-4 没有到达相同距离阶段，它不能提供同状态的局部速度验证。

![阶段平均每步下降量与 lr 的二次响应](../../results/oneshot-lr-stability/stage-velocity-lr-candidates.png)

平滑窗口改为 u=60 或 u=90 后，加入 1e-5 的零点候选在两个区间合计为 1.475e-5–2.697e-5，最佳速率候选为 7.376e-6–1.349e-5。只使用最高 5e-6 的分支时，较晚阶段的零点从 5.94e-5 变为 9.09e-5，另一个窗口甚至没有正二次惩罚项。低 lr 的近线性响应不足以稳定识别高 lr 边界；接近收益饱和的实测点对推断具有决定作用。

## 实验判断与下一组扫描位置

现有数据已经验证该历史配方可使用 1e-5，也验证 1e-4 无法持续达到低距离。阶段二次拟合将下一组有价值的扫描点放在 1.5e-5、2e-5、3e-5，必要时再用 5e-5 缩小失败区间。所有这些 lr 都是当前数据之外的候选，不计为已完成结果。

更严格的局部边界检验应从同一 checkpoint 分叉，保留参数、Adam 状态与相同后续 rollout/监督，直接比较三点方向曲线；在线 OPD 还应同时保留固定 prefix 的完整词表审计。这样可以区分步长曲率、Adam 历史与测度变化。使用原历史随机 rollout 的不同分支拟合，只能给阶段性的经验候选。

这些数值不迁移为当前 BPO 的 lr 上限。当前 BPO 使用 FP32、冻结 anchor、eta=0.3、短轨迹及不同 center，梯度场与 Adam 轨迹均不同。已经排队的全量 64 条 rollout BPO 矩阵用于直接检验该设置的可用范围。

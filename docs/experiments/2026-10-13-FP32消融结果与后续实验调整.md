# FP32消融结果与后续实验调整

## 判断与执行范围

单精度浮点数（FP32）训练加快了固定监督的拟合，但FP32条件仍在数百次更新中持续改善。现有证据支持“学生计算精度影响学习速度”，不支持把整个长期吸收过程归因于BF16舍入。内层学生锚点KL很小与教师监督是否已经吸收，仍需要按指标定义、优化目标和锚点生命周期分别判断。

后续FP32学习率扫描停止执行。当前半倍学习率FP32条件保留330条已提交更新记录，以及第100、200步的完整模型和优化器checkpoint；它没有完成原定600步，作为部分实验归档，不计为完成条件。该条件不再继续训练或增加数学评测。种子142和242的全部条件按用户要求取消。

执行范围保留seed42的12个完整条件：两个已完成零学习率控制、三个已完成BF16固定监督学习率条件、三个在线OPD学习率条件，以及MDPO和BPO分别采用固定初始锚点和每16步重设锚点的四个条件。原45条件的预注册设计保持原样，用户调整后的范围保存为独立的execution-selection.json。分析输出同时列出原始条件数、当前条件数、取消条件和保留的部分实验。

## FP32与BF16训练的配对结果

对照使用相同seed42、相同64条固定响应、相同BF16教师标签、相同AdamW配置和恒定学习率$5\times10^{-7}$。每次optimizer更新覆盖全部64条响应，包含395862个有效动作。学生前向分别采用FP32和16位浮点格式BF16。下表报告各自训练精度下的当前策略；FP32列来自FP32训练条件。

定义固定动作平均绝对log-prob差为

$$
d_t=\frac{1}{N}\sum_{i=1}^{N}\left|\log T(a_i\mid s_i)-\log p_{\theta_t}(a_i\mid s_i)\right|.
$$

$N=395862$，$s_i$是固定响应的预测前缀，$a_i$是相应动作，$T$是缓存的教师分布。update_before$t$的记录对应已经完成$t$次更新、尚未开始第$t+1$次更新的模型。

| 已完成更新数 | BF16动作绝对差 | FP32动作绝对差 | FP32相对BF16减少 |
| ------------ | -------------: | -------------: | ---------------: |
| 0            |       0.239874 |       0.238875 |             0.4% |
| 20           |       0.231665 |       0.171588 |            25.9% |
| 100          |       0.113953 |      0.0570620 |            49.9% |
| 200          |      0.0489151 |      0.0305508 |            37.5% |
| 300          |      0.0343489 |      0.0210049 |            38.8% |

100步时FP32的动作距离约为BF16的一半。该差异持续到300步，因此精度对拟合轨迹有实际影响；单个距离比不能直接解释成相同倍数的训练加速。

FP32从100步到200步的距离比为0.5354，从100步到300步的距离比为0.3681。后两个阶段继续降低固定监督误差。FP32没有把整个吸收过程压缩到首次更新，BF16舍入不能独自解释数百步持续学习。

完整词表距离采用相同4096个固定预测前缀，定义为

$$
D_t=\frac{1}{M}\sum_{j=1}^{M}\sum_a p_{\theta_t}(a\mid s_j)\log\frac{p_{\theta_t}(a\mid s_j)}{T(a\mid s_j)},\qquad M=4096.
$$

每个前缀的距离是当前学生到教师的Kullback–Leibler散度（KL）。固定前缀集合在全部响应位置中均匀无放回抽取，跨条件复用。完整词表KL独立于动作绝对差计算。

| 已完成更新数 | BF16完整词表KL | FP32完整词表KL |
| ------------ | -------------: | -------------: |
| 0            |       0.106206 |       0.105226 |
| 100          |      0.0267815 |     0.00971684 |
| 200          |     0.00772170 |     0.00472888 |
| 300          |     0.00505154 |     0.00345255 |

完整词表距离也支持FP32拟合更快的判断。当前停止的FP32条件没有完整数学基准评测，其结果只用于固定训练分布的概率拟合分析，不给出FP32数学能力变化结论。

## 首步台阶与长期吸收的区分

半倍学习率的首次更新后，BF16的生产学生锚点KL均值为0.000406099，FP32为0.0000491368。计算精度明显改变了首步数值。两种精度的零学习率控制均接近零，因此这组首步变化对应实际更新，不是零更新时的缓存对齐误差。

学生锚点距离比较锚点$q$与当前学生$p$。记生产支持集合并尾部桶后的分布为$q_H$与$p_H$，则该指标为

$$
C_t=\mathrm{KL}(q_H\Vert p_{H,t}).
$$

初始化时$p_0=q$，所以$C_0=0$；初始化学生到教师的完整词表KL仍约为0.106。学生锚点距离等于零不构成教师距离等于零的充分条件。

固定锚点OPD对照在300步时的学生锚点KL为BF16的0.0885683和FP32的0.0892986。这时两种学生到教师的KL已经降至上表的0.00505154和0.00345255。学生接近教师的同时远离初始锚点，两类距离描述不同的变化。

MDPO/BPO使用的镜像目标和锚点重置方式还需要直接消融。FP32对照已经验证精度影响，但更多FP32学习率和种子不能替代这组目标与生命周期实验。因此剩余计算优先投入在线采样、固定锚点和16步锚点重置。

## 训练精度与权重转换读出的区分

此前BF16训练权重改用FP32前向后，教师距离曾升高。该结果是同一组BF16训练权重的精度转换读出，不能代表从初始化开始执行FP32训练的效果。当前FP32训练在300步时得到的完整词表KL为0.00345255，属于另一条优化轨迹。

精度转换读出与FP32训练对照分别保留。现有对照不把精度影响拆成权重舍入、梯度数值误差与计算内核差异的独立因果贡献；后续不再为这一分解增加实验。

## 剩余实验与判分

| 剩余条件                        | 更新预算      | 检验内容                                               |
| ------------------------------- | ------------- | ------------------------------------------------------ |
| 在线OPD，半倍、标准、两倍学习率 | 600、300、150 | 每步刷新64条响应时，学习率乘更新数能否解释主要时间尺度 |
| MDPO、BPO，固定初始锚点         | 各300         | 固定镜像目标误差、当前教师距离与学生锚点距离之间的关系 |
| MDPO、BPO，每16步重设锚点       | 各800         | 锚点重置后的内层KL外观，以及累计教师对齐变化           |

12个完整条件共4308次optimizer更新，已有5个条件完成1058次更新，剩余7个条件共3250次更新。另有330条已停止FP32实验的更新记录。当前范围共44组正式checkpoint或初始化评测，已有14组完成，剩余30组；每组包含相同570题。

FP32跨学习率20%距离一致性的预测取消验证。多种子重复也取消，原“至少两个种子通过”的判据不再作为当前执行范围的完成要求。单个种子的数值阈值保持原样，seed42标准BF16固定监督已通过100步以后持续吸收的两个分量。后续结论限定在seed42及其固定响应集合和已执行的采样协议，不宣称跨随机种子的稳定性。

执行入口仍为training/oneshot_suite.py，统计入口为experiments/analysis/oneshot_effective_time.py。范围调整与部分FP32数据分别保存在data/oneshot-effective-time-20261012/execution-selection.json和同目录的frozen-opd-fp32-lr5em7-s42/。原始未完成记录保留为部分实验，取消条件不会作为待执行条件重新排入队列。

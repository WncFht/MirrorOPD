# 固定监督蒸馏动力学与 BPO 优化实验报告

更新日期：2026-10-15。本报告合并 OneShot 与 BPO 标量调度两份报告，是固定监督、学习率、精度、镜像蒸馏及相关 target/中心估计研究的唯一实验正文。外层迭代 outer 建立 rollout 与冻结锚点，内层迭代 inner 复用当轮缓存；一步指一次 optimizer 更新。前向传播、反向传播、监督 token 和墙钟时间分别计数。

研究从一个可重复的现象出发：同一批状态和教师标签可以被学生持续吸收数百步。目标是区分误差谱、AdamW 状态、数值精度和生产代理的作用，判断完整 BPO 的 logit 二次结构能否帮助选择全局学习率，同时减少达到相同误差阈值的实际成本。后续幂均值研究改变教师 target，单独讨论，不能作为原 LR 调度假设的证据。

已有证据支持固定监督下的长期吸收和有限范围内的有效时间缩放。当前 search/feedback 没有在生产代理上超过充分调参的常数 LR；同状态分叉只验证了局部增大学习率的有限收益。尚未验证一个从头执行、长期优于强常数的调度，也未识别真实渐近误差底。

## 研究问题、判据与证据范围

同策略蒸馏（On-Policy Distillation，OPD）在学生访问的前缀上对齐教师；镜像下降策略优化（Mirror Descent Policy Optimization，MDPO）拟合每轮镜像目标；BPO 沿用代码名称，指中心化对数比的方差目标。KL 是 Kullback–Leibler 散度，FP32 是单精度浮点数，BF16 是 bfloat16。下文统一使用冻结锚点 $q$、教师 $T$、当前学生 $p_\theta$，$\eta$ 为该轮固定镜像强度。

成功判据分为三个层次。现象验证要求固定数据上 update100 后仍改善；优化验证要求独立完整目标的下降或阈值成本优于充分扫描的常数；生产收益还要求总耗时、验证误差与稳定性支持。代理 residual 变小、optimizer step 变少、单步下降变大均不能单独通过后两层判据。原标量确认以几何平均误差改善至少 10% 为主判据，失败、反弹和未达阈值保留。

## 统一目标、动力学与比较口径

### 三种误差各自回答的问题

固定动作上的平均绝对 log-prob 差衡量记录动作的拟合；完整词表 reverse KL 衡量固定前缀上的当前学生到教师距离；BPO 衡量本轮 Gibbs target 的拟合：

$$
\begin{aligned}
d(\theta)&=\frac1N\sum_i|\log p_\theta(a_i\mid c_i)-\log T(a_i\mid c_i)|,\\
D_T(\theta)&=\mathbb E_{c\sim\mu}\sum_a p_\theta(a\mid c)\log\frac{p_\theta(a\mid c)}{T(a\mid c)},\\
U&=\log(p_\theta/q),\quad r=\log(T/q),\quad C_qf=f-\mathbb E_qf,\\
R&=C_q(U-\eta r),\qquad Q(\theta)=\frac{\mathbb E_{\mu,q}R^2}{2\eta}.
\end{aligned}
$$

固定动作来自 $q_0$，其有符号均值的期望是 $\mathbb E_{q_0}\log(p/T)$；当前 reverse KL 的动作测度则是 $p$。二者通常不同。anchor–student KL、teacher center 和当前 teacher KL 也分别记录。$\eta=0.3$ 时完整 BPO 自由分布最优解为 $p_G\propto q^{0.7}T^{0.3}$；$Q=0$ 通常仍有 $D_T>0$，该值也不是所有学生的 teacher KL 下界。

### 固定监督仍然减慢的谱机制

对单前缀 softmax，$F_p=\operatorname{Diag}(p)-pp^\top$，精确 reverse-KL logit 梯度为 $F_p(z-z_T)$。一般位置的 Hessian 还包含 $F_p$ 的导数，只有目标附近固定 Jacobian 时才近似 $H=\mathbb E[J_c^\top F_{T,c}J_c]$。例如均匀二分类教师、学生概率为 $1-\varepsilon$，KL 接近 $\log2$，logit 梯度却只有 $O(\varepsilon\log(1/\varepsilon))$；饱和几何可造成大误差、小梯度。

固定二次参考模型记 $E=Q-Q_* = e^\top He/2$，在固定特征基下梯度流有 $E_i(\tau)=E_i(0)e^{-2\lambda_i\tau}$。令 $w_i=E_i/E$，逐步求导得到

$$
\frac{dE}{d\tau}=-2\sum_i\lambda_iE_i,\quad
\frac{dw_i}{d\tau}=-2w_i(\lambda_i-\mathbb E_w\lambda),\quad
-\frac{d\log E}{d\tau}=2\mathbb E_w\lambda,\quad
\frac d{d\tau}\left[-\frac{d\log E}{d\tau}\right]=-4\operatorname{Var}_w(\lambda)\le0.
$$

快方向先消失，剩余权重转向慢方向，故相对吸收率也能下降。单指数只产生绝对下降量变小。有限维正谱最终有正的最慢活跃速率；持续趋零还需接近零的谱、移动几何或误差底。未知 $Q_*$ 时，原始 $Q/Q_0$ 的吸收率不能直接当作 excess loss 的吸收率。

### BPO 的精确二次结构及参数边界

令 $z_G=(1-\eta)z_q+\eta z_T$。展开 log-softmax 后，所有公共归一化常数被 $C_q$ 消去；再用 $\mathbb E_q[(x-\mathbb E_qx)^2]=x^\top F_qx$ 得到

$$
R=C_q(z_\theta-z_G),\qquad Q=\frac1{2\eta}\mathbb E_\mu[(z_\theta-z_G)^\top F_q(z_\theta-z_G)],\qquad
\nabla_zQ=F_q(z-z_G)/\eta,\quad \nabla_z^2Q=F_q/\eta.
$$

自由 logits 中该式全局成立，不要求师生接近。共享非线性参数的 Hessian 还包含 logit 的二阶导数：

$$
\nabla_\theta^2Q=\frac1\eta\mathbb E_\mu\left[J_c^\top F_{q,c}J_c+\sum_v(F_{q,c}(z_\theta-z_G))_v\nabla_\theta^2z_{\theta,c,v}\right].
$$

固定 Jacobian 才得到参数二次问题。冻结 $q$ 固定 logit 权重，稀有 $q$ 动作仍可对应小曲率；改变 teacher 会改变误差谱权重和上述 residual 二阶项。完整推导与定理维护在[动力学章节](../book/sections/dyn_scalar_schedule.tex)。

### 有效时间、AdamW 与 loss 变换

小步 GD 的各方向满足 $e_{n+1,i}=(1-\alpha_n\lambda_i)e_{n,i}$。当 $0\le\alpha_n\lambda_i<1$ 时，对乘积取对数并展开：

$$
\log\frac{|e_{N,i}|}{|e_{0,i}|}=-\lambda_i\sum_{n<N}\alpha_n-\frac{\lambda_i^2}{2}\sum_{n<N}\alpha_n^2-\cdots,\qquad
u_N=\sum_{n<N}\frac{\alpha_n}{10^{-6}}.
$$

常数 LR 才可写成 $u=(\alpha/10^{-6})N$；时变 LR 必须累加。连续标量梯度流只是时间重参数化；离散步序可改变谱滤波，但当前算法没有证明 Chebyshev 类谱加速。已知固定谱、普通 GD 下的理想 Chebyshev 步序依赖可信谱端点，不能直接迁移到当前 AdamW。

AdamW 对裁剪后梯度 $\widetilde g_n$ 更新

$$
\begin{aligned}
m_{n+1}&=\beta_1m_n+(1-\beta_1)\widetilde g_n,\quad v_{n+1}=\beta_2v_n+(1-\beta_2)\widetilde g_n^{\odot2},\\
\widehat m_{n+1}&=m_{n+1}/(1-\beta_1^{n+1}),\quad \widehat v_{n+1}=v_{n+1}/(1-\beta_2^{n+1}),\\
\theta_{n+1}&=\theta_n-\alpha_n\left[\widehat m_{n+1}/(\sqrt{\widehat v_{n+1}}+\epsilon)+\lambda_{\rm wd}\theta_n\right].
\end{aligned}
$$

LR 在 moments 之后乘当前方向。两矩的原始更新记忆尺度为 $-1/\log\beta$，当前 betas 对应约 9.49 和 999.50 步；换 LR 后它们在 $u$ 轴上的记忆也变化。曲线近似重合需要相同参数位置的更新方向接近，不能从 Adam 定义直接保证。BF16 又把 FP32 master 映射为离散前向权重，跨过舍入阈值的顺序影响后续梯度。Adam 的定义与实现依据分别见原论文[^adam]和 PyTorch[^torch-adamw]。

对整个真实 loss 作 $\phi(Q)$，梯度变为 $s_ng_n$、$s_n=\phi'(Q_n)$。从零状态开始、同一梯度历史、恒定 $s>0$、裁剪未引入不同跨步倍率时，一阶矩乘 $s$、二阶矩乘 $s^2$，因此

$$
\frac{\widehat m'}{\sqrt{\widehat v'}+\epsilon}=\frac{\widehat m}{\sqrt{\widehat v}+\epsilon/s}.
$$

$\epsilon$ 可忽略时常数 loss 缩放几乎抵消；乘 LR 则确实放大参数位移。时变 $s_n$ 被两矩以不同历史权重吸收，各坐标通常不再共享一个相对于原方向的倍率。log/sqrt loss 是改变 moments 的独立机制，不能当作严格保持 AdamW 方向的 LR 调度。生产 `coefficient * log_prob` 只承载梯度；先由独立 residual 求缩放，再 stop-gradient 乘 surrogate，才具有指定梯度缩放含义。

### 完整目标与生产代理的差别

生产 residual 为 $\widehat R=U+\widehat K_S-\eta(r+\widehat K_T)$。student center 每次 forward 重算后停止梯度，teacher center 在 outer 内冻结；训练梯度为 $\widehat g=\operatorname{mean}[\operatorname{sg}(\widehat R/\eta)\nabla\log p]$。即使使用完整 center，有限固定动作的经验平方梯度还含 $\operatorname{mean}[R\nabla K_S]/\eta$；总体 $q$ 期望中因 $\mathbb E_qR=0$ 才消失。

Top-k 加尾部桶满足完整 KL 链式分解。记 $\delta_S=\widehat K_S-K_S$、$\delta_T=\widehat K_T-K_T$、$b=\delta_S-\eta\delta_T$，完整动作期望下的近似 logit 场为

$$
K_S=\widehat K_S+q_{\rm tail}\operatorname{KL}(q(\cdot\mid\mathrm{tail})\Vert p(\cdot\mid\mathrm{tail})),\qquad
\widehat g_z=F_q(z-z_G)/\eta+b(q-p)/\eta.
$$

尾部式由 $q_a=q_Rq(a\mid R)$、$p_a=p_Rp(a\mid R)$ 代入逐项 KL 后分别求和得到。$b$ 随尾部形状变化，更新场一般不能当作同一个固定平方目标的梯度。任意有限正标量保持该场的零点，不能补回缺失方向。固定 full-batch、dropout=0 时没有新的 minibatch 重采样噪声；经验偏差、表示限制和数值误差仍可存在。

## 标量规则的可实现条件与最小算法

### 沿当前方向的最佳步长与比例限制

固定 AdamW moments 更新后的方向 $d$，精确二次模型有 $E(a)=E-aA+a^2B/2$，其中 $A=g^\top d$、$B=d^\top Hd$。$A\le0$时该方向没有正下降步长；$A>0$、$B>0$时，导数为−A+aB，故

$$
\alpha_*=A/B,\qquad \alpha_{\rm zero}=2A/B,\qquad \rho_{\max}=\frac{E-E(\alpha_*)}{E}=\frac{A^2}{2BE}.
$$

由 $(e^\top Hd)^2\le(e^\top He)(d^\top Hd)=2EB$ 得$0\le\rho_{\max}\le1$。$B=0$时半正定 H 给$Hd=0$、$A=0$，该方向不改变目标。给定比例$0<\rho\le\rho_{\max}$，解二次方程 $aA-a^2B/2=\rho E$，选择较小根并有理化得

$$
\alpha_\rho=\frac{2\rho E}{A+\sqrt{A^2-2B\rho E}}.
$$

该式需要真实 excess loss 及方向能力，未知 $Q_*$ 时不宜强行跟踪固定比例。GD 中 $d=g$，有 $\rho_{\max}=(\mathbb E_w\lambda)^2/\mathbb E_w\lambda^2$。取谱 m/M、loss 权重 M/(m+M) 与 m/(m+M)，得到 4mM/(m+M)²，宽谱时按 1/κ变小；单一全局标量无法突破给定方向的限制。

零下降边界表示一步前后 loss 相同，参数仍可移动；一维αλ=2 时误差翻号而平方不变。它既不是梯度为零，也不是整段 AdamW 训练的最大可用 LR。实验 16 直接表明局部最优还不足以控制 40 步效果。

### 已比较规则及其成本

| 规则            | 明确更新语义                                                              | 当前证据                                        |
| --------------- | ------------------------------------------------------------------------- | ----------------------------------------------- |
| 常数 LR         | 未变换 surrogate，原生 AdamW                                              | 生产主基线；按各配方独立扫描                    |
| search every1/4 | 一次 backward 与 moments 后冻结方向，0/h/2h 拟合，实际 forward 接受与回退 | 精确小 LM 省部分 backward；生产确认失败         |
| feedback        | 由上一步 proxy log 收缩调下一 LR；增幅≤1.25，非下降减半                   | 确认四 pool 更差，末期贴 LR 下限                |
| 方向 Polyak     | $\alpha\approx.05Q/(g^\top d)$、有上限                                    | 早期参考；$Q_*$未知时不继承最优值已知证明[^sps] |
| inverse-LR      | 按误差倒数提 LR、有上限                                                   | 早期参考，无曲率保护                            |
| log/sqrt loss   | 由独立残差平方求缩放，停止缩放梯度后乘 surrogate                          | 改变 Adam 矩历史；不等价于调 LR                 |

feedback 的近似依据是 $r_n=\log(E_{n-1}/E_n)\simeq\alpha_{n-1}A/E$，下一步取 $\alpha_n=\min[\alpha_{max},\alpha_{n-1}\operatorname{clip}(r_*/r_n,1/2,5/4)]$，非下降直接减半。它跟踪上一方向，不识别当前 B，且 proxy 未必是真 E。$\beta_2$ 历史、非下降方向和误差底都可让反馈失效。

### 最小受限搜索的伪代码

下列是已实现并测试的搜索语义，不是胜出推荐。输入动作只在 outer 起点由 q 采样，inner 固定复用；不构造成对 token 或新预条件器。监测优先用独立完整 Q；使用经验 residual 时，只能保证该经验量的候选接受。

```pseudocode
\begin{algorithm}
\caption{沿原生 AdamW 方向的全局标量搜索\\{\small\textit{Semantics: 根据正文重构}}}
\begin{algorithmic}
\INPUT fixed cache $D\sim(\mu,q)$; teacher $T$; fixed $\eta$; probe $h$; cap $\alpha_{\max}$; budget $N$
\OUTPUT student parameters $\theta$
\IF{$D$ has no valid supervised token}
    \RETURN $\theta$
\ENDIF
\FOR{$n=1$ \TO $N$}
    \STATE recompute student center; keep teacher center frozen
    \STATE $R_j\gets U_j+K_{S,j}-\eta(r_j+K_{T,j})$
    \STATE $g\gets\operatorname{backward}(\operatorname{mean}_j[\operatorname{stopgrad}(R_j/\eta)\log p_\theta(a_j\mid c_j)])$
    \STATE apply unchanged global gradient clipping
    \STATE update AdamW moments and bias-correction counter exactly once
    \STATE $d\gets\widehat m/(\sqrt{\widehat v}+\epsilon)+\lambda_{\rm wd}\theta$; $\theta_0\gets\theta$
    \STATE freeze $d$ and optimizer state for all trials
    \STATE define $Q(a)$ by installing $\theta_0-ad$ and forwarding the same cache
    \STATE $h\gets\min(h,\alpha_{\max}/2)$; evaluate $Q_0,Q_1,Q_2\gets Q(0),Q(h),Q(2h)$
    \STATE $B\gets(Q_2-2Q_1+Q_0)/h^2$; $A\gets(Q_0-Q_1)/h+hB/2$
    \STATE $S\gets\{(0,Q_0),(h,Q_1),(2h,Q_2)\}$; discard nonfinite nonzero trials
    \IF{$A>0$, $B>0$ and both are finite}
        \STATE $a_f\gets\min(A/B,2h,\alpha_{\max})$; add finite $(a_f,Q(a_f))$ to $S$
    \ENDIF
    \IF{every nonzero trial has value at least $Q_0$}
        \FOR{$j=1$ \TO $8$}
            \STATE $a_b\gets h/2^j$; stop this loop below the numerical minimum
            \STATE evaluate $Q(a_b)$; add finite trial to $S$
            \IF{$Q(a_b)<Q_0$}
                \STATE stop the backtracking loop
            \ENDIF
        \ENDFOR
    \ENDIF
    \STATE $(a,Q_a)\gets\operatorname{argmin}_{(b,Q_b)\in S}Q_b$; prefer $a=0$ on a tie
    \STATE $\theta\gets\theta_0-ad$; retain this step's moments even if $a=0$
    \STATE use accepted $a$ as next probe; otherwise halve $h$ subject to its numerical minimum
\ENDFOR
\RETURN $\theta$
\end{algorithmic}
\end{algorithm}
```

每个候选从θ0 恢复后安装，试探不额外 backward、不推进 moments；零步也保留一次 moment 更新。初始 Q0 必须有限，否则该步终止并记失败。大 pool 的独立 proxy forward 按真实成本记账；分布式接入须统一所有 rank 的统计与接受决定，不能各自选 LR。当前验证覆盖独立模型 benchmark 和标量内核，尚无生产多轮调度胜出结果。

### 平台时间不能压成一步

一维稳定 GD、0<αλ<1 时，$E_n=E_0(1-\alpha\lambda)^{2n}$，达到δ的次数为 $\lceil\log(E_0/\delta)/[-2\log(1-\alpha\lambda)]\rceil$；小步近似 $u_\delta=\log(E_0/\delta)/(2\times10^{-6}\lambda)$。多谱由求和不等式隐式决定，通常没有仅依赖 LR 的统一闭式。

随机参考 $e_{n+1}=(1-\alpha\lambda)e_n-\alpha\xi_n$，独立零均值噪声方差σ²，平方取期望并解稳态得到

$$
\mathbb Ee_{n+1}^2=(1-\alpha\lambda)^2\mathbb Ee_n^2+\alpha^2\sigma^2,\qquad E_\infty=\frac{\alpha\sigma^2}{2(2-\alpha\lambda)}.
$$

若目标是超过平台的δ，即 E_n≤E∞+δ，且 E0>E∞，需 $\lceil\log[(E_0-E_\infty)/\delta]/[-2\log|1-\alpha\lambda|]\rceil$ 次，结果至少取 0；αλ=1 单独检查首步。该式是随机 GD 参考，不是 AdamW 精确方程；full-batch 平台不能直接套这个噪声底。

即使一维 E=e²/2、λ=1，梯度流达到 1% 需时间 log100/2=2.302585，一步用同样α却使误差比 (1−2.302585)²≈1.697。loss 与真 gradient norm 只能识别 $\|g\|^2/(2E)=\mathbb E_w\lambda$，无法识别最大曲率；不能从低 LR 衰减时间或生产 norm 推出全局安全上限。

### teacher、student 与数据迁移的保留设计

迁移依据是固定 q/prefix/J 参考$H=\mathbb E[J^\top F_qJ]/\eta$，换 teacher 保持该近似 H 但改变误差谱投影；换 student 则改变 q/Fq/J，换数据改变μ和长度。真实网络还有 residual 二阶项，teacher 分数不能单独决定最佳 LR。One-Shot OPD[^oneshot]提供固定 64 条参照，Dual Nature[^dual]提醒同源应落实到具体共同初始化，不能仅凭同属 Qwen 认定。

| 条件  | Student / teacher / 数据                     | 控制目的                                  |
| ----- | -------------------------------------------- | ----------------------------------------- |
| A0    | 当前 student / JustRL / DAPO                 | 新协议基线                                |
| T1/T2 | 当前 student / DeepScaleR 或 Nemotron / DAPO | 同初始化来源、同 domain 的 teacher 变化   |
| S1/S2 | DeepScaleR 或 DeepCoder / JustRL / DAPO      | 同规模后训练 student 变化，不称纯规模实验 |
| D1/D2 | 当前师生 / DeepMath 或 Code                  | 数据来源与 domain                         |
| C1/C2 | 当前 student / DeepCoder / Code 或 DAPO      | 与 A0/D2 构成 teacher×domain 四格         |

模型来源见 DeepScaleR[^deepscaler]、DeepCoder[^deepcoder]、Nemotron[^nemotron]；使用前锁完整 revision、检查 token ID/special tokens/输出词表与同一prefix编码。候选pool为16个无放回prompt×4响应、全部64求梯度；16个不重叠prompt验证，cap2048，长7168另列。换teacher复用q动作，换student各自q采样，共同S0面板只诊断。FP32、eta.3、Top16、clip2、wd0统一，按实际token成本计。

原候选预算九条件×五 LR×160 步=7200 更新，阶段五 LR×20 步上限 2700；当前未授权自动开展。DeepMath 只用 question[^deepmath]；Code 选训练 split、排除评测与文本重叠[^codedata]，不把附带 teacher 解答放入 prefix。原三 seed 提议不执行。可用 $T_\gamma\propto q^{1-\gamma}T^\gamma$、γ0.5/1 作幅度诊断，初始完整 Q 按γ²缩放；Adam 归一化和 Top-k 场仍须实测。

仅四卡，1.5B 先离线 teacher 评分再释放；完整词表缓存分块读磁盘。64×2048×151936 的一份 FP32 矩阵约 79.7GB，两份约 159.3GB，不能全部驻 GPU。3/4B 需 canary 后分片，7B 仅后续离线 teacher 可行性候选，14/32B 与 40K–96K 长度不进该设计。Math 和 Code 能力基线与优化指标分开；少量 Code 题只筛查，不据此挑选确认 LR。

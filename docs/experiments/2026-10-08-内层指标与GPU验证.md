# 内层指标与 GPU 验证

本次验证检查两个命题：逐 inner 日志是否忠实于有效 response token 上的统计；新布局中的三种 Mirror 更新是否在真实模型、冻结 outer 缓存、hard sync 和 vLLM rollout 链路上正常执行。失败判据是统计聚合与直接计算不一致、非有限梯度、outer 内 teacher center 改变，或同步后 student center 未归零。本次没有将四次 inner 更新判定为收敛。

## 实现与测量时点

生产损失位于 `src/mirroropd/training/losses.py`，布局适配位于 `src/mirroropd/integrations/verl/fsdp.py`。新增 `src/mirroropd/training/metrics.py` 负责充分统计量、聚合结果和 JSONL 记录。上游补丁只连接模型输出、损失 callback 和训练 worker，不复制指标公式。

每条 JSONL 对应一次实际 optimizer 更新。策略统计在该次更新之前测量；`grad_norm` 是这次更新的 clipping 前梯度范数。`outer_call` 和 `inner_step` 从零开始，前者是 worker 的更新调用计数，后者按 epoch、mini-batch 的实际执行顺序编号。它们不是恢复后的全局训练 step。恢复训练时应使用独立日志，并结合 checkpoint 和 trainer global step 建立映射。

同一 outer 使用固定 rollout 与 anchor 缓存。每次 inner forward 都重新计算当前 student 的概率及中心。完成更新后再 hard sync 和 rollout。记录在 worker 汇总阶段写出，但保存的是各次更新原有测量，不是最后一个 student 重新评分全部历史 step。

## 指标定义

固定 prefix $s_i$ 和 sampled action $a_i$，记 anchor 为 $q=\pi_k$、student 为 $p=\pi_\theta$、teacher 为 $T$，$S_i=\operatorname{TopK}(q(\cdot\mid s_i),32)$。本次两个 center 都是把尾部合并为一个类别的 Tail-aware KL：

$$
\widehat K(q\Vert p)
=\sum_{v\in S_i}q(v)\log\frac{q(v)}{p(v)}
+q(S_i^c)\log\frac{q(S_i^c)}{p(S_i^c)}.
$$

teacher center 用 $T$ 替代 $p$。它在 outer 内冻结。两个 center 的日志名称分别为 `student_center` 与 `teacher_center`；它们不是当前 student 与 teacher 的 reverse KL，也不是完整词表 KL。

sampled reward、位移和比率分别为

$$
r_i=\log T(a_i\mid s_i)-\log q(a_i\mid s_i),\qquad
u_i=\log p(a_i\mid s_i)-\log q(a_i\mid s_i),\qquad
w_i=e^{u_i}.
$$

三种更新记录的 `score_coefficient` 为

$$
\begin{aligned}
c_i^{\rm Mean}&=u_i-\eta(r_i+\widehat K_i^T),\\
c_i^{\rm BPO}&=(u_i+\widehat K_i^\theta)/\eta-r_i-\widehat K_i^T,\\
c_i^{\rm MDPO}&=w_i(u_i/\eta-r_i).
\end{aligned}
$$

实际损失使用 $\operatorname{stopgrad}(c_i)\log p(a_i\mid s_i)$。指标全部 detach，统计不会增加训练目标的梯度项。`score_coefficient/rms` 是 sampled PG 系数的均方根，不是三个算法共有的目标误差。尤其 MDPO 充分优化后，该系数也不要求逐 token 为零。

`student_entropy` 是当前 student 的完整词表熵，单位 nats。head mass 是在同一个 anchor 支持集上的质量；tail mass 是其补集质量。没有为了这些诊断新增完整 teacher logits 缓存。当前保存 anchor/student 的质量，尚不保存 teacher 的 head mass 和完整熵。

## 有效 token 加权与 ESS

对于一个 optimizer batch 的 $M$ 个有效 response token，先聚合

$$
N=M,\qquad A=\sum_{i=1}^{M}x_i,\qquad B=\sum_{i=1}^{M}x_i^2,
$$

再计算

$$
\bar x=A/N,\qquad
\sigma_x^2=B/N-(A/N)^2,\qquad
\operatorname{RMS}(x)=\sqrt{B/N}.
$$

标准差采用总体定义，`ddof=0`。它刻画本批 token 值的离散程度，不是 KL 估计器重复采样方差，不是独立 prefix 的标准误。轨迹中相邻 prefix 相关，置信区间需要另外按 prompt 或 trajectory 重采样。

micro-batch 先合并 sum、sum-square、count、min、max，随后执行 DP 聚合。固定上游的 `Metric.aggregate_dp` 对 SUM 字段进行 rank 平均，因此 $A/N$ 与 $B/N$ 的公共因子抵消；有效 token 数及 ESS 需乘回 DP rank 数。测试包含不同 micro-batch 的有效 token 长度和 masked NaN，避免错误地平均 micro-batch 均值或标准差。

比率的经验有效样本量定义为

$$
\operatorname{ESS}_{\rm IS}=\frac{(\sum_iw_i)^2}{\sum_iw_i^2},\qquad
\operatorname{ESS}_{\rm fraction}
=\frac{(\sum_iw_i)^2}{M\sum_iw_i^2}.
$$

这个 ESS 诊断 anchor action 到当前 student 的 importance weighting。它不是 reward ESS，也不能证明 teacher reward 没有重尾。Mean/BPO 也记录真实 $w_i$ 以测量位移，但更新系数没有 MDPO 的乘法权重。

## GPU 配置与来源

archbox 使用 RTX 4070 SUPER 12 GB。student 为 Qwen3-0.6B、teacher 为 Qwen3-1.7B，模型 snapshot revision、补丁基线和部署 SHA-256 保存在[manifest](../../results/training/inner-metrics-20261008/manifest.json)。远端生产核心、布局适配和入口脚本的 hash 与本机一致；11 个框架集成文件也逐一一致。补丁在干净官方基线上重放后与本机修改逐字节一致。

| 设置            | 实际值                                             |
| --------------- | -------------------------------------------------- |
| 数据            | canary 的四条算术 prompt；每个 outer 取两条        |
| rollout         | 每个 prompt 一条；温度 1、top-p 1、采样 top-k 关闭 |
| 长度            | prompt 上限 64、response 上限 64、vLLM context 128 |
| optimizer batch | prompt batch 2、mini-batch 2、micro-batch 1        |
| inner / outer   | 每个 outer 4 次全量更新，共 2 个 outer             |
| 方法参数        | $\eta=0.1$、anchor Top-k 32                        |
| 模型更新        | LoRA rank 8、alpha 16、BF16                        |
| optimizer       | AdamW、学习率 $10^{-5}$、gradient clip 1           |
| 同步            | outer hard sync                                    |
| 随机种子        | actor 与 data loader 为 42、vLLM engine 为 0       |

采样轨迹没有保存为一个跨方法共用的固定数据集，因此本次执行结果不是算法优劣的配对比较。MDPO 第一轮的 teacher center 就不同于另两种方法；这个差异必须在解释训练曲线时保留。

三种运行均正常退出，各写出 8 条记录，共 24 条。actor 报告的 allocated 显存峰值约 6.35 GB；它不是包括 vLLM 与其他进程在内的整卡峰值。全部 response 达到 64-token 长度上限，`clip_ratio=1`，因此本实验只能验证截断轨迹的执行链路。

## 结果与解释

下表取每个 outer 第一条与最后一条 pre-update 记录。最后一条是在第四次更新之前，不代表第四次更新后的状态。

| 方法 | outer | coefficient RMS 首 → 末 | grad norm 首 → 末 | 最低 ESS fraction |
| ---- | ----: | ----------------------: | ----------------: | ----------------: |
| BPO  |     0 |         1.7791 → 1.5586 | 18.9115 → 15.7904 |           0.99807 |
| BPO  |     1 |         1.4260 → 1.2603 | 14.2987 → 12.0429 |           0.99822 |
| Mean |     0 |         0.1779 → 0.1521 |   1.7821 → 1.4844 |           0.99838 |
| Mean |     1 |         0.1429 → 0.1319 |   1.3613 → 1.1408 |           0.99875 |
| MDPO |     0 |         3.3487 → 2.8529 | 32.6417 → 28.2306 |           0.99742 |
| MDPO |     1 |         1.9047 → 1.5485 | 15.8698 → 12.2896 |           0.99840 |

三个方法的 teacher center 在各自 outer 内逐条不变。每次 hard sync 后的 student center 均值绝对值小于 $2\times10^{-10}$；BF16/FP32 归约产生的极小负值属于数值误差。最后一条 student center 均值在 $6.2\times10^{-4}$ 至 $9.4\times10^{-4}$ 之间，表明本组更新的 anchor 位移较小。

这组数据支持缓存冻结、重算 student 和同步归零的执行语义。RMS 与梯度范数总体下降，但最后梯度仍明显非零，而且全部超过 clipping 阈值。不能据此宣布 inner 已收敛。AdamW、clipping、LoRA 和近似中心共同影响实际更新，独立 categorical logits 的精确 Fisher 步长结论不能直接套用。

Mean 第一轮初始系数 RMS 是 BPO 的 $0.1$ 倍，符合 $\eta=0.1$ 时初始化梯度尺度的推导。真实模型反向传播的梯度范数并非逐位严格相差 10 倍；低精度数值和模型链路的测量需要与 float64 数学恒等式分开。跨方法 RMS 和梯度量级也不是性能排名。

两个 outer 的 teacher center 下降包含 anchor 和访问 prefix 的共同变化，没有固定诊断 prefix，不能解释为同一分布上的 exact KL 单调下降。当前尚未接入固定 prefix 的 full-vocab student/teacher KL、参数更新范数和全局分位数；这些指标仍是正式收敛实验所需的独立测量。

# BPO 学习率迁移实验设计

## 研究问题与启动条件

本研究检验阶段最佳学习率及其可用上界如何随 teacher、student 和固定监督数据改变。优先采用同一初始化谱系的 1.5B 模型，通过单因素对照及 teacher × 数据域的四格对照辨认变化来源。这里只制定实验方案；没有启动新训练、生成新 rollout、下载模型权重或把这些条件加入自动队列。

开始本研究前，先完成并分析《2026-10-13-BPO全量学习率扫描与阶段对照》中的常数 lr 校准、相同 checkpoint 分叉、多种子确认和长轨迹检验。现有队列继续执行。后续网格、长度和预算根据这些结果锁定，再写入独立 manifest。本设计中的预算是候选预算，不是已经投入的算力。

需要先确认四项证据：常数 lr 的收益是否已经越过网格边缘；单步最佳 lr 与连续更新最佳 lr 是否一致；完整 BPO 与生产近似更新场是否给出一致的下降判断；7168-token 全量梯度能否在现有硬件正常执行。缺少这些证据时扩大模型矩阵，会把基础设置的问题重复九遍。

## 论文依据及本实验的位置

One-Shot OPD[^oneshot] 的固定状态消融复用初始 student 生成的 64 条轨迹，仍观察到数百步的学习。其附录 C.2 在默认 lr 的半倍、默认值和两倍上观察到有效时间轴近似重合。该结论支持先研究固定监督的步长效率；它没有给出跨 teacher 或模型可迁移的最大 lr。论文还用相同 1.5B student 配合不同领域的后训练 teacher，为小模型对照提供了直接参照。

Dual Nature[^dual] 将同源关系落实到共同的具体初始化 checkpoint，并比较同源与异源配对的泛化。我们的设计据此区分“同属 Qwen 系列”和“从同一个 checkpoint 继续训练”。论文的在线 OPD 使用 lr=1e-5、128 个 prompt × 每个 4 个 response；这些设置与当前冻结 64 条轨迹的 BPO 不同。其学习率作为待测范围的参考，不能直接作为本研究的推荐值。

两篇论文研究的主要对象是在线 OPD 的能力迁移。本实验先研究冻结 outer 中 BPO 的优化速度，再用少量能力评测检查所得速度收益。训练目标下降、teacher KL 下降和任务正确率提升分别报告。

## 学习率变化的可检验机制

### 换 teacher：保持二次度量，改变误差方向

固定 $q$、prefix 测度 $\mu$ 和 $\eta$，对 teacher $t$ 定义

$$
z_{G,t}=(1-\eta)z_q+\eta z_t,
\qquad Q_t(z)=\frac{1}{2\eta}\mathbb E_\mu[(z-z_{G,t})^\top F_q(z-z_{G,t})].
$$

对 $z$ 求导得到

$$
g_{z,t}=\frac{F_q(z-z_{G,t})}{\eta},
\qquad H_z=\frac{F_q}{\eta}.
$$

因此在相同 student 起点换 teacher，$H_z$ 保持一致，梯度及误差投影改变。在固定 Jacobian $J_c$ 的参数模型中同样有

$$
H_\theta=\frac{1}{\eta}\mathbb E_\mu[J_c^\top F_{q,c}J_c].
$$

设当前参数误差在 $H_\theta$ 的特征基中为 $e_i$。对普通梯度下降沿方向 $g=H_\theta e$，一步二次变化为

$$
Q(\theta-\alpha g)-Q(\theta)=-\alpha\sum_i\lambda_i^2e_i^2+\frac{\alpha^2}{2}\sum_i\lambda_i^3e_i^2.
$$

因此

$$
\alpha^*=\frac{\sum_i\lambda_i^2e_i^2}{\sum_i\lambda_i^3e_i^2}.
$$

换 teacher 即使没有改变曲率谱，也能通过 $e_i^2$ 的分布改变一步最佳 lr。teacher 的任务分数和初始 KL 都不足以单独预测这个比值。相同谱上的反例是两个目标分别沿小特征值和大特征值方向偏移，其最佳 lr 分别为对应特征值的倒数。

若 teacher 对照显示明显差异，再补一个误差幅度对照。对同一真实 teacher 定义合成目标 $t_\gamma\propto q^{1-\gamma}t^\gamma$，保持训练 $\eta=0.3$。在初始 $p=q$ 时，中心 residual 为 $R_\gamma=-\eta\gamma C_q\log(t/q)$，故 $Q_\gamma(q)=\gamma^2Q_1(q)$。先固定 $\gamma=0.5,1$，这两个目标只改变初始 residual 幅度，保留其 logit 方向。用实际 teacher 间的初始 Q 比例再做距离匹配，仅作为补充。合成目标不是新公开 teacher，也不用于能力排名；它用于检验“最佳 lr 仅由初始距离决定”的解释。Adam 的尺度抵消只在相应假设下成立，clip、epsilon 和后续非线性路径仍需记录。

真实共享网络还包含 residual 加权的 logit 二阶导数项。将 $\delta_c=z_\theta-z_G$ 代入链式法则得到

$$
\nabla_\theta^2Q=\frac{1}{\eta}\mathbb E_\mu\left[J_c^\top F_{q,c}J_c+\sum_v(F_{q,c}\delta_c)_v\nabla_\theta^2z_{\theta,c,v}\right].
$$

第二项随 teacher 变化。自由 logits 的不变性只给出参考模型的可检验预测，不能扩展成实际网络曲率与 teacher 无关的断言。

### 换 student 和数据：同时改变度量与参数几何

换 student 后，新 anchor $q$、$F_q$、Jacobian、初始 residual 和 Adam 状态共同变化。第一组对照保持架构与规模为 1.5B，只更换同源后训练 checkpoint，从而排除模型规模变化。模型规模及跨家族迁移放在后续阶段。

更换数据改变经验测度 $\mu$，并改变 response 长度、token 分布与 prefix 位置分布。相同 64 条轨迹不保证相同有效 token 数。所有条件记录实际 token 数与截断比例，能力和优化指标同时按更新次数、backward 次数、训练 token 数和耗时比较。

### AdamW 的方向与学习率响应

主实验继续使用原生 AdamW。设完成当前梯度计算及矩更新后，尚未乘 lr 的方向为 $d_n$，权重衰减为零。在同一 checkpoint 分叉并仅改变下一步 lr 时，$d_n$ 相同。沿这个方向的局部二次模型为

$$
Q(\theta-\alpha d_n)-Q(\theta)\approx-A_n\alpha+\frac12B_n\alpha^2,
\qquad A_n=\nabla Q^\top d_n.
$$

对两个 probe $h,2h$，记 $\Delta_h=Q(\theta-hd_n)-Q(\theta)$，得到

$$
\widehat B_n=\frac{\Delta_{2h}-2\Delta_h}{h^2},
\qquad \widehat A_n=\frac{\widehat B_nh}{2}-\frac{\Delta_h}{h}.
$$

当 $\widehat A_n>0$、$\widehat B_n>0$ 且第三个 probe 验证拟合时，报告一步候选 $\widehat A_n/\widehat B_n$ 和零下降候选 $2\widehat A_n/\widehat B_n$。它们是当前方向上的局部量。连续 20 步的最佳 lr 由真实分叉结果决定，因为随后参数、梯度与 Adam 矩已经分化。

生产 sampled-token、停止梯度的 Top-k center 场与完整 $Q$ 梯度存在差异，$A_n$ 能为负。此时记录方向不一致，不强制拟合正的最佳 lr。上述 probe 只评估原生方向，不构造 Hessian 或新的预条件器。

A0、D2、C1、C2 构成 teacher × 数据域的完整四格。对某阶段的最佳 lr 定义描述性交互量

$$
I=\log\alpha^*_{TC,DC}-\log\alpha^*_{TC,D0}-\log\alpha^*_{TJ,DC}+\log\alpha^*_{TJ,D0}.
$$

只在四格都具有内点最佳值及足够分辨率时计算 $I$，并按 seed 重采样给出区间。最佳值位于网格边缘时，报告删失区间，不能把网格边缘值当作已知最优。

S1/S2 回答后训练初始化如何影响 lr，不代表模型大小实验。它们也不预设 TJ 的各项能力都超过 student；正式能力评测先测每个 student 和 teacher 的基线，任务分数倒挂时仍保留优化对照，并单独报告能力变化。

## 固定训练 setting 与配对

| 项目      | 设置                                                                                           |
| --------- | ---------------------------------------------------------------------------------------------- |
| Outer     | 单轮冻结 $q$ 和 teacher，$\eta=0.3$                                                            |
| 训练数据  | 固定 64 条 rollout，每条全部有效 response token 参与每次更新，无放回重采样、无有放回 minibatch |
| 梯度      | 逐条累积，按全 pool 有效 response token 数归一化；每次更新恰有 64 次轨迹 backward              |
| 生产场    | 当前 sampled-action BPO，Top-16 加尾部桶 center，每次 forward 重算 student center 后停止梯度   |
| Optimizer | FP32、dropout=0、AdamW betas=(0.9,0.999)、epsilon=1e-8、weight_decay=0、全量梯度 clip=2        |
| Decoding  | 冻结初始 q，temperature=1、top-p=1、无 top-k 截断；保留自然 EOS                                |
| Prompt    | 主设计采用 16 个不同 prompt，每个 4 条响应；验证使用不重叠的 16 个 prompt，每个 1 条响应       |
| 长度      | 主矩阵候选 response cap=2048；总 context 不超过各模型实际支持值；7168-token 复验单列           |
| 审计      | 固定训练/验证各最多 4096 个 response prefix，保持固定 token 均值测度，记录选点 ID 和权重       |
| 物理 GPU  | 只用 0、1、2、3，现有设备为 H800，每张约 80 GiB                                                |

2048-token 主矩阵是在四卡预算下覆盖更多完整推理片段的候选折中，不称为无截断长推理。若前置长轨迹检验表明 7168-token 成本可接受，则在启动前统一提高主矩阵 cap 并重新登记预算；不能在条件间使用不同 cap。256-token 历史结果作为短轨迹参照，不能混入新矩阵主排名。

换 teacher 的 A0/T1/T2/C2 使用完全相同的 $q$ rollout、prefix、sampled action 和验证位置，只更换 teacher 分布缓存。同一个 seed 下 TJ/TC 的 Code 数据也复用相同 rollout。每个 lr 条件同样复用该条件的完整 pool。

换 student 的 S1/S2 使用相同 prompt ID、每个 prompt 的响应数和 decoding 设置，各自从初始 student 生成并冻结 $q$ rollout。随机种子相同不意味着生成相同响应。额外在 S0 的公共 prefix 面板上仅做诊断打分，用于区分状态访问差异和同状态预测差异；这个面板不冒充 S1/S2 的 on-anchor 训练测度。

所有新条件开始时 Adam 矩置零，此规则对 A0 同样适用。阶段分叉则完整保留本分支 Adam 一二阶矩和偏差修正 step。已有训练 checkpoint 若作为额外 student，必须另列“先前训练历史”条件，不能与公开初始模型混合解释。

Math/Code 共用外层消息结构，任务正文保留其题目内容。需要领域专用 system prompt 的能力验证另列，避免同时改变数据域与 system prompt。主对照按真实自然长度报告，长度机制复验使用事先定义的长度匹配 pool，固定 64 条及全部有效 token，不通过逐 token 重加权改变训练算法。

16 个 prompt 从清洗后的固定 split 按已登记 seed 无放回选择，同一条件的四条响应独立生成；不同 seed 更换题目与响应。主矩阵不按 teacher 是否能解题进行过滤。领域差异明显时再按初始 student 解题率分层复验，保持题目数、响应数和长度预算一致。这个 16 × 4 的新 pool 构成单独实验，A0 也重新生成；它与已有 256-token sweep 的输入不同，不能直接复用旧曲线作配对基线。

## 搜索、阶段选择和预算

### 发现阶段

使用独立 seed1042。从前置详细 sweep 的稳定区间选取覆盖峰值两侧的五个公共 lr，九条件各运行 160 次更新、每 10 步审计一次。原先八点网格不直接永久套用到每个模型。若条件在最小或最大 lr 获胜，逐次增加相邻二倍或半倍值，最多增加两个；仍在边缘则报告未定位最佳点。

基础预算为 $9\times5\times160=7200$ 次全 pool 更新，即 460800 次轨迹 backward。以审计之外的实际秒数和 token 数报告成本；不用模型参数规模推算未经测量的完成日期。

对每个条件选择归一化完整训练 BPO 曲线积分最小的常数分支。保留其全部阶段快照，并优先在 $Q_n/Q_0$ 首次低于 0.7、0.4、0.2 时做阶段分叉。该比例是可实现的观测 loss 比例；它不是已知不可约误差底之上的 excess loss。160 步内没有到达的阶段报告缺失，补报固定 update40/120/160 的结果。

### 同状态阶段分叉

每个可用阶段对五个公共 lr 各做 20 次更新，第一、第二步及每五步审计。最多 $9\times3\times5\times20=2700$ 次更新。下一步分叉保持参数、Adam 矩、optimizer step、q、teacher、输入和审计面板完全一致。

分别报告单步最佳 lr、20 步累计下降最佳 lr，以及长程常数最佳 lr。相同 $Q/Q_0$ 只改善阶段可比性，不等同于相同 residual 谱投影；因此还报告初始 $Q$、teacher KL、anchor 熵、Top-16 重合度、clip 比例和 Adam 方向统计。

在 A0 与变化最大的一个条件上，另用公共固定 prefix 审计完整 BPO 和 production residual 平方。审计数值不等同于生产 surrogate 的 coefficient × log_prob 数值。完整目标可下降而 sampled residual 指标反弹，反之亦然，两者都保留。

### 确认阶段与长度复验

发现阶段结束后锁定最多四个代表条件：A0、teacher 变化最大者、student 变化最大者、数据变化最大者。用 seed42/142/242 比较最佳常数、前置基线常数和一项已通过前置实验的标量调度，各 400 次更新；去除重复条件或重复 lr。上限为 $4\times3\times3\times400=14400$ 次更新。若前置 search/feedback 都未胜过强常数对照，第三项改为相邻常数，不预设调度必须进入确认。

发现、阶段分叉、确认的基础上限合计 24300 次全 pool 更新，1555200 次轨迹 backward，尚不含网格扩展、审计和生成。先完成发现与分叉，再决定确认是否值得投入，避免一开始把全部预算同时排入队列。

7168-token 长度复验优先选择 A0 与一个变化最大的 teacher 或 domain 条件，先做完整 64 条梯度的一步显存检验，再用三个 lr 做 80 步稳定性对照。若出现排序翻转，再增加第三 seed 与长程确认；80 步结果不声称已经验证长期收敛。

## 判分与机制分析

### 优化效率和稳定边界

主指标是达到固定完整 BPO 比例阈值 0.5、0.25、0.1 所需 backward 次数；阈值未达到时报告右删失。辅指标是固定预算的训练/验证 BPO、teacher reverse KL、KL(q 到 student)、每次更新下降比例和耗时。归一化比值随 $Q_0$ 改变，绝对 loss 曲线同步提供。

“可用 lr”定义为在指定更新预算内数值有限、完整 BPO 曲线积分优于不更新基线、最后三个审计点均低于初始值。最后 20 步若相对此前最小的三点滚动中位值反弹超过 10%，标记反弹。最高通过和最低失败的测试值仅给出有限预算经验区间；若排序不单调，展示所有可用/失败区间，不把它们压缩成唯一 max lr。

确认阶段要求三个 seed 的效率改善方向一致、中位 backward 节省至少 10%，同时验证 BPO 与 teacher KL 相对强常数对照退化不超过 5%。若任务分数下降，即使训练更快也不称为更好的能力迁移方案。三个 seed 的区间宽度据实报告，不把小样本区间包装成高精度显著性结论。

### 有效时间和更新幅度

对时变 lr 使用累计有效时间

$$
u_n=\sum_{j=0}^{n-1}\frac{\alpha_j}{10^{-6}}.
$$

在线性低步长区，检验相同条件不同 lr 的 $Q(u)$ 是否重合。分叉的第零步采用共同起点，避免把测量前后的索引错移一整步。不同 teacher 或 student 不预设共享一条 $Q(u)$ 曲线。

同时记录实际参数位移 $\lVert\Delta\theta_n\rVert_2$、相对位移 $\lVert\Delta\theta_n\rVert_2/\lVert\theta_n\rVert_2$ 及累计路径长度。它们帮助区分相同 lr 的不同有效更新幅度，但不自动定义新的训练调度。

One-Shot 的对齐参照采用裁剪已经不生效的区间：至少连续 10 次更新 clip=0 后才建立起点，无法达到则单列裁剪阶段。grad norm 归一化不能消除 Adam 历史，比较 lr 的主要证据仍来自相同参数和矩状态的分叉。

### 记录与可证伪标准

| 假设                                      | 支持证据                                                  | 否定或限制证据                                          |
| ----------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------- |
| teacher 主要通过 residual 方向改变可用 lr | 相同 q/prefix 下变化重复出现，局部 A/B 与真实单步峰值一致 | 相同初始距离仍无一致规律，或二次预测在 probe 范围外失败 |
| student 初始化比任务域更主导 lr           | S1/S2 的变化跨 seed 大于 D1/D2，且公共 prefix 诊断也变化  | 差异只出现在各自 rollout，公共 prefix 上消失            |
| 数据差异主要由长度解释                    | 事先定义的长度匹配复验显著缩小 lr 差异                    | 匹配后差异保留，需分析 token 分布与状态覆盖             |
| 可用 lr 由相对更新幅度解释                | 按相对位移比较后各条件稳定区间接近                        | 同样相对位移仍出现不同反弹与局部峰值                    |
| 低 lr 只改变数值时间                      | 相同条件的 Q(u) 在审计误差内重合                          | 曲线系统分离或排序随阶段改变                            |

这些比较只有九个条件，不能拟合高维“万能 lr 公式”。优先给出同一因素的配对差值和反例。初始 KL、grad norm、teacher 分数与最佳 lr 的相关性属于描述；因果论断必须依靠冻结因素或相同 checkpoint 分叉。

新增日志只记录全局标量：裁剪前后 grad norm、Adam 方向 norm、参数 norm、update norm、$g^\top d$、矩的全局 norm、epsilon 主导坐标比例、clip 状态。日志不改变 optimizer betas、二阶矩机制或方向。诊断收集成本计入实际耗时。

能力评测只在初始点及确认终点进行。Math 用当前 MATH-500、AMC23、AIME25；Code 使用排除训练时间段重叠的固定 LiveCodeBench 子集及官方执行判分，发现阶段可先冻结 100 题、avg@1 作成本受限筛查，确认阶段提高样本数并报告实际预算。所有模型使用同一评测 cap 和 decoding；截断率同步提供。优化阈值由固定 prefix 指标判定，不由这 100 题选择 lr。

## 四卡执行与后续规模迁移

主矩阵使用 1.5B student，每张授权卡执行一个条件，最多并发四个 worker。teacher 按冻结 prefix 离线打分并缓存，打分结束后释放模型；训练不要求 student、anchor、多个 teacher 同时常驻显存。评分与训练共用 GPU 租约，严格只占用物理 GPU0–3。

FP32 AdamW 的参数、梯度、一二阶矩合计约 $16P$ 字节。按 $P=1.8\times10^9$ 举例约 28.8 GB，这是基础张量估计，尚未包含 activation、logits、临时副本和框架开销，实际峰值由 canary 测量。完整词表 FP32 矩阵的存储为 $4NV$ 字节；64 条 × 2048 token × 151936 词表约 79.7 GB，q 与单 teacher 两份约 159.3 GB，尚不含 prompt 和验证。这些缓存放磁盘并按块读取，不全部驻留 GPU。

后续提高 student 规模需要共享参数和矩的分片或既有 offload 支持。4B 的基础张量已约 64 GB，不能据此声称单张 80 GB 卡足够长轨迹训练。第一轮先回答同源 1.5B 的 teacher、初始化和数据因素；确有可重复规律后再做一个 3B/4B 家族内部配对，以两至四卡执行单条件并先校验训练语义。

7B 仅作为条件明确的后续离线 teacher 候选。新家族使用其内部兼容 tokenizer 的配对，独立报告；跨家族直接 token KL 不混入当前实现。改变模型规模同时改变谱系与架构时，结果称为整组模型迁移，不声称识别了纯参数规模效应。14B/32B 及论文的 40K–96K 训练长度不进入这轮四卡计划。

启动后的每个 pool 保存 dataset revision、清洗规则、prompt/trajectory ID、模型 revision、tokenizer 校验、生成参数、自然 EOS/截断分布和 cache SHA。运行 manifest 保存代码 commit、实际 GPU、阶段来源 checkpoint 及 optimizer step。原始失败分支和边缘最优分支同样保留。

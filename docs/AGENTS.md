# AGENTS.md — 文档

本层补充文档特有要求。[文档分工](../.agents/references/documentation.md)定义事实归属；编写与审核使用[maintain-docs](../.agents/skills/maintain-docs/SKILL.md)，句级审阅使用[maintain-prose](../.agents/skills/maintain-prose/SKILL.md)。

- 当前参考对应当前实现；历史报告写明源码、条件及证据截止点，不把旧验证改称当前验证。
- 一项事实一个权威归属。架构解释职责，算法参考解释当前计算语义，运行指南提供操作，日志参考定义统计；完整证明与未审定推导进入`theory/`。
- 实验报告按[实验报告维护](../.agents/references/experiment-reports.md)组织，使用实际配置和原始产物核验。CPU 恒等式、GPU 链路、单种子训练与正式任务效果分别报告。
- 同一研究问题持续更新原报告；条件不同的运行分别列出。新证据推翻解释时改正原结论，说明纠正依据，保留原始数值及必要负结果。
- 正文只保留问题、方法、证据、论证、限制和复现条件。排队、PID、临时排错、工具安装及检查流水进入忽略的`runs/`。
- 逐篇决定重写、合并或删除。合并须迁入独有有效内容，再修复入链并删除被替代正文；不以“历史”名义保留重复文章，不按字数或文件数凑指标。
- 固定监督蒸馏与 BPO 总报告按用户要求保留一个 Markdown 文件，不受 1000 行限制；实现与估计器正确性对照维护独立报告。
- 段落不手工折行；外部来源按脚注引用，符号、测度、单位和时间条件明确。模板只提供骨架，不为填章节编造结论。

Agent Notes 保存长期决策理由，遵循[记录规则](../.agents/notes/README.md)。理论来源仍待用户 review 与合并；目录调整保留正文、推导和附件，不将未审定内容自动引入工程参考。检查能力与历史源码恢复见[维护指南](maintenance.md)。

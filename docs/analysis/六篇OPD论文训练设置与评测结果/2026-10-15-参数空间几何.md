# 6. P5：OPD 的参数空间几何，2606.07082

[返回横向总结](../2026-10-15-六篇OPD论文训练设置与评测结果调研.md)。

来源：Shen 等的几何研究[^geometry]。这篇的主要结果是参数空间统计与训练曲线，不是新的任务成绩排行榜。SFT、OPD、RLVR 的起点和训练预算不同，正文将它们作为几何比较，不能改写成等成本算法优劣评测。

## 6.3 几何诊断与评测协议

| 诊断                | 精确设置与聚合                                                                                                        |
| ------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 评测任务            | 主共享表写 AIME2024 avg@8；Code variant 为 LCB v5；评测 temperature、top-p、长度及 verifier 版本未披露                |
| BF16-aware sparsity | 两 checkpoint 先 cast BF16 再回 FP32；差值≤$10^{-3}\max(\lvert w_0\rvert,\lvert w_+\rvert)$视为不变；总体按参数数加权 |
| 主子空间旋转        | 每矩阵 top512 左右奇异子空间 principal angles；CPU float64 SVD，避免近相同矩阵的 GPU SVD 不稳                         |
| 谱漂移              | NSS=$\lVert\sigma(W_+)-\sigma(W_0)\rVert_2/\lVert\sigma(W_0)\rVert_2$；每矩阵计算后等权平均                           |
| update-mask 位置    | principal mask 取$W_0$的 rank64 重构的大幅值区域；low mask 取原始权重的小幅值区域；附录默认比例 0.5                   |
| stable rank         | 累积更新$\Delta W_t=W_t-W_0$的$\lVert\Delta W_t\rVert_F^2/\lVert\Delta W_t\rVert_{op}^2$，逐矩阵后平均                |
| 其他轨迹指标        | Frobenius norm；奇异值 Hill tail estimate，具体截断 k 未统一给出                                                      |
| 子空间一致性        | top16 右奇异向量与最终 checkpoint 比较，$\lVert V_{16}(t)^\top V_{16}(end)\rVert_F^2/16$                              |
| 控制实验分析矩阵    | 36 层×每层 4 个 attention 矩阵=144；必要时拆分 Q/K/V；矩阵间等权平均                                                  |
| 控制实验 checkpoint | 63、127、191、255、299；token sparsification 只评 63、127、191、255                                                   |

图 3 正文以 30% 作为随机 mask 基线，而附录 C.3 写默认 mask 比例 50%，因此这些图的 mask 参数须按图示另行确认，不能把附录默认 0.5 直接套到正文 30% 基线。图 2 正文的代表层旋转量级为 SFT>10°、OPD 约 1°、RLVR<0.5°；NSS 约$10^{-3}/10^{-4}/10^{-5}$，属于图示/文字量级，不是精确全层均值。

## 6.4 所有投影、采样与目标消融

| 控制                    | 具体变化                                                                                                               | 观测结果                                                                         |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| rank16 投影训练         | 在各自训练约 20% 处从累积更新提取 top16 右奇异向量 V，后续每矩阵梯度替换为$gVV^\top$；OPD/SFT 各自使用自己的早期子空间 | OPD 性能基本保持，SFT 下降；图 6、8；不是将训练权重压成 rank16                   |
| top-KL 稀疏化           | 每条 response 按采样动作的$\log p_\theta-\log p_T$排序，保留最大的 25%/50%；并非按绝对值或完整分布 KL 排序             | stable rank 接近原 OPD；图 7a                                                    |
| random 稀疏化           | 每 response 均匀保留 25%/50%token                                                                                      | stable rank 仍接近；图 7a                                                        |
| 稀疏信号补偿            | mask 后的 gap 乘$T/\sum m_t$，再以负 gap 加入 advantage；逐 response 独立 mask                                         | 改变 update 量级多于谱形状；图 9；空 mask 处理未披露                             |
| off-policy              | 教师 Qwen3-32B 产生轨迹，学生对教师 token 计算 log-prob；纯蒸馏，无 outcome 混合                                       | norm 稍大，stable rank 近似匹配；图 7b/9；这不是固定初始学生缓存                 |
| off-policy 服务与 ratio | sglang router，两份教师 replica；importance-ratio clipping ε=1.0，作者称该设置近似不约束此对照                         | 实际全局 ratio 不受裁剪的范围与实现细节未给出，不宜将ε=1 写成数学上完全禁用 clip |
| objective mixing        | $A^{(\alpha)}=\alpha A_{OPD}+(1-\alpha)A_{RLVR}$；α={0.75,0.50,0.25,0.05,0.01}，纯 OPD=1、纯 RLVR=0                    | OPD 分量很弱时离开原 stable-rank 轨迹；图 7c/9                                   |
| mixing 归约             | OPD 为负 sampled log-gap；RLVR 为数学正确性 GRPO advantage 广播到 token；原始信号直接混，不按 batch 标准差归一化       | α是信号混合权重，不是 P6 的教师概率插值系数                                      |

rank16 附加评测图 8 的轴直接写出不同采样次数：AIME2024 avg@32、AMC2023 avg@4、AIME2025 avg@8、Minerva avg@4、Beyond AIME avg@4。这与共享表写 AIME2024 avg@8 不同；本文保留该实验专属图示协议。原文没有给每条曲线的精确末步数值表。

## 3.2 评测协议

评测 temperature=1.0、top-p=0.95、top-k=−1；长度按原表 4。数学与科学任务均加入 system prompt，取最后一个 `\boxed{}` 的内容，使用 Math-Verify 解析和判分。数学提示为 `Please reason step by step, and put your final answer within \boxed{}.`；GPQA 提示限定 boxed 中只放 A/B/C/D。所有模型使用相同的这两种 system prompt。

| Benchmark        | Metric |
| ---------------- | ------ |
| AMC 2023         | Avg@16 |
| MATH-500         | Avg@1  |
| AIME 2025        | Avg@16 |
| AIME 2026        | Avg@16 |
| BeyondAIME       | Avg@5  |
| OlymMATH-Hard    | Avg@5  |
| OlymMATH-Easy    | Avg@5  |
| OlymMATH-ZH      | Avg@5  |
| R-HORIZON        | Avg@10 |
| LiveMathBench-ZH | Avg@16 |
| GPQA-Diamond     | Avg@4  |
| LiveCodeBench v5 | Avg@10 |
| IFEval           | Avg@4  |

English Math 是 AMC2023、MATH-500、AIME2025、AIME2026、BeyondAIME、OlymMATH-Hard 六项宏平均；Chinese Math 是 OlymMATH-ZH 与 LiveMathBench-ZH 的平均；Long-Horizon Math 是 R-HORIZON 的 AIME24-Horizon-2 与 AMC23-Horizon-4 平均。Code 使用 LCB v5 中 2024-08-01 至 2025-02-01 的题目；Science 用 GPQA-Diamond；IF 用 IFEval。不同 benchmark 的 K 不同，先在各项内计算 avg@K，再按论文分组平均。

曲线只用于展示时做中心移动平均：第一点不平滑，第二点平均前三个 checkpoint，之后使用前后各两个点的五点窗口。右端使用图示区间之后仍已记录的 checkpoint，所以末端曲线并非原始末步单点；表值与统计计算不做平滑。多训练种子的均值与误差未给出。

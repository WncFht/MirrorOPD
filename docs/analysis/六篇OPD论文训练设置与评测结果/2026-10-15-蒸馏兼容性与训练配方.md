| 后续 OPD           | 剩余 OpenThoughts prompt 与 SFT prompt 去重，约 30K；同教师；与从 Base 直接启动 OPD 的对照使用相同 prompt 集                                                    |

另一个“prompt 内容对齐”实验的 DeepMath 去重：先从两数据集抽题面、去掉 instruction suffix；删 exact match；用`all-mpnet-base-v2`嵌入并 L2 归一化，FAISS 内积 top1 检索，余弦相似度≥0.6 删除。最终与 DAPO 匹配规模；精确剩余样本 ID 及随机 seed 未给出。

DAPO 原模板要求最后单列 `Answer: $Answer`，同时有“step by step”的指令；教师对齐模板改成问题后追加 boxed 指令。两者改变输出格式，不是只改变数据内容。内容对齐实验中，更高的交集概率质量伴随更低学生熵；论文建议混入教师训练数据之外的 prompt，但没有提供一组已验证的最优混合比例。

## 5.5 论文公式与公开代码的差别

正文式 (5) 将学生和教师在同一候选集合内分别归一化后计算 KL。固定代码的 `dp_actor.py` 中，`only_stu` 分支计算原始 log-ratio，并只将学生权重在集合内归一化：

$$
\widetilde p(v)=\frac{p(v)}{\sum_{u\in S}p(u)},\qquad A(v)=-\widetilde p(v)\,[\log p(v)-\log q(v)].
$$

这个差别在 k=1 尤其明确：若两侧都在单元素集合上归一化，则 KL 恒为 0；代码却保留该 argmax token 的原始教师—学生 log-ratio，因此能产生非零信号。本文的 top1 失败结果指作者报告的实验实现，不将它解释为数学上恒为 0 的归一化单元素 KL。

代码还对交集分支归一化权重，但对`union-intersection`（对称差）设置`normalize=False`，使用未归一化概率；空交集引起的非有限权重经`nan_to_num`置 0。因而公开代码的交集/对称差消融同时改变 support 和权重标度，不能仅凭该实验宣称两个设置具有相同梯度尺度。以上为固定代码核验，不代表已经重跑并验证其全部训练结果。

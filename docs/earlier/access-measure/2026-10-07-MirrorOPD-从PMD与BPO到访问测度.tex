\chapter*{摘要}
\addcontentsline{toc}{chapter}{摘要}
本文从固定 prefix 上的 KL 镜像子问题出发，统一写出 PMD-Part、PMD-Mean、BPO 与 MDPO 的优化目标、精确最优解和参数梯度。主线结论是：PMD-Part 的闭式 target 是 Gibbs 分布；PMD-Mean 是带单纯形约束的 Lambert-$W$ 投影；MDPO 直接优化 KL 正则化目标，梯度中保留 action importance ratio；BPO 从平方 residual 回归出发；本稿保留完整 reverse-KL 导数并分析其中心化 score 梯度，不把后续线性化、二元 KL 或工程权重作为理论前提。四者可以共享同一个 token-level 最优策略，但离开最优点后的梯度并不相同。重要性采样降低测度偏差却引入 ratio 方差，回归型方法则承担访问测度下的投影偏差。最后核对 OpenKimi、经典 MDPO 和 BPO 论文源码，区分固定 inner budget 与真正的子问题收敛。

\chapter{统一的 token-level 镜像子问题}
\label{ch:unified-problem}

\section{Prefix、行为策略与局部 reward}
\label{sec:notation}

固定一个 prefix $s=(x,a_{<t})$，词表动作为 $a$，行为策略为 $\beh(a\mid s)$，待更新学生策略为 $\cand_\theta(a\mid s)$。以下所有结论都在
\[
\cand_\theta(\cdot\mid s)\ll\beh(\cdot\mid s)
\]
的 support 条件下成立。记局部监督信号为 $f(s,a)$；它可以是即时 per-token reward、优势 $A^\beh(s,a)$，也可以是包含未来 reward 的 soft $Q$。

设 $d_\beh(s)$ 是行为轨迹访问 prefix 的测度。若一个条件 target 在每个 prefix 上可以独立实现，则 $d_\beh(s)>0$ 只决定该 prefix 在总体训练损失中的权重；如果模型共享参数、数据有限或存在未覆盖 prefix，它会改变投影点和估计方差。

\section{KL 镜像最优解}
\label{sec:token-optimum}

给定 Natural Gradient 学习率 $\eta>0$，token-level PMD 子问题为
\begin{equation}
\label{eq:token-subproblem}
 \cand^+(\cdot\mid s)=\argmax_{p\ll\beh(\cdot\mid s)}
 \left\{\E_{a\sim p}[f(s,a)]-\frac{1}{\eta}\KL(p\Vert\beh(\cdot\mid s))\right\}.
\end{equation}
令
\[
 Z_f(s)=\E_{a\sim\beh(\cdot\mid s)}\exp\left(\eta f(s,a)\right).
\]

\begin{theorem}[Token-level Gibbs 解]
\label{thm:gibbs}
若 $0<Z_f(s)<\infty$，式 \eqref{eq:token-subproblem} 的唯一解为
\begin{equation}
\label{eq:gibbs}
 \cand^+(a\mid s)=\frac{\beh(a\mid s)\exp(\eta f(s,a))}{Z_f(s)}.
\end{equation}
等价地，$u^+(s,a)=\log(\cand^+/\beh)$ 满足
\begin{equation}
\label{eq:optimal-logratio}
 u^+(s,a)=\eta f(s,a)-\log Z_f(s).
\end{equation}
\end{theorem}

\begin{proof}
先检查式 \eqref{eq:gibbs} 确实定义了概率分布。由于 $Z_f(s)$ 是有限正数，
\[
\sum_a\cand^+(a\mid s)
=\frac{1}{Z_f(s)}\sum_a\beh(a\mid s)e^{\eta f(s,a)}=1.
\]
并且 $\cand^+(a\mid s)>0$ 只可能发生在 $\beh(a\mid s)>0$ 的 action 上，所以 $\cand^+\ll\beh$。
对任意满足 $p\ll\beh$ 的候选分布，由定义逐项展开可得
\begin{align*}
\KL(p\Vert\cand^+)
&=\E_p\left[\log\frac{p}{\cand^+}\right]\\
&=\E_p\left[\log\frac{p}{\beh}
      -\eta f+\log Z_f(s)\right]\\
&=\KL(p\Vert\beh)-\frac1\eta\E_p[f]+\log Z_f(s).
\end{align*}
将等式两边乘以 $-1/\eta$ 并整理，得到目标恒等式
\begin{equation*}
\E_p[f]-\frac1\eta\KL(p\Vert\beh)
=\frac1\eta\log Z_f(s)-\frac1\eta\KL(p\Vert\cand^+).
\end{equation*}
KL 散度满足 $\KL(p\Vert\cand^+)\geq0$，且等号当且仅当 $p=\cand^+$ 几乎处处成立。因此任意候选分布的目标值都不超过 $\frac1\eta\log Z_f(s)$，而 $p=\cand^+$ 达到该上界，故它是唯一最优解。
\end{proof}

\begin{corollary}[优势形式]
若 $f=A^\beh$ 且 $\E_{\beh}[A^\beh(s,\cdot)\mid s]=0$，则
\[
\cand^+(a\mid s)=\beh(a\mid s)\exp(\eta A^\beh(s,a)) / Z_A(s).
\]
若 $A^\beh$ 是与序列 PMD 一致的 soft advantage，则 $Z_A(s)=1$；若它是硬 reward advantage，$Z_A(s)$ 一般不等于 $1$。
\end{corollary}

\section{即时 reward 与完整序列 reward}
\label{sec:immediate-vs-return}

若 $f(s,a)=r_t(s,a)$，式 \eqref{eq:token-subproblem} 是局部 token reward 的镜像更新。若完整目标是
\[
R(y)=\sum_{t=1}^{T}r_t(s_t,a_t),
\]
则与 sequence-level PMD 一致的 token score 必须是
\[
Q^\beh(s_t,a_t)=r_t(s_t,a_t)+\E_\beh\left[\sum_{k>t}r_k(s_k,a_k)\mid s_t,a_t\right],
\]
再取相应 soft advantage。直接把 $r_t$ 放进式 \eqref{eq:gibbs} 会得到局部目标，而不是完整序列目标。per-token reward 消除了终端奖励的稀疏性，却没有消除 future reward 对全局最优条件分布的作用。

\chapter{四种方法从最优解出发的推导}
\label{ch:four-methods}

\section{共同起点：同一个镜像子问题如何产生两个 residual}
\label{sec:common-residual-origin}

固定 prefix $s$，把行为策略简写为 $\mu(a)$，把候选策略简写为 $\pi(a)$，并令 $u(a)=\log(\pi(a)/\mu(a))$。统一采用 Natural Gradient 学习率 $\eta$，镜像子问题为
\begin{equation}
\label{eq:common-mirror-objective}
\max_{p\ll\mu}
\left\{\E_p[f]-\frac1\eta\KL(p\Vert\mu)\right\}.
\end{equation}
对任意 $p$，定义
\[
Z_f=\E_\mu[e^{\eta f}],
\qquad
\pi^+(a)=\frac{\mu(a)e^{\eta f(a)}}{Z_f}.
\]
与定理 \ref{thm:gibbs} 相同的 KL 分解给出
\[
\E_p[f]-\frac1\eta\KL(p\Vert\mu)
=\frac1\eta\log Z_f-
\frac1\eta\KL(p\Vert\pi^+).
\]
因此最优策略满足
\begin{equation}
\label{eq:common-optimality-equation}
 u^+(a)=\log\frac{\pi^+(a)}{\mu(a)}
 =\eta f(a)-\log Z_f.
\end{equation}
这一步是 PMD-Part 与 BPO 的共同起点，尚未引入任何线性化、clip 或重要性采样。

PMD-Part 直接把式 \eqref{eq:common-optimality-equation} 当作逐 action 的回归方程。定义
\begin{equation}
\label{eq:part-residual-from-optimum}
 q(a):=u^+(a)-u(a)
 =\underbrace{\eta f(a)-\log Z_f}_{h(a)}-u(a).
\end{equation}
所以 PMD-Part 的平方损失就是 $q(a)^2/2$ 的行为测度平均。

BPO 采用同一个最优性方程的“常数消除”形式。令
\[
 b(a):=\eta f(a)-u(a).
\]
在行为优势满足 $\E_\mu[f]=0$ 时，
\begin{align*}
\E_\mu[b]
&=\eta\E_\mu[f]-\E_\mu[u]\\
&=-\E_\mu[u]\\
&=\KL(\mu\Vert\pi).
\end{align*}
于是 BPO 的 centered residual 是
\begin{equation}
\label{eq:bpo-residual-from-optimum}
\delta(a):=b(a)-\E_\mu[b]
=\eta f(a)-u(a)-\KL(\mu\Vert\pi)
=\eta f(a)-u(a)+\E_\mu[u].
\end{equation}
它等价于把同一个最优性方程中的 action-independent 常数先减去行为均值。

两种 residual 的零点仍然相同。若 $\delta(a)=0$ 对所有有正行为概率的 action 成立，则 $u(a)=\eta f(a)-C$，其中 $C$ 与 action 无关。策略归一化要求
\[
1=\E_\mu[e^{u}]
=e^{-C}\E_\mu[e^{\eta f}]
=e^{-C}Z_f,
\]
所以 $C=\log Z_f$，从而 $u=u^+$。反过来，若 $u=u^+$，则 $b(a)=\log Z_f$ 为常数，故 $\delta(a)=0$。因此 BPO 和 PMD-Part 由同一个镜像最优解出发，并共享同一个可实现零点；它们的差别只出现在对这个最优性方程采用的残差和参数梯度上。

\section{中心化条件的来源与 OPD 特化}
\label{sec:centering-and-opd}

前面的条件 $\E_\mu[f\mid s]=0$ 不是任意 per-token reward 都满足的恒等式。它在 $f=A^\mu$ 时成立，是因为优势函数按定义为
\[
A^\mu(s,a)=Q^\mu(s,a)-V^\mu(s),
\qquad
V^\mu(s)=\E_{a\sim\mu(\cdot\mid s)}[Q^\mu(s,a)],
\]
所以逐 prefix 有
\begin{align*}
\E_\mu[A^\mu(s,a)\mid s]
&=\E_\mu[Q^\mu(s,a)\mid s]-V^\mu(s)\\
&=V^\mu(s)-V^\mu(s)=0.
\end{align*}
如果 $f$ 是即时 reward、教师打分、logit reward 或任意 OPD per-token reward，这个均值通常不为零。此时可以定义
\[
\bar f(s):=\E_\mu[f(s,a)\mid s],
\qquad
\widetilde f(s,a):=f(s,a)-\bar f(s),
\]
并用 $\widetilde f$ 作为 BPO 的中心化信号。中心化只减去 prefix 相关的 action-independent 常数；在 Gibbs 解中，
\[
\frac{\mu(a\mid s)e^{\eta\widetilde f(s,a)}}
{\E_\mu[e^{\eta\widetilde f(s,\cdot)}\mid s]}
=
\frac{\mu(a\mid s)e^{\eta f(s,a)}}
{\E_\mu[e^{\eta f(s,\cdot)}\mid s]},
\]
因此不改变最优条件策略，只改变配分函数的表示。

令 $r_{\mathrm{OPD}}(s,a)$ 表示 OPD 在当前 prefix 上提供的即时 token 信号。它可以是教师偏好分数、教师与行为策略的 log-ratio、或已经估计好的 token advantage。记
\[
\bar r(s)=\E_\mu[r_{\mathrm{OPD}}(s,a)\mid s],
\qquad
\widetilde r(s,a)=r_{\mathrm{OPD}}(s,a)-\bar r(s),
\]
则三种 token-level 方法都可以从同一个 OPD mirror subproblem 出发：
\begin{equation}
\label{eq:opd-mirror-subproblem}
\max_{p\ll\mu}
\left\{
\E_p[r_{\mathrm{OPD}}(s,a)]
-\frac1\eta\KL(p\Vert\mu(\cdot\mid s))
\right\}.
\end{equation}
其精确教师策略为
\begin{equation}
\label{eq:opd-gibbs}
\pi^+_{\mathrm{OPD}}(a\mid s)
=
\frac{\mu(a\mid s)e^{\eta r_{\mathrm{OPD}}(s,a)}}
{Z_{\mathrm{OPD}}(s)},
\qquad
Z_{\mathrm{OPD}}(s)=\E_\mu[e^{\eta r_{\mathrm{OPD}}(s,\cdot)}\mid s].
\end{equation}

\paragraph{OPD--PMD-Part.}
定义
\[
h_{\mathrm{OPD}}(s,a)=\eta r_{\mathrm{OPD}}(s,a)-\log Z_{\mathrm{OPD}}(s).
\]
PMD-Part 回归完整的 OPD log-ratio：
\begin{equation}
\label{eq:opd-part-loss}
\mathcal L_{\mathrm{Part}}^{\mathrm{OPD}}
=\frac12\E_{s\sim d_\mu,\,a\sim\mu}
\left[u_\theta(s,a)-h_{\mathrm{OPD}}(s,a)\right]^2,
\end{equation}
其下降方向为
\begin{equation}
\label{eq:opd-part-gradient}
-\nabla_\theta\mathcal L_{\mathrm{Part}}^{\mathrm{OPD}}
=\E_{d_\mu\mu}
\left[(h_{\mathrm{OPD}}-u_\theta)g_\theta\right].
\end{equation}
它不需要对 action 乘 IS ratio；访问测度 $d_\mu\mu$ 只决定 OPD residual 在 prefix 和 action 上的投影权重。

\paragraph{OPD--PMD-Mean.}
PMD-Mean 先用中心化信号
\[
g_{\mathrm{OPD}}(s,a)=\eta\widetilde r(s,a)
\]
替代未知的 $\log Z_{\mathrm{OPD}}$，再求解带归一化约束的投影：
\begin{equation}
\label{eq:opd-mean-loss}
\min_u\frac12\E_{d_\mu\mu}[(u-g_{\mathrm{OPD}})^2]
\quad\text{s.t.}\quad
\E_{a\sim\mu(\cdot\mid s)}[e^{u(s,a)}]=1.
\end{equation}
固定 prefix 后，令 $\lambda(s)$ 为约束乘子，则一阶条件为
\[
u(s,a)-g_{\mathrm{OPD}}(s,a)+\lambda(s)e^{u(s,a)}=0.
\]
令 $v=g_{\mathrm{OPD}}-u$，得到
\[
v e^v=\lambda(s)e^{g_{\mathrm{OPD}}},
\]
所以
\begin{equation}
\label{eq:opd-mean-lambert}
u_{\mathrm{Mean}}^+(s,a)
=g_{\mathrm{OPD}}(s,a)
-W\!\left(\lambda(s)e^{g_{\mathrm{OPD}}(s,a)}\right),
\end{equation}
其中 $\lambda(s)$ 由归一化约束确定。这个解一般不等于精确 OPD Gibbs log-ratio；它是行为测度下的中心化 log-ratio 投影。

\paragraph{OPD--BPO.}
对任意 OPD reward，BPO 应使用中心化 residual，而不能直接把 $\E_\mu[f]=0$ 当作无条件事实：
\begin{equation}
\label{eq:opd-bpo-residual}
\delta_{\mathrm{OPD}}(s,a)
=\eta\widetilde r(s,a)-u_\theta(s,a)
+\E_{a'\sim\mu(\cdot\mid s)}[u_\theta(s,a')].
\end{equation}
因为 $\E_\mu[\widetilde r\mid s]=0$，有 $\E_\mu[\delta_{\mathrm{OPD}}\mid s]=0$。完整 reverse-KL 的梯度为
\[
\nabla_\theta\delta_{\mathrm{OPD}}(s,a)
=-\left(g_\theta(s,a)-\bar g_\theta(s)\right),
\qquad
\bar g_\theta(s)=\E_\mu[g_\theta(s,a)\mid s],
\]
所以未线性化 OPD--BPO 的下降方向为
\begin{equation}
\label{eq:opd-bpo-gradient}
-\eta\nabla_\theta\mathcal L_{\mathrm{BPO}}^{\mathrm{OPD}}
=\E_{d_\mu\mu}
\left[\delta_{\mathrm{OPD}}(g_\theta-\bar g_\theta)\right].
\end{equation}
若 OPD reward 本身就是优势，$\widetilde r=r_{\mathrm{OPD}}$；若不是优势，式 \eqref{eq:opd-bpo-residual} 的中心化步骤是定义 BPO residual 所必需的。三者都使用同一个 token-level OPD mirror subproblem，但 PMD-Part 拟合精确配分函数，PMD-Mean 做归一化约束投影，BPO 做行为测度下的中心化 residual 回归。

\section{PMD-Part：回归最优 log-ratio}
\label{sec:pmd-part}

定义 $u_\theta(s,a)=\log\cand_\theta(a\mid s)/\beh(a\mid s)$，并令
\[
h(s,a)=\eta f(s,a)-\log Z_f(s).
\]
PMD-Part 在行为测度下回归精确最优性方程：
\begin{equation}
\label{eq:part-loss}
 \mathcal L_{\mathrm{Part}}(\theta)
 =\frac12\E_{s\sim d_\beh,\,a\sim\beh}
 \left[u_\theta(s,a)-h(s,a)\right]^2.
\end{equation}
把 target $h$ 和行为策略视为固定，记 $g_\theta(s,a)=\nabla_\theta\log\cand_\theta(a\mid s)$，则
\begin{equation}
\label{eq:part-gradient}
 -\nabla_\theta\mathcal L_{\mathrm{Part}}
 =\E_{d_\beh\beh}\left[(h-u_\theta)g_\theta\right].
\end{equation}

\begin{proposition}[PMD-Part 的零点]
\label{prop:part-zero}
在无限容量、正访问权重和满 action support 下，$\mathcal L_{\mathrm{Part}}=0$ 当且仅当 $\cand_\theta(\cdot\mid s)=\cand^+(\cdot\mid s)$ 对 $d_\beh$-几乎处处的 prefix 成立。
\end{proposition}

\begin{proof}
平方损失为非负数。它为零当且仅当 $u_\theta=h$ 在行为测度下几乎处处成立。指数化并使用式 \eqref{eq:optimal-logratio} 即得 $\cand_\theta=\cand^+$。反向蕴含显然成立。
\end{proof}

PMD-Part 的重要性质是目标中没有 ratio 权重；ratio 只出现在被拟合的 log-ratio 中。因此它避免了直接 policy gradient 的乘法重尾，但有限模型下它优化的是 $d_\beh$ 加权的投影。

\section{\texorpdfstring{PMD-Mean：中心化回归与 Lambert-$W$}{PMD-Mean：中心化回归与 Lambert-W}}
\label{sec:pmd-mean}

令
\[
\bar f(s)=\E_{a\sim\beh}[f(s,a)\mid s],
\qquad g(s,a)=\eta\left(f(s,a)-\bar f(s)\right).
\]
PMD-Mean 不显式估计 $\log Z_f(s)$，而求解
\begin{equation}
\label{eq:mean-loss}
 \min_u\;\frac12\E_{s\sim d_\beh,a\sim\beh}[(u-g)^2]
 \quad\text{s.t.}\quad
 \E_{a\sim\beh(\cdot\mid s)}[e^{u(s,a)}]=1\quad\forall s.
\end{equation}
约束是策略归一化，而不是可省略的附加条件。

\begin{theorem}[PMD-Mean 的逐 prefix 解]
\label{thm:mean-lambert}
在有限 action space、$\beh(a\mid s)>0$ 和可行条件下，式 \eqref{eq:mean-loss} 的 KKT 解满足
\begin{equation}
\label{eq:mean-lambert}
 u^+(s,a)=g(s,a)-W\!\left(\lambda(s)e^{g(s,a)}\right),
\end{equation}
其中 $\lambda(s)\geq0$ 由 $\E_\beh[e^{u^+(s,\cdot)}\mid s]=1$ 唯一确定。
\end{theorem}

\begin{proof}
固定 prefix $s$，记行为概率为 $\beh_a=\beh(a\mid s)$，并把 $g_a=g(s,a)$。由于 action space 有限且 $\beh_a>0$，该问题是严格凸目标加凸归一化约束；因此满足 KKT 条件的解就是唯一全局解。其拉格朗日函数为
\[
\mathcal J(u,\lambda)=
\frac12\sum_a\beh_a(u_a-g_a)^2
+\lambda\left(\sum_a\beh_a e^{u_a}-1\right).
\]
对每个 $u_a$ 求偏导，并利用 $\beh_a>0$，得到
\[
0=\frac{1}{\beh_a}\frac{\partial\mathcal J}{\partial u_a}
=u_a-g_a+\lambda e^{u_a}.
\]
令 $v_a=g_a-u_a$，则 $u_a-g_a=-v_a$，代入上式并乘以 $e^{v_a}$：
\[
v_a=\lambda e^{g_a-v_a}
\quad\Longleftrightarrow\quad
v_a e^{v_a}=\lambda e^{g_a}.
\]
Lambert-$W$ 函数由 $W(z)e^{W(z)}=z$ 定义，所以
\[
v_a=W(\lambda e^{g_a}),
\qquad
u_a=g_a-W(\lambda e^{g_a}),
\]
这就是式 \eqref{eq:mean-lambert}。
剩下的乘子由归一化方程确定。令
\[
H(\lambda)=\sum_a\beh_a
\exp\left(g_a-W(\lambda e^{g_a})\right).
\]
对 $\lambda\geq0$，每个 $W(\lambda e^{g_a})$ 随 $\lambda$ 单调增加，因此 $H$ 连续单调下降；可行条件保证存在 $\lambda$ 使 $H(\lambda)=1$。严格凸性保证该乘子对应的 $u$ 唯一。
\end{proof}

PMD-Part 的修正项 $\log Z_f(s)$ 对 action 是常数，PMD-Mean 的 Lambert-$W$ 项依赖 action。两者只有在退化或额外近似下才相同；它们可以拥有相同的排序和单调改进性质，但不是同一个 mirror subproblem 的两个无偏实现。

\section{MDPO：直接优化 KL 正则化目标}
\label{sec:mdpo}

MDPO 直接对式 \eqref{eq:token-subproblem} 的目标做参数优化。令
\[
F_s(\theta)=\E_{a\sim\cand_\theta}[f(s,a)]-\frac1\eta\KL(\cand_\theta\Vert\beh).
\]
对 $\theta$ 求导时，先将 KL 写成
\[
\KL(\cand_\theta\Vert\beh)=
\E_{a\sim\cand_\theta}[\log\ratio_\theta].
\]
对第一项使用 score identity，对第二项使用乘积法则：
\begin{align*}
\nabla_\theta\E_{\cand_\theta}[f]
&=\E_{\cand_\theta}[f g_\theta],\\
\nabla_\theta\E_{\cand_\theta}[\log\ratio_\theta]
&=\E_{\cand_\theta}[g_\theta\log\ratio_\theta]
  +\E_{\cand_\theta}[\nabla_\theta\log\ratio_\theta]\\
&=\E_{\cand_\theta}[g_\theta\log\ratio_\theta]
  +\E_{\cand_\theta}[g_\theta]
=\E_{\cand_\theta}[g_\theta\log\ratio_\theta],
\end{align*}
因为 $\beh$ 不依赖 $\theta$，所以 $\nabla_\theta\log\ratio_\theta=g_\theta$，且归一化恒等式给出 $\E_{\cand_\theta}[g_\theta]=0$。因此
\begin{equation}
\label{eq:mdpo-onpolicy-gradient}
\nabla F_s
=\E_{a\sim\cand}\left[
\left(f(s,a)-\frac1\eta\log\ratio_\theta(s,a)\right)g_\theta(s,a)
\right].
\end{equation}
其中 $\ratio_\theta=\cand_\theta/\beh$。若样本来自行为策略，则
\begin{equation}
\label{eq:mdpo-is-gradient}
\nabla F_s
=\E_{a\sim\beh}\left[
\ratio_\theta(s,a)\left(f(s,a)-\frac1\eta\log\ratio_\theta(s,a)\right)g_\theta(s,a)
\right].
\end{equation}
这就是 MDPO 中的 action-level IS。若状态也来自 replay 的 $d_\beh$，而目标是 $d_{\cand}$ 下的 occupancy 目标，还需要 prefix ratio；经典实现通常把状态测度固定为 replay/rollout 测度，因而没有完整解决 state-distribution mismatch。

\begin{proposition}[MDPO 梯度与 PMD-Part 回归梯度的零点一致、方向不一致]
\label{prop:mdpo-part}
MDPO 的梯度式 \eqref{eq:mdpo-is-gradient} 与 PMD-Part 梯度式 \eqref{eq:part-gradient} 在精确镜像解处都为零，但一般不相等。
\end{proposition}

\begin{proof}
在镜像解处，$\log\ratio=\eta f-\log Z_f$，故式 \eqref{eq:mdpo-onpolicy-gradient} 为最优目标的驻点；PMD-Part 的 residual $h-u$ 逐点为零。离开镜像解时，MDPO 被积函数包含 $\ratio_\theta$ 和 $f-\frac1\eta\log\ratio_\theta$，PMD-Part 被积函数只有 $h-u_\theta$，两者测度和残差均不同。
\end{proof}

\section{BPO：从 token 最优性到实际 PG surrogate}
\label{sec:bpo}

BPO 的 token-level PMD 起点与式 \eqref{eq:token-subproblem} 相同，使用 $f=A^\beh$。在终端奖励情形，论文先定义 token residual
\begin{equation}
\label{eq:bpo-token-residual}
 d_\pi(s_t,a_t)=\eta A^\beh(s_t,a_t)-\left[\log\frac{\cand(a_t\mid s_t)}{\beh(a_t\mid s_t)}+\KL(\beh(\cdot\mid s_t)\Vert\cand(\cdot\mid s_t))\right].
\end{equation}
该 residual 在 $a_t\sim\beh(\cdot\mid s_t)$ 下条件均值为零。BPO 将沿轨迹的 residual 累加成平方回归目标，并证明其零点与 PMD 解一致。

理论上先对 residual 平方损失求梯度；本文件不把 BPO 的 clip、二元 KL 近似或具体 mismatch weight 纳入推导。对逐 prefix 的 token-level residual，完整 reverse KL 的导数是
\begin{equation}
\nabla_\theta\bigl[\log\rho(a)+\KL(\beh\Vert\cand)\bigr]= g(a)-\E_\beh[g(a)].
\label{eq:bpo-score-centering}
\end{equation}
因此 BPO 的未线性化梯度天然包含行为测度下的 score centering；下一章证明它与 PMD-Part 的差异恰好是一个 action-independent 常数乘以行为 score 均值。

\chapter{梯度的偏差与方差}
\label{ch:bias-variance}

\section{估计对象必须先固定}

固定 prefix $s$，令 $g(a)=\nabla_\theta\log\cand_\theta(a\mid s)$、$u(a)=\log(\cand_\theta(a\mid s)/\beh(a\mid s))$，并令 $\rho(a)=e^{u(a)}$。以下区分三个不同的随机量：

\begin{enumerate}[label=(\roman*)]
    \item 直接 KL 镜像目标的梯度 $\nabla F_s$；
    \item 行为测度下回归损失的梯度 $-\nabla\mathcal L_{\rm Part}$；
    \item BPO 的逐 prefix 残差损失梯度。
\end{enumerate}

三者在精确镜像解处共享零点，但只有第一个是 $F_s$ 的梯度。偏差必须相对于明确的目标定义；把行为测度下的回归梯度称为 ``无偏 off-policy policy gradient'' 会混淆两个目标。

\section{MDPO：无偏但承担 action-ratio 的二阶矩}

令 $c(a)=f(s,a)-\frac1\eta u(a)$。MDPO 的单样本估计量为
\begin{equation}
\widehat G_{\rm MDPO}=\rho(a)c(a)g(a),\qquad a\sim\beh(\cdot\mid s),
\end{equation}
并且在 $\cand\ll\beh$、$\E_\beh[\rho\lVert cg\rVert]<\infty$ 时
\begin{equation}
\E_\beh[\widehat G_{\rm MDPO}]=\E_\cand[cg]=\nabla F_s.
\end{equation}
因此 action-level IS 本身不产生偏差；若 prefix 来自 $d_\beh$ 而目标要求 $d_\cand$，还必须乘 $W_{<t}=d_\cand(s_t)/d_\beh(s_t)$。这两个密度比修正的是不同测度。

\begin{theorem}[MDPO 梯度的精确偏差--方差分解]
\label{thm:mdpo-exact-mse}
设 $G=\E_\beh[\rho cg]$，批量大小为 $n$，并假设 $\E_\beh[\rho^2c^2\lVert g\rVert^2]<\infty$。则样本均值 $\widehat G_n$ 满足
\begin{align}
\operatorname{Bias}(\widehat G_n)&=0,\\
\E\lVert\widehat G_n-G\rVert^2
&=\frac1n\left(\E_\beh[\rho^2c^2\lVert g\rVert^2]-\lVert G\rVert^2\right).
\end{align}
若 $\lVert g\rVert\leq B_g$、$|c|\leq B_c$，则
\begin{equation}
\operatorname{tr}\operatorname{Cov}(\widehat G_n)
\leq\frac{B_g^2B_c^2}{n}(1+\chi^2(\cand\Vert\beh)).
\end{equation}
\end{theorem}

\begin{proof}
令
\[
X_i=\rho(a_i)c(a_i)g(a_i),
\qquad a_i\stackrel{\mathrm{i.i.d.}}{\sim}\beh,
\qquad \widehat G_n=\frac1n\sum_{i=1}^nX_i.
\]
由 support 条件，$\rho=\cand/\beh$ 在 $\beh$-几乎处处有定义。换测度恒等式给出
\begin{align*}
\E_\beh[X_i]
&=\sum_a\beh(a)\frac{\cand(a)}{\beh(a)}c(a)g(a)\\
&=\sum_a\cand(a)c(a)g(a)=\E_\cand[cg]=G.
\end{align*}
因此
$\E[\widehat G_n]=n^{-1}\sum_i\E[X_i]=G$，样本均值的偏差严格为零。
再令 $Y_i=X_i-G$。独立性和 $\E[Y_i]=0$ 消掉交叉项，故
\begin{align*}
\E\lVert\widehat G_n-G\rVert^2
&=\E\left\lVert\frac1n\sum_iY_i\right\rVert^2\\
&=\frac{1}{n^2}\sum_i\E\lVert Y_i\rVert^2
=\frac1n\left(\E\lVert X_1\rVert^2-\lVert G\rVert^2\right).
\end{align*}
这就是向量均方误差公式。最后，若 $\lVert g\rVert\leq B_g$ 且 $|c|\leq B_c$，则
\[
\E_\beh\lVert X_1\rVert^2
\leq B_g^2B_c^2\E_\beh[\rho^2]
=B_g^2B_c^2\bigl(1+\chi^2(\cand\Vert\beh)\bigr),
\]
其中最后一个等号来自
$\chi^2(\cand\Vert\beh)=\E_\beh[(\rho-1)^2]=\E_\beh[\rho^2]-1$。去掉非负项 $\lVert G\rVert^2$ 即得到协方差迹的上界。
\end{proof}

在自回归序列中，$W_{\leq t}=\prod_{k\leq t}\rho_k$ 的二阶矩可以逐步展开。给定 prefix $y_{<t}$，有
\[
\E_\beh[\rho_t^2\mid y_{<t}]
=\sum_a\beh(a\mid y_{<t})
\left(\frac{\cand(a\mid y_{<t})}{\beh(a\mid y_{<t})}\right)^2
=1+\chi^2\bigl(\cand(\cdot\mid y_{<t})\Vert\beh(\cdot\mid y_{<t})\bigr).
\]
因为 $W_{\leq t}=W_{<t}\rho_t$，塔式法则给出
\begin{align*}
\E_\beh[W_{\leq t}^2]
&=\E_\beh\left[W_{<t}^2\E_\beh[\rho_t^2\mid y_{<t}]\right]\\
&=\E_\beh\left[W_{<t}^2\left(1+\chi^2(s_t)\right)\right].
\end{align*}
若所有可达 prefix 都满足 $c_{\rm lo}\leq\chi^2(s)\leq c_{\rm hi}$，则递推归纳得到
\begin{equation}
(1+c_{\rm lo})^t\leq\E_\beh[W_{\leq t}^2]\leq(1+c_{\rm hi})^t.
\end{equation}
这给出了 prefix IS 方差随修正长度增长的明确阶数。

再考虑完整权重 $W=W_{\leq t}W_{>t}$。在条件 $y_{\leq t}$ 下，后缀权重的均值为一：$\E[W_{>t}\mid y_{\leq t}]=1$，因此
$\E[W\mid y_{\leq t}]=W_{\leq t}$。全方差公式于是给出
\begin{equation}
\label{eq:prefix-total-variance}
\begin{aligned}
\operatorname{Var}(W)
&=\operatorname{Var}(\E[W\mid y_{\leq t}])
 +\E[\operatorname{Var}(W\mid y_{\leq t})]\\
&=\operatorname{Var}(W_{\leq t})
 +\E[W_{\leq t}^2\operatorname{Var}(W_{>t}\mid y_{\leq t})].
\end{aligned}
\end{equation}
第二项非负；只要 prefix 之后存在策略比率不恒等于一的可达状态，它就严格为正。这说明后缀权重只能增加方差，不能抵消 prefix 权重已经产生的方差。

\section{未线性化 BPO：与 PMD-Part 的梯度差异定理}

BPO 的逐 prefix 残差（取 $f=A^\beh$，故 $\E_\beh[f\mid s]=0$）写成
\begin{equation}
\delta(a)=\eta f(a)-u(a)-\KL(\beh\Vert\cand).
\label{eq:bpo-delta}
\end{equation}
因为 $\KL(\beh\Vert\cand)=-\E_\beh[u]$，有 $\E_\beh[\delta]=0$。理论 BPO 损失为
\begin{equation}
\mathcal L_{\rm BPO}^{\rm tok}=\frac{1}{2\eta}\E_\beh[\delta(a)^2].
\end{equation}
对完整 reverse KL 求导时
\begin{equation}
\nabla_\theta\KL(\beh\Vert\cand)=-\E_\beh[g(a)]= -\bar g,
\qquad \bar g:=\E_\beh[g(a)],
\end{equation}
从而
\begin{equation}
\nabla_\theta\delta(a)=-(g(a)-\bar g).
\label{eq:bpo-centered-score}
\end{equation}

\begin{theorem}[未线性化 BPO 与 PMD-Part 的精确梯度差异]
\label{thm:bpo-part-equivalence}
设 $f=A^\beh$ 满足 $\E_\beh[f\mid s]=0$，$\log Z_f$ 使用精确配分函数，target、$\beh$ 与访问测度均停止梯度。定义
\begin{equation}
h(a)=\eta f(a)-\log Z_f,\qquad q(a)=h(a)-u(a).
\end{equation}
则
\begin{equation}
\delta(a)=q(a)+c_s,\qquad c_s=\log Z_f+\E_\beh[u],
\end{equation}
且
\begin{equation}
-\eta\nabla\mathcal L_{\rm BPO}^{\rm tok}
=\E_\beh[\delta(g-\bar g)]
=\E_\beh[qg]+c_s\bar g
=-\nabla\mathcal L_{\rm Part}^{(\eta)}+c_s\bar g,
\label{eq:bpo-part-exact}
\end{equation}
其中 $\bar g=\E_\beh[g]$，$\mathcal L_{\rm Part}^{(\eta)}=\frac12\E_\beh[q^2]$ 是把温度写成 $1/\eta$ 的 PMD-Part 损失。因此二者的梯度相同当且仅当 $c_s\bar g=0$；一般情况下并不相同。
\end{theorem}

\begin{proof}
先把两个残差都写成同一组基本量。由于 $f$ 是行为优势，
$\E_\beh[f]=0$；又因为 $u=\log(\cand/\beh)$，有
\[
\KL(\beh\Vert\cand)
=\E_\beh\left[\log\frac{\beh}{\cand}\right]
=-\E_\beh[u].
\]
所以 BPO 残差逐点为
\[
\delta=\eta f-u-\KL(\beh\Vert\cand)
=\eta f-u+\E_\beh[u].
\]
PMD-Part 残差是 $q=\eta f-\log Z_f-u$，两式相减得到
\[
\delta-q=\log Z_f+\E_\beh[u]=c_s.
\]
这里 $c_s$ 只依赖 prefix $s$，不依赖 action $a$。同时
\[
\E_\beh[\delta]
=\eta\E_\beh[f]-\E_\beh[u]+\E_\beh[u]=0.
\]

接着对平方损失求导。因为 target、行为策略和访问测度停止梯度，只有 $\delta$ 依赖 $\theta$，故
\[
\nabla_\theta\mathcal L_{\rm BPO}^{\rm tok}
=\frac1\eta\E_\beh[\delta\nabla_\theta\delta].
\]
对式 \eqref{eq:bpo-delta} 求导，并使用
$\nabla_\theta u=g$ 与
$\nabla_\theta\KL(\beh\Vert\cand)=-\bar g$，得到
\[
\nabla_\theta\delta=-g+\bar g=-(g-\bar g).
\]
因此
\begin{align*}
-\eta\nabla\mathcal L_{\rm BPO}^{\rm tok}
&=\E_\beh[\delta(g-\bar g)]\\
&=\E_\beh[\delta g]-\E_\beh[\delta]\bar g\\
&=\E_\beh[\delta g]\\
&=\E_\beh[(q+c_s)g]\\
&=\E_\beh[qg]+c_s\E_\beh[g]\\
&=\E_\beh[qg]+c_s\bar g.
\end{align*}
另一方面，PMD-Part 的损失为
$\mathcal L_{\rm Part}^{(\eta)}=\frac12\E_\beh[q^2]$，所以
$-\nabla\mathcal L_{\rm Part}^{(\eta)}=\E_\beh[qg]$。代入即可得到式 \eqref{eq:bpo-part-exact}。
注意这里用到的是残差的行为测度均值 $\E_\beh[\delta]=0$；不能把 $\E_\beh[g]$ 误写成零。score 的零均值恒等式是 $\E_\cand[g]=0$，因为 score 是相对于候选策略而非行为策略取期望。
\end{proof}

二者只在 $c_s\bar g=0$ 时退化为相同梯度，例如锚点 $\cand=\beh$、可实现根处，或参数化恰好使 $\bar g=0$。一般离开锚点后，BPO 的 score centering 会留下 $c_s\bar g$ 这一额外项。若 $f$ 不是优势而有非零行为均值，必须先把 $f$ 中心化，否则 residual 与 PMD-Part 的 target 不再只差常数。若把 reverse KL 近似成二元项、停止其梯度、加入 clip 或使用不精确的 $Z_f$，式 \eqref{eq:bpo-part-exact} 也不再成立，只能视为近似 PG surrogate。
\section{为什么同为 token-level 仍然不等价}
\label{sec:bpo-part-intuition}

token-level 只说明二者都在固定 prefix $s$ 上处理条件分布；它没有规定必须使用同一个参数空间度量。PMD-Part 回归的是带有确定常数项 $-\log Z_f(s)$ 的完整 log-ratio：
\[
q(a)=\underbrace{\eta f(a)-\log Z_f(s)}_{h(a)}-u(a).
\]
因此它的平方损失直接惩罚 action-independent 的常数误差，梯度为 $\E_\beh[qg]$。BPO 使用的是 reverse-KL 中心化后的 residual：
\[
\delta(a)=\eta f(a)-u(a)+\E_\beh[u]
=q(a)+c_s,
\qquad c_s=\log Z_f(s)+\E_\beh[u].
\]
BPO 的目标只关心 $u(a)-\eta f(a)$ 在行为 action 测度下的中心化部分，因而沿着所有 action 同时平移 $u$ 的方向不会产生同样的惩罚。

真正产生梯度差异的是对 BPO reverse KL 的求导。逐点求导给出
\[
\nabla_\theta\delta(a)=-(g(a)-\bar g),
\qquad \bar g=\E_\beh[g].
\]
代入平方损失后，残差的行为均值为零，于是
\[
-\eta\nabla \mathcal L_{\rm BPO}
=\E_\beh[\delta(g-\bar g)]
=\E_\beh[\delta g]
=\E_\beh[qg]+c_s\bar g.
\]
PMD-Part 从一开始就把 $\log Z_f$ 当作固定 target 常数，不会产生 $c_s\bar g$ 这一项。换句话说，差异不是来自 token-level 与 sequence-level 的访问测度，也不是来自 clip 或线性化；它来自两个平方回归问题对 action-independent 方向的处理不同，以及 BPO 对 reverse KL 求导产生的行为 score centering。

两者仍然共享同一个可实现根：在 $u=h$ 时，$q=0$、$c_s=0$ 且 $\delta=0$。共享根只说明最优解一致，不说明离开根以后向量场一致。以二动作 logit 参数化为例，若 $\beh(1)=m$、$\cand_\theta(1)=p$，则
\[
g(1)=1-p,\qquad g(0)=-p,qquad \bar g=m-p.
\]
只要 $p\neq m$ 且 $c_s\neq0$，就有 $c_s\bar g\neq0$，BPO 和 PMD-Part 的更新方向严格不同。这一差异即使在有限 action、精确配分函数和完整 reverse KL 下仍然存在。

\section{PMD-Part 的投影偏差与 BPO 的中心化方差}

设策略类受限为 $\Pi$。PMD-Part 的 population 解为
\begin{equation}
\theta_{\rm Part}^*=\argmin_{\theta\in\Pi}\E_{d_\beh,\beh}[(u_\theta-h)^2],
\end{equation}
而 BPO 的逐 prefix 解为
\begin{equation}
\theta_{\rm BPO}^*=\argmin_{\theta\in\Pi}\E_{d_\beh}\operatorname{Var}_{a\sim\beh}[u_\theta(a)-\eta f(a)].
\end{equation}
二者在可实现时拥有同一零点；不可实现时，BPO 不惩罚 action-independent 的误差，因此它允许更大的常数方向自由度，而 PMD-Part 通过精确的 $\log Z_f$ 固定该常数。共享参数网络下，$d_\beh$ 同时决定状态间投影误差如何分配。

\begin{proposition}[prefix IS 的偏差--方差阶梯]
\label{prop:prefix-bias-variance}
对终端或未来回报 $R$，行为样本下的 token-level 不加前缀权重估计量，其期望与目标策略梯度的差可分解为
\begin{equation}
\sum_s(d_\cand-d_\beh)(s)\sum_a\nabla\cand(a\mid s)A^\beh(s,a)
+\sum_s d_\cand(s)\sum_a\nabla\cand(a\mid s)(A^\cand-A^\beh)(s,a).
\end{equation}
乘 $W_{<t}$ 后第一项恰好消失；再乘后缀 $W_{>t}$ 才能修正第二项，但其额外方差正是式 \eqref{eq:prefix-total-variance} 的第二项。
\end{proposition}

\begin{proof}
第一项来自把 $d_\cand$ 替换为 $d_\beh$，第二项来自把 $A^\cand$ 替换为可估计的 $A^\beh$。前缀密度比将行为 prefix 测度换成 $d_\cand$，所以只消掉第一项；后缀比率不改变已经使用的优势估计，却引入条件二阶矩，故只能修正价值滞后而不能降低方差。
\end{proof}

\begin{remark}[可加残差为何能绕开乘积]
若信号写成逐 token 鞅差之和 $D=\sum_tD_t$，且 $\E[D_t\mid s_t]=0$，则交叉项消失并有
\begin{equation}
\E[D^2]=\sum_t\E[D_t^2].
\end{equation}
这正是离策略修正文档中 ``可加泛函的换测度界'' 的核心：回归型 PMD/BPO 利用逐点最优性或中心化残差，把序列乘积权重替换成逐步二阶量；代价是目标从真策略梯度改成行为测度下的投影问题。

\end{remark}

\begin{proposition}[可加 BPO 残差的损失估计方差]
\label{prop:bpo-loss-variance}
设轨迹残差可写成 $\delta=\sum_{t=1}^{T}e_t$，其中 $e_t$ 是关于 prefix 过滤的鞅差，且 $|e_t|\leq B_e$。则
\begin{equation}
\E[\delta^2]=\sum_{t=1}^{T}\E[e_t^2],
\qquad
\E[\delta^4]\leq T^2B_e^2\sum_{t=1}^{T}\E[e_t^2].
\end{equation}
对 $n$ 条独立轨迹的平方残差损失估计量
$\widehat{\mathcal L}=n^{-1}\sum_i\delta_i^2/(2\eta)$，有
\begin{equation}
\operatorname{Var}(\widehat{\mathcal L})
\leq \frac{T^2B_e^2}{4\eta^2n}
\sum_{t=1}^{T}\E[e_t^2].
\end{equation}
因此中心化残差的统计方差按 token 二阶量相加，而不是按 sequence ratio 的二阶矩相乘。
\end{proposition}

\begin{proof}
鞅差正交给出第一式。由 Cauchy--Schwarz，
$\delta^2=(\sum_te_t)^2\leq T\sum_te_t^2\leq T^2B_e^2$，故
$\delta^4\leq T^2B_e^2\delta^2$。独立样本均值的方差为单样本方差除以 $n$，再用
$\operatorname{Var}(\delta^2)\leq\E[\delta^4]$ 即得结论。
\end{proof}

\section{BPO 论文的训练预算}
\label{sec:bpo-implementation}

BPO 论文源码的主实验写明：每个 training step 先生成 256 个 prompt、每个 prompt 16 个 response，共 4096 条 response；再划分为 8 个、每个 512 条 response 的 mini-batch，执行 8 次 optimizer updates。主实验运行 400 个 training steps，即 3200 次 optimizer updates；附录消融运行 1000 个 training steps。论文没有按 residual norm 或 mirror-subproblem gap 停止的 inner loop，因此这些是固定更新预算，不是子问题收敛步数。

\section{OpenKimi/PMD 的训练预算}
\label{sec:openkimi-implementation}

OpenKimi 的 PMD loss 默认先对完整 response 的 token log-ratio 求和，再把 sequence log-ratio broadcast 到 response 内 token。\par Qwen2.5-7B math recipe 设置 `PPO\_EPOCHS=1`、`train\_batch\_size=512`、`actor.ppo\_mini\_batch\_size=32`，所以静态 batch 下每个 outer step 约有 $512/32=16$ 个 mini-batch 更新。代码没有 inner residual stopping 或 PMD gap 检验；`total\_training\_steps=3000` 是 outer steps 上限。

\section{经典 MDPO 的训练预算与 IS}
\label{sec:mdpo-implementation}

经典 MDPO on-policy 代码默认 `sgd\_steps=5`，MuJoCo README 的推荐示例使用 10。一个 rollout batch 固定后，对同一批数据重复执行该数量的 policy optimizer updates，再刷新 old/new anchor；没有根据 mirror residual 自适应停止。

off-policy 代码的 README 暴露 `sgd\_steps=1000`，但当前训练循环实际写为 `for grad\_step in range(1)`，原本的 `int(self.gradient\_steps)` 被注释。因此每个 train event 实际只执行一次 actor/critic update；`gradient\_steps` 主要影响 target/anchor policy 同步周期。实现使用 replay 状态测度和 action-level policy gradient，不能解释为完整的 prefix-IS 求解。

\section{比较时应报告的指标}
\label{sec:reporting}

为了比较四种方法，实验至少应固定同一 rollout batch，并记录：每个 inner update 的 mirror loss、log-ratio residual norm、$\KL(\cand_\theta\Vert\beh)$、梯度范数、ratio 的均值与二阶矩、中心化 residual 的条件方差，以及 prefix coverage。这样才能区分“做了更多 optimizer steps”和“真正接近 token-level mirror optimum”。

\chapter{结论与 MirrorOPD 的边界}
\label{ch:conclusion}

从同一个 token-level Gibbs 最优解出发，PMD-Part 是精确 log-ratio 回归，PMD-Mean 是中心化回归后的 Lambert-$W$ 投影，MDPO 是带 action IS 的直接 KL 正则化 policy gradient。BPO 的完整 reverse-KL 平方 residual 在未线性化时产生中心化 score 梯度；它与 PMD-Part 共享可实现时的最优点，但一般相差 $c_s\bar g$，因此不能把二者的梯度直接视为相同。线性化、二元 KL 化简和工程截断属于后续近似，本文件没有把它们作为理论等价的前提。

本文件暂不推导 OPD 的完整 off-policy correction 或 KL 系数调度。后续 MirrorOPD 需要先选择局部即时 reward 目标还是完整加性回报目标，再决定是否引入 prefix IS、是否采用 Part/Mean 投影，以及如何用 Natural Gradient 控制学生策略与教师策略的距离。

# Top-J 支持重叠诊断

## 三组比较对象

沿用旧书符号，$\pi_k$ 是本轮冻结 anchor，$\pi_{k,n}$ 是 inner 更新前 student，$\pi_T$ 是 teacher。令它们在同一个 prefix $s$ 的原生 Top-J 集合分别为 $H_k(s)$、$H_{k,n}(s)$ 和 $H_T(s)$。本次实现令 $J$ 等于配置 `distillation_loss.topk`；将集合大小与 inner 次数区分，本文把 inner 次数记作 $N_{\mathrm{inner}}$。

对任意一对集合 $H_A,H_B$ 定义

$$
I_{AB}(s)=\lvert H_A(s)\cap H_B(s)\rvert,\qquad U_{AB}(s)=\lvert H_A(s)\cup H_B(s)\rvert=2J-I_{AB}(s),
$$

$$
O_{AB}(s)=\frac{I_{AB}(s)}{J},\qquad \mathcal J_{AB}(s)=\frac{I_{AB}(s)}{U_{AB}(s)}.
$$

三个比较对象分别是 student–teacher、student–anchor 和 anchor–teacher。student–teacher 是主要教师对齐诊断，student–anchor 测量本轮更新的集合漂移，anchor–teacher 给出本轮开始时的教师对齐状态。首 inner 满足 student=anchor，因此 student–anchor 为 1，student–teacher 等于 anchor–teacher。后两者初始化无需等于 1。

## 字段名称与统计协议

每对集合分别记录以下四个逐 token 字段，`PAIR`取 `student_teacher`、`student_anchor`、`anchor_teacher`：

| 内核字段                                    | 定义              |
| ------------------------------------------- | ----------------- |
| `mirror_overlap_PAIR_intersection_count`    | $I_{AB}$          |
| `mirror_overlap_PAIR_union_count`           | $U_{AB}$          |
| `mirror_overlap_PAIR_intersection_fraction` | $O_{AB}$          |
| `mirror_overlap_PAIR_jaccard`               | $\mathcal J_{AB}$ |

`token_moments` 先汇总有效 response token 的充分统计量，`finalize_token_moments` 再做跨 micro、跨 DP 统计。新字段因此与现有 teacher center 使用同一有效 token 测度。JSONL 前缀自动变成 `mirror/overlap_PAIR_STAT/{mean,std,rms,min,max}`；W&B 均值等映射到 `06_support_mass/{inner,outer}_overlap_PAIR_STAT/...`，极值仍遵循现有 `90_detail_extrema` 分类。

归约层另记录 `mirror/overlap_PAIR_pooled_jaccard`，定义为有效 token 交集计数总和除以并集计数总和。它不同于逐 tokenJaccard 的 mean：J4 下一个完全相同、一个不重叠，mean 为 0.5、pooled 为 1/3。两者各有独立名称。

旧字段 `mirror_support_overlap` 保留，逐项等于 `mirror_overlap_student_anchor_intersection_fraction`。它保证现有报表读取兼容，同时新增名称明确区分三种比较对象。旧缓存若缺 `mirror_teacher_topk_ids`，只产生可定义的 student–anchor 新字段，缺失 teacher 字段保持缺失；不写出虚假的零重叠。

J=0 是完整关闭 Top-J 支持诊断的边界配置。本实现把两种 count 和两种 fraction 都记 0；此时 fraction 是工程约定值。J 等于完整词表大小时，三个集合均为完整词表，intersection_count=union_count=J，两种 fraction 均 1。

Top-J 成员选择沿用现有 `torch.topk`。并列 logits 处的成员采用该算子的原生选择，集合比较忽略返回顺序。不同设备或执行版本对边界并列项可选择不同成员，因此重复实验应固定计算环境；这些字段不能把浮点近并列造成的成员变化解释成概率质量发生大幅变化。

## 缓存和部署契约

教师在 outer 起点对同一 prefix 做一次前向。`complete_mirror_teacher_cache` 除原有 anchor 选出 token 的 teacher logprob 外，新增教师自己的 Top-J token IDs，字段为 `mirror_teacher_topk_ids`、dtype 为 int64、形状为 prefix 维度加 J。无效 prefix 位置置 0。teacher IDs 与 teacher centers 一样冻结，所有 inner 复用；student 的原生 Top-J 每次 inner 前向重新计算。

第一方 `integrations/verl/fsdp.py` 在 teacher scoring 阶段返回该缓存，在 loss 阶段读取。仓库上游补丁更新 trainer 的 teacher 输出字段列表与 padding/no-padding 传输列表，让新增 int64 缓存完整走过实际 worker 链路。算法 loss、已有 centers、IS 与 reward 公式保持相同，新增字段全部无梯度。

缓存额外空间为 $8NJ$ 字节，其中 N 是本轮有效及传输 prefix 位置数。若 N=400000、J=16，未计张量封装的全局新增 ID 存储约 48.8MiB；四 DP 均分后每 rank 约 12.2MiB。实际 padding 布局还可能保存无效位置，应以运行时 tensor 大小核实。teacher 新增一次原生 Top-J 计算，三对交集各需要 J×J 布尔比较；没有新增 teacher 前向。

本次只在独立 worktree 准备源码与补丁，没有同步到正在训练的 backend。部署需一起同步第一方 cache/loss/adapter 与更新后的 TA-OPD patch；仅同步第一方代码不能使旧 trainer 转发新的 teacher 字段。

## 与 MD-OPD 的策略选择区分

MD-OPD `top_k_strategy=intersection/union/only_stu` 选择训练候选支持及其权重；其 `top_k_overlap_ratio` 是 student 与 teacher 原生 Top-K 的 intersection/K。这两个概念互相独立。MirrorOPD 本次新增的 union_count 与 Jaccard 属于观测量，不选择 loss 支持，不开启 union/intersection 训练策略。

例如两个四元素集合交集含两个 token，intersection_fraction=0.5，union_count=6，Jaccard=1/3。把 loss 支持选成它们的并集不会使原生集合 overlap 自动变 1；统计比较对象仍是两个原生集合。

## 验证

`tests/test_topk_overlap.py` 覆盖三对集合、已知交集与并集、集合排列不变性、并列 logits、J=0 与 J=完整词表、变长 response mask、无效 prefix 置零、全 token 加权归约、teacher 缓存冻结以及新旧诊断对 loss/gradient 不变性。

`tests/test_upstream_mirror_wiring.py` 在重放新补丁的隔离 backend 上执行真实 trainer 方法及 padding 函数，核对 teacher Top-J IDs 形状、dtype 与无效位置。CPU 模型链路和训练统计回归同时核对更新后的 cache/loss 契约。GPU 分布式吞吐与显存影响需要后续 canary 测量。

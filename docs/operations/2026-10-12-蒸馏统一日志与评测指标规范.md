## 数学对象与符号字典

### 冻结前缀、动作与参数

第 $k$ 轮冻结锚点为 $\pi_k$，教师为 $\pi_T$，第 $n$ 次 inner 更新前学生为 $\pi_{k,n}=\pi_{\theta_{k,n}}$，满足 $\pi_{k,0}=\pi_k$。当前位置前缀为 $s_t=(x,y_{<t})$，动作 $a_t=y_t$ 是在该前缀下实际生成的下一 token。当前书的 $q_k,p_{k,n},t$ 与这三个策略逐项相同：

$$
q_k=\pi_k,\qquad p_{k,n}=\pi_{k,n},\qquad t=\pi_T.
$$

本规范用 $N$ 表示每轮 inner optimizer 更新数、$J$ 表示诊断 Top-$J$头部大小、$R$ 表示每题评测生成数、$M_k$ 表示本轮有效回答 token 总数。运行名中的 `j16` 实际表示 $N=16$，配置 Top-k=16 表示 $J=16$；图例应分别写出。

| 符号                 | 数学定义                                 | 规范对象名             | 单位与方向                                  |
| -------------------- | ---------------------------------------- | ---------------------- | ------------------------------------------- |
| $U_{k,n}$            | $\log(\pi_{k,n}/\pi_k)$                  | `u_student_anchor`     | nat，学生减锚点 log-prob                    |
| $r_k$                | $\log(\pi_T/\pi_k)$                      | `r_teacher_anchor`     | nat，冻结教师减锚点                         |
| $r^{cur}_{k,n}$      | $\log(\pi_T/\pi_{k,n})=r_k-U_{k,n}$      | `r_teacher_student`    | nat，教师减当前学生                         |
| $\omega_{k,n}$       | $\pi_{k,n}/\pi_k=e^{U_{k,n}}$            | `omega_student_anchor` | 无量纲，条件动作概率比                      |
| $w_{k,n}$            | $\pi_{k,n}/\beta_k$                      | `w_student_behavior`   | 无量纲，真实行为分布 $\beta_k$ 的 IS 比率   |
| $\mathcal K_k^T$     | $\operatorname{KL}(\pi_k\Vert\pi_T)$     | `kl_anchor_teacher`    | nat，锚点到教师                             |
| $\mathcal K_{k,n}^S$ | $\operatorname{KL}(\pi_k\Vert\pi_{k,n})$ | `kl_anchor_student`    | nat，锚点到学生                             |
| $K_{pT,k,n}$         | $\operatorname{KL}(\pi_{k,n}\Vert\pi_T)$ | `kl_student_teacher`   | nat，当前学生到教师                         |
| $K_{pq,k,n}$         | $\operatorname{KL}(\pi_{k,n}\Vert\pi_k)$ | `kl_student_anchor`    | nat，学生到锚点，与 $\mathcal K^S$ 方向相反 |
| $\psi_{k,n}$         | $\nabla_\theta\log\pi_{k,n}(a\mid s)$    | `score_vector`         | 参数坐标相关                                |
| $\bar\psi_{k,n}$     | $\mathbb E_{\pi_k}\psi_{k,n}$            | `anchor_mean_score`    | 不要求为零                                  |
| $c^{score}_{k,n}$    | $g=\mathbb E[c^{score}\psi]$             | `score_coefficient`    | 最小化目标的下降梯度系数                    |
| $A^{score}_{k,n}$    | $-c^{score}_{k,n}$                       | `ascent_advantage`     | 同一更新改写为策略上升时的优势              |
| $\eta$               | 镜像目标中的系数                         | `mirror_eta`           | 无量纲，与 optimizer lr 不同                |
| $\rho$               | $\pi_{k+1}=(1-\rho)\pi_k+\rho\pi_{k,N}$  | `sync_rho`             | 概率空间同步系数，hard sync 为 1            |

旧书第二章还用 $\rho_{k,n}$ 表示教师与当前学生 log-ratio；本规范统一写成 $r^{cur}_{k,n}$，保留无下标 $\rho$ 的同步含义。PPO 概率比率使用 $w$ 或 $\omega$。参数 EMA 另外记录 `parameter_ema_decay`，其参数空间操作不能被写成精确概率混合。

旧书 K4 估计器的 $c=p/\operatorname{sg}(p)$ 与下降系数重名。本规范固定写 $c^{score}$；K4 量使用 `estimator/k4_score_multiplier`，并附 $p/\operatorname{sg}(p)$ 的公式。所有 log 为自然对数，KL、entropy、NLL 使用 nat；展示 bits 必须显式除以 $\log2$ 并更改 units。

### 访问测度与归约

有效长度 $H_i$ 包含实际 EOS、排除 prompt 与 padding；预算终止保留实际最后 token，不伪造 EOS。旧书固定的 token 访问测度为

$$
d_k(A)=\frac{\mathbb E_{\tau\sim\pi_k}\sum_{t=1}^{H(\tau)}\mathbf1\{s_t\in A\}}{\mathbb EH(\tau)}.
$$

总体动作联合测度为 $d_k(s)\pi_k(a\mid s)$。冻结 batch 的经验平均写成

$$
M_k=\sum_{i=1}^{B}H_i,\qquad \langle z\rangle_k=\frac1{M_k}\sum_i\sum_{t=1}^{H_i}z(s_{i,t},a_{i,t}).
$$

长回答贡献更多 token。每题先除以 $H_i$ 再平均会改变目标：未来长度取决于当前动作，不能保持同一条件动作测度却替换归约。有限 batch 的随机分母使比率估计一般不是总体目标严格无偏估计；独立轨迹与可积条件下是一致估计。

规范归约标签为 `response_token_occurrence`、`response`、`prompt`、`device`、`optimizer_update`。每条字段描述必须声明标签。训练 signal/KL/entropy 按 token，数学正确率按 prompt 或 response，设备显存按 device；不能把这些量以一个全局 `mean` 混合解释。

## 六类算法的目标、梯度与可记录量

### OPD 与 Token-IS OPD

固定当前前缀测度，OPD 最小化

$$
L_{OPD}=\mathbb E_{s\sim d_k}\operatorname{KL}(p(\cdot\mid s)\Vert t(\cdot\mid s)).
$$

对单一前缀求导，使用概率归一化导数为零：

$$
\begin{aligned}
\nabla L_{OPD}(s)&=\sum_a p_a(\log p_a-\log t_a+1)\psi_a\\
&=\mathbb E_p[-r^{cur}\psi],\qquad \mathbb E_p\psi=0.
\end{aligned}
$$

所以动作无关 baseline $b_{pT}(s)$ 不改变总体梯度。fresh rollout 的 On-policy OPD 系数为 $c=-(r^{cur}+b_{pT})$；一般行为策略采样的 Token-IS 系数为 $c=-w(r^{cur}+b_{pT})$。测度校正只改变动作积分，不改变冻结前缀 $d_k$。

严格 on-policy 要求每次 optimizer 更新前 fresh rollout。MirrorOPD 正式 OPD 为 $N=1$，权重一；若同模式复用 batch 做多次更新，后续动作不再来自当前学生，不能继续称严格 on-policy。MD-OPD 普通 sampled direct 路径还经过 vanilla PPO ratio/clipping，是否触发clip、是否包含其他reward必须按resolved config 分别记录。

### 共同镜像子问题与 MDPO

给定冻结 reward $r_k$，镜像负目标为

$$
L_{MDPO}(p)=\frac1\eta\operatorname{KL}(p\Vert q)-\mathbb E_p r_k
=\operatorname{KL}(p\Vert t)+(\eta^{-1}-1)\operatorname{KL}(p\Vert q).
$$

其 Gibbs target 与配分函数为

$$
Z_k(s)=\mathbb E_q e^{\eta r_k},\qquad
\pi_k^*(a\mid s)=\frac{q_a e^{\eta r_k(a)}}{Z_k(s)}=\frac{q_a^{1-\eta}t_a^\eta}{Z_k(s)}.
$$

代入目标分解得到

$$
L_{MDPO}(p)=\frac1\eta\operatorname{KL}(p\Vert\pi_k^*)-\frac1\eta\log Z_k.
$$

梯度逐项求导并换测度：

$$
\begin{aligned}
\nabla L_{MDPO}&=\mathbb E_p[(U/\eta-r_k+1/\eta)\psi]\\
&=\mathbb E_q[\omega(U/\eta-r_k)\psi].
\end{aligned}
$$

第二行删去 $\mathbb E_p\psi/\eta=0$。生产采用停止梯度系数乘 log-prob 承载最后一行。原始 IS integrand 直接 autograd 在有限 batch 多出 $\langle\omega\psi\rangle_k/\eta$；总体为零的控制变量与有限样本具体梯度不能混为一谈。

MDPO 系数 mean 本身等于当前动作 batch 的镜像 IS 目标数值估计：

$$
\widehat L_{MDPO,IS}=\langle\omega(U/\eta-r_k)\rangle_k=\langle c^{score}\rangle_k.
$$

该量可以从 MDPO 原始 coefficient mean 精确恢复，字段标为 `objective/mdpo/is_train_batch`，但这项等式不适用于 BPO 或 OPD。它与 score surrogate $\langle c\log p\rangle_k$ 数值不同；固定数据复用及 adaptive 参数又限制其总体估计解释。

### PMD-Part、PMD-Mean 与 BPO

三类残差分别为

$$
\begin{aligned}
R^{Part}&=U-\eta r_k+\log Z_k,\\
G_k&=\eta(r_k+\mathcal K_k^T),\qquad R^{Mean}=U-G_k,\\
R^{BPO}&=U-G_k+\mathcal K^S_{k,n}.
\end{aligned}
$$

对应目标及下降系数如下。表中期望均含固定 $d_k$，baseline 与 logZ 是每前缀条件量，不是跨前缀全局均值。

| 算法         | 原始最小化目标                               | 实际 score 系数 $c^{score}$ | 动作测度       | 目标最优分布          |
| ------------ | -------------------------------------------- | --------------------------- | -------------- | --------------------- |
| OPD          | $\mathbb E_{d_k}\operatorname{KL}(p\Vert t)$ | $-(r^{cur}+b_{pT})$         | 当前 $p$       | teacher，函数类允许时 |
| Token-IS OPD | 同上                                         | $-w(r^{cur}+b_{pT})$        | 行为 $\beta_k$ | 同上，前缀仍冻结      |
| MDPO         | $\mathbb E_{d_k,p}[U/\eta-r_k]$              | $\omega(U/\eta-r_k)$        | anchor $q$     | Gibbs                 |
| PMD-Part     | $\frac12\mathbb E_{d_k,q}(R^{Part})^2$       | $R^{Part}$                  | anchor $q$     | Gibbs                 |
| PMD-Mean     | $\frac12\mathbb E_{d_k,q}(R^{Mean})^2$       | $R^{Mean}$                  | anchor $q$     | Lambert-$W$投影       |
| BPO          | $\frac1{2\eta}\mathbb E_{d_k,q}(R^{BPO})^2$  | $R^{BPO}/\eta$              | anchor $q$     | Gibbs，完整中心       |

PMD-Part 的 logZ 及 Mean 的 teacher target 在 inner 内冻结，因此平方残差求导直接给 $\mathbb E_q[R\psi]$。BPO 还要保留 student center 导数：

$$
\nabla\mathcal K^S=-\bar\psi,\qquad
\nabla L_{BPO}=\frac1\eta\mathbb E_q[R^{BPO}(\psi-\bar\psi)]
=\frac1\eta\mathbb E_q[R^{BPO}\psi].
$$

最后一步依赖每个前缀精确 $\mathbb E_qR^{BPO}=0$。固定 batch 每前缀仅一个动作时，该条件在经验动作上不恒等成立；生产 PG 与这批动作平方残差的 autograd 不必相同。有限样本复用中的参数依赖该 batch，不能把固定参数独立抽样下无偏推广为每步无条件无偏。

Mean target 通常不能使残差为零。因 $\mathbb E_qG=0$，非恒定 G 有 $\mathbb E_q e^G>1$；拟合 $U=G$ 违反概率归一化。KKT 条件为

$$
U_a-G_a+\lambda e^{U_a}=0,\qquad \sum_aq_ae^{U_a}=1.
$$

令 $V_a=G_a-U_a$，则 $V_ae^{V_a}=\lambda e^{G_a}$，得到

$$
U_a^*=G_a-W_0(\lambda e^{G_a}),\qquad
\pi_k^{*,Mean}(a)=q_a\exp\{G_a-W_0(\lambda e^{G_a})\}.
$$

$\lambda\ge0$ 由归一化确定。Mean 收敛应检查其受约束平方目标与 Lambert-$W$ target，不以到 Gibbs 的距离宣判失败。

`implemented`：MirrorOPD primitive 有 OPD/Token-IS/MDPO/BPO/PMD-Mean，categorical oracle 有 PMD-Part。`proposed`：神经网络生产 PMD-Part 需要完整或明确近似的条件 logZ 缓存；不能仅把 mean center 改名为 partition。

## KL 中心、分区与近似误差

### 方向、支持与精度标签

规范字段名包含方向和精度：`kl/anchor_teacher/full`、`kl/anchor_student/tail_aware_j16`、`kl/student_teacher/action_mc`。在表中简写为 $K^{TA}$；实际完整名字还需指定选支持的策略 `anchor_top_j`、`student_top_j` 或其他真实方式。

设选取支持为 $\mathcal H_k(s)$，尾部为 $\mathcal T_k=\mathcal V\setminus\mathcal H_k$。Tail-aware KL 为

$$
K^{TA}_{qp}=\sum_{a\in\mathcal H_k}q_a\log(q_a/p_a)+q_{\mathcal T}\log(q_{\mathcal T}/p_{\mathcal T}).
$$

完整尾部项逐项分解为

$$
\sum_{a\in\mathcal T}q_a\log(q_a/p_a)=q_{\mathcal T}\log(q_{\mathcal T}/p_{\mathcal T})
+q_{\mathcal T}\operatorname{KL}(q(\cdot\mid\mathcal T)\Vert p(\cdot\mid\mathcal T)).
$$

所以 $K^{full}_{qp}-K^{TA}_{qp}=\delta_S\ge0$，teacher 同理为 $\delta_T\ge0$。聚合 KL 是下界；高 head mass 不独自界定误差小，因为 tail 条件 KL 没有仅依质量的有限上界。选中头部但丢弃尾部的 KL 部分和没有这一非负下界保证，不能命名为 Tail-aware KL。

### 近似对算法的不同作用

MDPO 系数不使用这些 center，Top-$J$只影响诊断和缓存。OPD/Token-IS 的 baseline 是动作无关量，在正确动作测度下即使粗化也不改变总体梯度，但会改变有限样本方差。PMD-Mean 与 BPO 在 anchor 动作测度下使用 teacher center，离开 anchor 后 center 近似会改变总体梯度。

生产 BPO 相对完整中心的偏差为

$$
c_{TA}-c_{full}=-\delta_S/\eta+\delta_T,\qquad
g_{TA}-g_{full}=\mathbb E_{d_k}[(-\delta_S/\eta+\delta_T)\bar\psi].
$$

在 $p=q$ 时 $\bar\psi=0$；离开 anchor 后一般非零。因此 BPO 的 center error 字段属于训练目标近似诊断，MDPO 同名字段属于观测近似诊断，不能统一宣称“Top-k 只影响日志”。

## 三对支持重叠、集合策略与概率质量

### 三个独立比较对象

令 $H^S_{k,n}=\operatorname{Top}_J(\pi_{k,n})$、$H^k=\operatorname{Top}_J(\pi_k)$、$H^T=\operatorname{Top}_J(\pi_T)$。每前缀同时定义

$$
O^{Sk}=|H^S\cap H^k|/J,\qquad
O^{ST}=|H^S\cap H^T|/J,\qquad
O^{kT}=|H^k\cap H^T|/J.
$$

三个规范字段为 `support/student_anchor/overlap_fraction`、`support/student_teacher/overlap_fraction`、`support/anchor_teacher/overlap_fraction`。首 inner $p=q$ 保证 $O^{Sk}=1$，且 $O^{ST}=O^{kT}$，不保证后两者为 1。teacher/anchor 在 inner 冻结，使 $O^{kT}$ 固定；$O^{ST}$ 反映当前 teacher 对齐，$O^{Sk}$ 反映本轮策略漂移。

`implemented`：MirrorOPD 记录 $O^{Sk}$，MD-OPD 记录 $O^{ST}$。`proposed`：两库同时补三对，并统一全局 token 归约。同一前缀的真实 teacher Top-$J$在 MirrorOPD 现有 anchor-head cache 里缺失，仅凭 teacher 在 anchor IDs 上的概率不能恢复 teacher Top-$J$。

例：$J=4$，$H^k=H^S=\{1,2,3,4\}$，$H^T=\{3,4,5,6\}$，则三者为 1、0.5、0.5。两库历史 overlap 初始化不同由比较对象导致，不能据此证明缓存不一致。

### Overlap、Jaccard 与集合操作

对任意等大小集合 A、B，令 $I=|A\cap B|$，则

$$
|A\cup B|=2J-I,\qquad |A\triangle B|=2J-2I,\qquad
\operatorname{Jaccard}(A,B)=\frac{I}{2J-I}=\frac{O}{2-O}.
$$

规范同时记录 intersection count、union count、symmetric-difference count、overlap fraction 和 Jaccard。不同 Top 大小时记录双方大小，不能继续用一个 J 作对称分母。非线性转换 $\mathbb E[O/(2-O)]\ne\bar O/(2-\bar O)$，历史 overlap 均值不能精确恢复全 token Jaccard 均值。

还需区分 prefix 平均 $Jac_{macro}=M^{-1}\sum_i I_i/C_i$ 与合并集合成员计数的 $Jac_{pooled}=\sum_iI_i/\sum_iC_i$。后者等于 $\bar O/(2-\bar O)$，前者一般不等。J4 下一个 prefix 完全相同、一个完全不重叠，macro 为 0.5、pooled 为 1/3。当前内核的 `jaccard/mean` 是 macro，全局 moment 归约另输出 `overlap_PAIR_pooled_jaccard`，不能给两者相同展示名。相同 J 且相同归约权重下，旧全 token O mean 可恢复 pooled；MD-OPD 旧 rank 平均缺 token 分母，不能据它恢复真实 global pooled。

MD-OPD `compute_top_k_reward` 声明的集合策略与当前端到端实现须分别记录。2026-10-12 重新核对 producer/consumer 后，实际状态如下。

| 策略                 | 预期候选集合       | 当前实际候选路径                                 | 状态与解释                                        |
| -------------------- | ------------------ | ------------------------------------------------ | ------------------------------------------------- |
| `only_stu`           | $H^S$              | student IDs，teacher 在这些 IDs 上评分           | 已实现 student 候选路径                           |
| `only_tch`           | $H^T$              | 仍使用 student IDs 与对应概率                    | 声明未完整接线；当前不能代表 teacher-only         |

| `union-intersection` | $H^S\triangle H^T$ | 仅保留 student-only 一侧，缺 teacher-only 一侧   | 未实现完整对称差；修正后命名 symmetric_difference |

候选权重模式为 student_p、teacher_p 或 none。令有效集合 C，$v_a$ 对应 p、t 或 1。归一化模式 $\lambda_a=v_a/\sum_{b\in C}v_b$，未归一化模式 $\lambda_a=v_a$；候选 reward 为 $\lambda_a(\log t_a-\log p_a)$。它是支持受限且可能重归一化的训练信号，不是完整词表反向 KL，也不是 Tail-aware 聚合。规范将 `support_selection`、`candidate_weight_mode`、`candidate_weight_normalized` 和 `top_j_role=metric_only|training_reward` 一起保存。

### 概率质量及历史聚合误差

集合概率质量与集合计数分开。对任意策略 $v\in\{q,p,t\}$ 和任意支持 C，

$$
\operatorname{mass}_v(C)=\sum_{a\in C}v_a,\qquad
\operatorname{overlap_mass}(p,t)=\sum_{a\in\mathcal V}\min(p_a,t_a)=1-\operatorname{TV}(p,t).
$$

完整 probability overlap mass 需要完整共同词表；Top 集合 overlap 无法恢复它。当前 MirrorOPD anchor_head_mass 为 $q(H^k)$，student_head_mass 为 $p(H^k)$，后者不是 $p(H^S)$。规范名字包含质量来源策略和支持选取策略，例如 `support/student/mass_on_anchor_top_j`。

MD-OPD teacher worker 在每 rank 先求 $O_r=\sum_iI_{ri}/(JN_r)$，driver 再算 rank 均值 $R_{DP}^{-1}\sum_rO_r$。规范需要全 token 平均 $\sum_rN_rO_r/\sum_rN_r$。10 与 90 token 两个 rank，overlap 为 0.2 与 0.8 时，历史值 0.5，规范值 0.74。historical mass/top_k_reward_mean同一scalar链路也有此限制；缺rank分子分母时无法精确重建。

MD-OPD 归档 `mdxt04lm__history.csv` 首行 `_step=1` 的 overlap 为 0.8200660354，student mass 为 0.9748263591，teacher mass 为 0.9734799819。它们是该库定义的 teacher-student 对象及 rank 归约，不能直接与 MirrorOPD 首 inner 的 student-anchor overlap=1 叠加。

## IS、ESS 及动作与轨迹的区别

动作 IS 恒等式为 $\mathbb E_{\beta_k}[wh\mid s]=\mathbb E_p[h\mid s]$。只要目标前缀测度仍为 $d_k$，这就是目标要求的校正。若改成当前 student 新 rollout 的整条轨迹目标，前缀校正涉及此前比率乘积；不能以单 token 比率代替。

对一次 inner 前向的有效 token 权重，

$$
\operatorname{ESS}=\frac{(\sum_jw_j)^2}{\sum_jw_j^2},\qquad
f_{ESS}=\frac{ESS}{M_k}=\frac{\bar w^2}{\overline{w^2}}=\frac1{1+CV(w)^2}.
$$

总体 $\mathbb E_{d_k,q}\omega=1$ 时，大样本固定参数极限满足

$$
f_{ESS}\to\frac1{1+\mathbb E_{s\sim d_k}\chi^2(p(\cdot\mid s)\Vert q(\cdot\mid s))}.
$$

同一回答内 token 相关，参数还受复用 batch 影响，ESS 不等于独立样本数。它不约束跨 outer 累计漂移、不诊断 task 能力、不校正 prefix 分布，也不单独决定梯度方差。MDPO 梯度还乘 $(U/\eta-r_k)\psi$；该项的规模与相关性同样重要。

BPO/Mean/Part在anchor测度优化，不将 $\omega$ 乘进梯度。规范保留 `omega/ess_fraction` 作漂移诊断，同时 `applies_action_is=false`；不能把它称为这三方法实际应用的 IS 权重 ESS。一般行为与 anchor 不同时，另记 w/ESS，不能用 omega 冒充 w。

MirrorOPD raw token moment 合并后计算 ESS 是 implemented。outer 的 ESS fraction 是 inner 标量的算术平均，不是池化所有 inner 权重得到的 ESS；outer std/RMS也是各inner对应量的平均，不能反解池化分布。跨inner汇总应使用单独 `inner_aggregate` 字段和 `mean_over_updates` 标签。

## Inner 收敛、目标进展与任务质量

### 系数与 student center 不构成通用收敛阈值

MDPO 在 Gibbs 解处 $U^*=\eta r_k-\log Z_k$，从而

$$
c^{score,*}=-\omega^*\log Z_k/\eta,\qquad
\mathbb E_q[c^{score,*}\psi^*]=-\log Z_k\,\mathbb E_{p^*}\psi^*/\eta=0.
$$

其 coefficient 和 $A=-c$ 一般不归零，完整梯度却为零。Mean 最优残差也通常非零。BPO/Part 在逐前缀可表达且精确中心下可使残差归零，但神经网络投影误差、center 近似与有限 batch 破坏该充分条件。训练 surrogate 的标量值不能替代真实目标值。

$\mathcal K^S=KL(q\Vert p)$ 描述本轮离开 anchor 多少，起点为零。有效学习可以使它增长到非零稳定值；一直接近零还可能表示更新很弱。ESS 也只是漂移和权重诊断。收敛判定必须关注固定对象上的 objective、gradient、实际参数更新与 holdout。

### 归约实现合同

每个 rank/micro-batch 传 `count,sum,sum_sq,min,max`，SUM/MIN/MAX 跨 rank 正确合并后再求统计。跨 DP 的 SUM 若框架按 rank 平均，须用 rank 数恢复真实 count/sum；比值本身共同尺度消去。不能平均局部 mean、std、ESS 或分位数后称为全 token 统计。

全 batch 损失梯度使用固定分母 $M_k$：每 micro backward $L_m=M_k^{-1}\sum_{j\in m}\ell_j$，全部累积后一次 clip 与 optimizer step。DP 梯度平均时 rank 局部和乘 DP 规模。如此划分不变性来自梯度有限和的线性；每 micro 单独 clip 的非线性不能穿过求和。

新增联合 moment `sum_u_r` 可恢复 $r^{cur}=r-U$ 的方差：

$$
\operatorname{Var}(r-U)=\operatorname{Var}(r)+\operatorname{Var}(U)-2\operatorname{Cov}(r,U).
$$

需要尾部 p95/p99 时保存可合并草图或逐 token 采样，记录采样方案与近似误差；现有 mean/std 不能恢复任意分位数。统计置信区间至少按独立轨迹或题目聚类，不把 token count 当独立样本量。

## 数学评测、解码协议与多次生成

### 固定协议及完整性

规范的 `protocol_id` 固定 dataset hash、scorer 版本、template hash、response/context budget、do_sample、temperature、top-p、top-k、每题 R 和 seed 方案。checkpoint hash 属于每次评测事件的模型版本，保持同一 protocol_id，才能把不同 checkpoint 连成学习曲线；不能把模型更新本身误当协议变化。当前已实现的 math-eval ID 对解码、R 和长度预算做 hash，完整 dataset/scorer/template hash 合同仍待补齐。运行中改变任一生成协议参数，创建新 protocol 系列，禁止继续写同名 accuracy。

MD-OPD 已归档 21run 配置的评测为 R16、do_sample=true、temperature0.7、top-p0.9、budget31744；MirrorOPD 正式三 run 为 greedy、R1、budget7168。mean@16 不是 greedy 重复 16 次，历史成绩不能通过改字段名与本次成绩公平比较。21 份配置一致也不证明每检查点 570 题和 570R 份响应全部完成；完整性还需逐题记录。

验证每次评测 D 个唯一题目、每题恰好 R 个 response ID、总生成 D×R 份、无重复或缺失 UID、protocol 和 checkpoint 一致。aborted 输出与评分失败记为明确失败原因，并分别报告分母，不能静默删掉使准确率上涨。

### mean、pass、best 与 majority

令 $z_{ij}\in\{0,1\}$ 为题 i 第 j 次生成正确性，$C_i=\sum_jz_{ij}$。题目等权的随机解码单次成功率估计为

$$
mean@R=\frac1D\sum_{i=1}^D\frac{C_i}{R}.
$$

R 越大提供更多生成观测，目标仍是单次回答成功率。至少一次成功的成绩为

$$
pass@R=\frac1D\sum_i\mathbf1\{C_i>0\}.
$$

若总采样 R 次而估计 h 次机会，MD-OPD 实现组合估计器

$$
\widehat{pass@h}=\frac1D\sum_i\left(1-\frac{\binom{R-C_i}{h}}{\binom Rh}\right),\qquad 1\le h\le R.
$$

h=1 等于 mean@R，h=R 等于至少一次正确。独立同分布随机采样、固定协议和二元 correctness 是概率解释条件。MD-OPD 泛用工具对数值变量统计是否等于 1，规范层仅对二元正确标记输出 pass。

同题 R16 中 4 次正确，对 mean@16 贡献 0.25，对 pass@16 贡献 1。majority 先对答案规范化后投票再判分，不等于 mean；tie 策略与无法抽取答案的处理写入 protocol。best 连续 reward 取最大值，也不等于二元 correctness 的 pass；现有 bootstrap best/worst 统计另存 diagnostic。MD-OPD 的 best@h 用有放回 bootstrap，二元正确率条件下其期望为 $1-(1-C_i/R)^h$；组合 pass@h 则是不放回子集成功率。即使 h=R，也不能把 bootstrap best@R 当成 empirical pass@R。

### Greedy 重复与不确定性

重复 greedy 属于可复现性检验，理想确定性下重复响应完全相同。若多次输出不同，保存逐题 token ID hash、正确性翻转、replica/request seed、batch shape 与精度，记录 `repeat_greedy/output_disagreement_rate` 和 `score_disagreement_rate`。不得将浮点或调度不一致产生的 R 个 greedy 结果解释为独立采样能力 pass@R。

后续对照共享同一初始化评测文件，训练种子重复独立报告。算法 checkpoint 差异使用同题配对 bootstrap 或二元配对检验，bootstrap 按题抽样，不按同题的 R 条生成当 R 道独立题。当前历史没有逐题配对输出，只有聚合正确数，无法恢复 McNemar 检验或逐题翻转原因。

预算耗尽率、EOS finish rate、有效答案率、平均与分位 token、正确题和错误题分别长度共同展示。长度耗尽不证明加长预算必然答对；长预算重评必须独立 protocol，同一 checkpoint 才能区分推理能力改变与预算改变。

## 资源、精度与词表支持

资源 stage 统一为 initialization、rollout、anchor_scoring、teacher_scoring、actor_forward_backward、optimizer、weight_sync、evaluation、checkpoint、probe。计时来自单调时钟，异步 stage 的墙钟区间可重叠，不能强制相加等于 outer 总时间；并行 stage 另记 critical-path wall time 和累计 device time。

Mirror 历史 `timing_s/step` 不含初始化和 periodic evaluation，`timing_s/update_actor` 包含 N 次更新。单次 update 耗时若只有此总数，可报告每 outer 平均值，不能伪造每 inner 方差或每阶段精确占比。`perf/throughput` 必须注明分母是否每 GPU、是否包含 prompt，避免与全局 response token/s混名。

PyTorch allocated/reserved是actor进程allocator统计，NVML used 是 device 所有进程统计；分别展示且统一 byte，GiB=byte/$2^{30}$。allocator peak 未重置时是 run 至此高水位，不是本 outer 峰值。规范保存 `peak_window=since_start|stage_reset`、进程角色和 device UUID。GPU0–3 和同节点其他运行分开，不能把整机峰值归给单 run。

CPU offload 分别记录 RSS/PSS/USS、进程组与整机 RAM。四 rank RSS 相加会重复计共享页；进程组 PSS 与整机 used RAM 各有独立字段。显存优化需要同时看 actor activation、vLLM KV、cache 及 offload CPU 成本，单个 reserved 峰值不能说明整个 pipeline 内存效率。

角色精度元数据分别记录 parameter storage、forward/autocast、gradient reduce、buffer、optimizer state、log-prob normalization。actor FP32 参数与 BF16 前向可同时成立；冻结 teacher 的 reduce dtype 配置不代表执行梯度归约。

共同 action 支持保存 tokenizer hash、output head 列数、可采样 ID 支持、无效 ID 概率质量、HF 与 vLLM 归一化定义。当前已核实该模型 output 列 151936、有效 action 支持 151665。MD-OPD 当前代码完整 HF 分母与 vLLM 有效支持存在差异，影响大小需实际 probe。设支持内质量为 $Z_p=\sum_{a\in\mathcal V}p_{\mathcal W}(a)$，则

$$
\log t_{\mathcal V}(a)-\log p_{\mathcal V}(a)=\log t_{\mathcal W}(a)-\log p_{\mathcal W}(a)+\log Z_p-\log Z_t.
$$

增加 Top-J 不能修复该归一化差异。规范记录 `support/actor/invalid_action_mass`、teacher 对应量、共同支持版本以及 rollout/HF action logprob discrepancy。

## 历史迁移、维护与验证

### 来源映射与可恢复性

每个规范字段附 `source_keys,source_schema,derivation,estimator,aggregation,measurement,status`。exact、derived、approximate、unrecoverable 四个恢复级别与 implemented/legacy/proposed 实现状态分别记录；“可以从历史恢复”不等于“生产已部署”。

1. Mirror `sampled_log_ratio`、ratio 与 global token moment 可 exact 映射；`token_advantage`改成 c，A 按符号规则 derived。MD-OPD `opd/adv_*`映射当前 teacher reward 统计，不改成实际优化 advantage。
2. teacher_center 按方法拆成 anchor_teacher 或 student_teacher。student_center 固定方向 anchor_student。旧 outer 平均移至 inner_aggregate，禁止当 snapshot。
3. $r^{cur}=r-U$ 的 mean 可由同 batch 两者 meanderived，std/RMS 缺协方差时 unrecoverable；支持重叠均值不能非线性转换全局 Jaccard。
4. 原 global token count 可以恢复训练生成 token 累计；actor_update_tokens 需要每次实际消费 token 计数，固定 mini 方案可 derived 并注明假设。时间按 stage 来源定义，缺 end-to-end 计时不造精确总秒。
5. full-vocabulary KL、full logZ、完整 teacher Top-J、末 inner post ESS、逐题配对与分位数缺原数据时 unrecoverable，从新 run 开始采集。
6. 在线受污染字段保留 raw，只在新 dataset/artifact/run 中输出规范重建；不覆盖旧 W&B history，也不让两个 event 共用新 series。

### 版本维护规则

schema 语义版本使用 major.minor.patch。公式、方向、聚合、measurement 或 units 改变属于 major；新增字段/事件属于 minor；不改变数值含义的文档和别名纠错属于 patch。run 固定 schema 版本，不能在同一 series 中升级语义而不换名字。

每个字段在机器可读 registry 中保存定义、公式、来源代码与 hash、测试、owner 和状态；本文是读者入口，registry 是适配层依据。新增算法先填写目标与梯度表，再选日志，不能从框架现成 field name 反推算法公式。新实验文档引用具体 schema 和 protocol 版本。

snapshot manifest 记录文件 SHA、W&B run ID、导出方式与导出时间。维护图像脚本时保存输入 hash、筛选规则、原始数值 CSV 和图生成版本。完成度按 snapshot 判断，running BPO 早期数据不与 finished OPD/MDPO写成三个最终checkpoint。

- 枚举小词表验证六算法总体梯度、符号、baseline 以及 BPO/Mean/Part 残差；MDPO 检查删去零均值项的期望等价与有限样本差别。

## 当前实现变更与部署边界

本次第一方代码已增加三对原生 Top-J 比较：`mirror/overlap_{student_teacher,student_anchor,anchor_teacher}_{intersection_count,union_count,intersection_fraction,jaccard}/{mean,std,rms,min,max}`。teacher 的原生 Top-J IDs 在 outer 起点冻结缓存，student 的原生集合每次 inner 重算。旧 `support_overlap` 保留 student-anchor 含义。详见 [实现说明](2026-10-12-TopJ支持重叠诊断.md)。旧记录缺原生 teacher IDs，不能重造 teacher 两对曲线。J=0 时原生比例字段的 0 是关闭诊断的工程约定，规范展示应标明 disabled，不能当作不重叠。

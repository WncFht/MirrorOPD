# TA-OPD 与 OPD 审查

## 身份与范围

本审查固定 TA-OPD 仓库 `ml-stat-Sustech/TA-OPD` 于 commit `62669afb5101bfdf57dc5ddf81e78f000c5ce2fc`，OPD 仓库 `thunlp/OPD` 于 commit `ac26e38d6f1572eb027597b48a9f4e01f6915ef8`。代码副本位于 `~/.cache/mirroropd-review/TA-OPD` 与 `~/.cache/mirroropd-review/OPD`，没有修改现有 upstream checkout。TA-OPD 论文是 Huang 与 Wei 的 “Tail-Aware Top-k On-Policy Distillation”，arXiv:2608.14728[^ta-paper]；OPD 论文是 “Rethinking On-Policy Distillation of Large Language Models: Phenomenology, Mechanism, and Recipe”，arXiv:2604.13016[^opd-paper]。对照基准是 MirrorOPD 书稿中的 scalar/vector KL、residual 与 autodiff 章节。

## 数学对象

设当前学生分布为 $p$，教师分布为 $q$，教师 top-$k$ 支持为 $S$，$P=p(S)$、$Q=q(S)$，尾部条件分布为 $	ilde p,	ilde q$。四个对象必须分开维护：截断头部 $H=\sum_{S}p\log(p/q)$；TA-OPD $H+(1-P)\log((1-P)/(1-Q))$；normalized top-k 是 $\mathrm{KL}(p(\cdot\mid S)\Vert q(\cdot\mid S))$；full reverse KL 是 $H+(1-P)\log((1-P)/(1-Q))+(1-P)\mathrm{KL}(\tilde p\Vert\tilde q)$。因此 TA 是 full KL 的下界，缺失项恰是尾形状 KL；normalized 改变了目标，不能作为 TA 的数值近似。

TA 仓库的 `compute_taopd_with_sg`（`verl/trainer/distillation/fsdp/losses.py:506-584`）把 top-k 与聚合尾部拼成 $S\cup\{tail\}$，并 detach 整个 log-ratio，得到 $\sum p_i\operatorname{sg}(\log p_i/q_i)$ 的梯度。`compute_taopd_reverse_kl_topk`（同文件 `588-701`）不 detach，得到真实 TA 数值和真实 TA 梯度。`compute_mopd_reverse_kl_topk`（`165-240`）实现的是 $H+Q-P=\sum_{S}[p\log(p/q)-p+q]$，即头部正测度的 I-divergence；它非负，但不是完整分布的 reverse KL 或 TA，命名不能与 MirrorOPD 的 MOPD residual 混用。[^ta-kernel]

## 方法矩阵

| 方法                    | 支持集与采样测度                                    | value                                     | backward/停止梯度                                                                                 | 假设与风险                                                |
| ----------------------- | --------------------------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| normalized top-k        | 教师 $S$，无 token 采样                             | 条件 reverse KL                           | 对 $S$ 内归一化分布求梯度，$S^c$ 梯度为零                                                         | 目标已变为条件分布；mass mismatch 永远不可见              |
| truncated/reverse top-k | 教师 $S$，无采样                                    | $H$，可为负                               | 直接 autodiff；尾部无项                                                                           | 不是 divergence；缺失 tail mass 与 shape                  |
| TA-OPD                  | 教师 $S$ 加单一 tail                                | $H+$tail-mass KL                          | 直接 autodiff 或 stopped-ratio 版本                                                               | 只假设 tail 被聚合；仍忽略 tail shape                     |
| sample-corrected TA     | 教师 $S$ 加 tail，额外从当前 $p$ 采样一个响应 token | TA 加 $S^c$ 的条件 log-ratio 修正         | correction ratio stop-grad；on-policy 用 $p/\operatorname{sg}(p)$，复用 batch 用 $p/p_b$，不 clip | 采样必须覆盖 $p$ 的尾部；off-policy 必须缓存行为 log-prob |
| MOPD-topk（TA 仓库）    | 教师 $S$                                            | $H+Q-P$                                   | 直接 autodiff                                                                                     | 头部正测度 I-divergence；不可宣称完整 reverse KL          |
| EMA/PG residual         | rollout token 测度（通常 $p_b$）                    | 头部控制量加 importance-weighted residual | residual 的 score 项需 stop-grad ratio，模型 log-prob 保留梯度                                    | 需要行为分布、support coverage、EMA 时序与方差控制        |

## 真实调用与后端分歧

TA 的 FSDP/VeOmni dispatch 在 `trainer/distillation/losses.py:149-176` 按 loss mode 选择 reverse、TA、normalized、MOPD 和 sample-corrected 内核。但同一函数的 Megatron 分支 `178-183` 无条件选择 `megatron_losses.compute_forward_kl_topk`；因此在 Megatron 下配置 `taopd_reverse_kl_topk`、`normalized_reverse_kl_topk` 或 `sample_corrected_ta_opd` 并不会得到所选目标，实际执行 teacher-weighted forward KL。这是阻断统一接口的硬错误，必须在抽象层把 loss identity 与 backend kernel 绑定并做 dispatch assertion。[^ta-dispatch]

sample-corrected 的 producer 是 FSDP logits processor，consumer 是 `compute_sample_corrected_ta_opd_loss`（`trainer/distillation/losses.py:486-574`）。direct-loss 模式强制读取 `data['old_log_probs']`（`519-523`），表示 rollout 行为分布必须随 batch 保存；policy-gradient 模式将行为 log-prob 设为 `None`（`510-518`），意图让 PPO 外层承担 ratio，但随后 `526` 无条件执行 `behavior_logp_y.detach()`。因此 policy-gradient 配置会在进入内核前对 `None` 解引用；这不是数学差异而是不可达路径。

OPD 的 producer-consumer 在 `verl/workers/actor/dp_actor.py:451-624`：producer 先计算学生 top-k、教师在学生 support 上的 log-prob；`only_tch` 再按教师 ID gather 学生 log-prob；`union` 拼接两套 ID 并以 `teacher_in_student_mask` 去重；`union-intersection` 使用对称差且关闭归一化权重。consumer 在 `update_policy`（同文件 `732` 起）把 producer 保存的 `student_top_k_ids` 或 `union_top_k_ids` 传回 forward，修复了重新 top-k 导致的 apples-to-oranges 错配。统一设计必须把“support IDs、对应当前/行为 log-prob、mask、proposal measure”作为同一 immutable token-support record 传递，不能只传 K 个数值张量。[^opd-actor]

OPD 的 student_p reward 在 producer 的 `no_grad` 路径下先按 support 归一化，再将 $-w_i\log(p_i/q_i)$ 交给外层 PPO；训练时不对 $w_i$ 求导。因此它是冻结支持、冻结权重的 score surrogate，不能仅因权重来自学生概率就称为 normalized conditional-KL 的 direct autodiff。只有额外满足精确居中、正确 ratio 与固定 sampling measure 的条件，两种总体梯度才有可证明的关系。union-intersection 关闭归一化，还额外改变了质量尺度。

## 内存、并行与数值

TA/SC-TA 的通信缓存为每个有效 token 的 $k$ 个教师 ID/log-prob，加 sampled teacher log-prob 和行为 sampled log-prob；学生端仍需要 full-vocabulary logsumexp，不能把 top-k cache 的 $O(Nk)$ 大小误写成整个 student forward 的复杂度。normalized 当前实现先建立 full student log_softmax，TA 采用 logsumexp 后 gather，仅 upcast $k$ 列，这减少了 float32 全词表概率张量，但 full logits 与 model output head 仍在。

`log1mexp`（FSDP `496-503`）使用 expm1/log1p 双分支避免尾质量直接做 $1-P$ 的 cancellation；代码同时将 log mass clamp 到 `-1e-6`。它把真实尾质量小于约 $10^{-6}$ 的位置替换成 floor，且 clamp 区域的 tail derivative 为零；因此严格 exact-value/exact-gradient 断言应限定在 floor 未激活区域。`torch.logsumexp(student_logits).float()` 是归约后 upcast，不是归约前提升 dtype；低精度 logits 的归约舍入仍需测试。

Ulysses 路径对 teacher ID/log-prob 按 sequence 分片，FSDP 学生端拥有完整词表；Megatron 使用词表并行 forward-KL custom autograd，其 scatter-add 与 teacher-weighted gradient 不能原样用于 TA reverse-KL。统一 backend contract 必须分开支持 sequence-sharded 和 vocab-sharded log-normalizer/gather/backward，并以同一微型词表枚举校验。OPD union 最多保存 $2k$ 候选，并再做学生在教师 support 的 forward；去重 mask 有效但不会缩短固定张量，内存预算应按 $2k$ 而非去重后的实际集合大小计算。

OPD 默认是 student top-k、$k=16$、`student_p` 权重；论文报告 top-k 大于 4 的收益有限，且重叠率与长序列 suffix 漂移显著影响 reward。该经验不能替代 TA 的教师 support 保证：student-only support 对教师尾部没有 coverage，teacher-only support 对学生高概率尾部没有 coverage，union 只是显式扩大支持，仍不自动成为全词表 KL。

## 数值证据

使用 TA FSDP 的真实函数 AST 提取，在 archbox 的 CPU PyTorch 环境枚举 $p=(.50,.25,.15,.10)$、$q=(.40,.30,.20,.10)$、$S=\{0,1\}$。结果如下：full reverse KL 值 `0.0228390756`，梯度 `[0.100152238,-0.051290159,-0.046578173,-0.002283908]`；TA 值 `0.0204110146`，梯度 `[0.101366274,-0.050683144,-0.030409878,-0.020273252]`；normalized 值 `0.0189956501`，梯度 `[0.090103378,-0.090103378,0,0]`；truncated 值 `0.0659914017`，梯度 `[0.203576088,0.000421762,-0.122398711,-0.081599141]`；MOPD-topk 值 `0.0159913301`，梯度 `[0.078576088,-0.062078238,-0.009898710,-0.006599140]`。四个 sampled correction 条件值按 $p$ 加权为 `0.0228390932`，期望梯度 `[0.100152242,-0.051290156,-0.046578172,-0.002283909]`，与 full KL 误差约 $2\times10^{-8}$。这验证了 sample-corrected 的 value+gradient 无偏条件，也直接证明 normalized、TA、MOPD-topk 不能互换。

## 统一抽象边界

统一层应只提供三类数学原语：`SupportRecord`（固定 token IDs、teacher/student/behavior log-prob、质量 mask 与 tail mass）；`DivergenceValue`（full、truncated、TA、conditional、linear-tail 的 forward definition）；`GradientEstimator`（direct autodiff、stopped ratio、score/residual、importance proposal、clip policy）。每个 estimator 显式声明 `measure`（$p$、behavior $p_b$ 或 teacher $q$）、`support`（teacher/student/union/full）、`normalization`、`stop_gradient`、`behavior_cache_required` 和 `unbiased_target`。

不能合并的边界有三条。第一，normalized 与 unnormalized/TA 的 target 不同，前者 zeroes outside-support gradient；第二，MOPD-topk 的 $Q-P$ 线性尾项与 MOPD residual 的逐动作平方残差不是同一目标；第三，sample correction 与 PPO policy-gradient ratio 只能由一个 owner 施加，重复 ratio 会改变估计量。任何 backend 若不能保留相同 SupportRecord 和 stop-gradient contract，应报告为不可达或近似实现，而不是复用名称。

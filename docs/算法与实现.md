# 算法与实现

本参考描述当前 API 2 的 `on_policy`、`mdpo`、`bpo`，对应 [配置](../src/mirroropd/core/config.py)、[信号](../src/mirroropd/core/signal.py)、[缓存](../src/mirroropd/core/cache.py)及[目标](../src/mirroropd/core/objectives.py)。旧实验中的 PMD-Mean、PMD-Part 和无穷 η 不属于当前生产接口。完整理论来源仍待用户审定，见 [theory](../theory/README.md)。

## 冻结对象与采样测度

在外层窗口 $k$，$q=\pi_k(\cdot\mid s)$ 为冻结锚点，$T(\cdot\mid s)$ 为冻结教师，$p=\pi_\theta(\cdot\mid s)$ 为当前学生。前缀 $s$ 来自当轮 rollout，采样动作 $a\sim q$；同一窗口内前缀、动作、锚点和教师缓存不变。内层只重算当前学生。这里的完整动作积分仍条件于已采样的前缀，不枚举全部可能的历史。

模型共享 token-to-ID、特殊 token 及前缀编码语义；[输入预检](../src/mirroropd/runtime/preflight.py)检查合法词表和共同模板。[布局适配](../src/mirroropd/integrations/verl/adapter.py)对齐 response action 与其前驱预测位置，包含预算末尾的 action；padding 在概率运算前排除。

## 共同幂均值信号

定义教师相对锚点的对数比 $r=\log(T/q)$。实际信号为

$$
A_{\kappa,\eta}(r)=
\begin{cases}
r,&\kappa=0\text{ 或 }\eta=1,\\
\dfrac{\log(1-\eta+\eta e^{\kappa r})}{\kappa\eta},&\kappa>0,\ 0<\eta<1.
\end{cases}
$$

当前要求 $0\le\kappa\le1$、$0<\eta\le1$ 且有限。η 控制目标，与 AdamW 学习率分别配置。默认 κ=0.5、η=0.2；此时 $\eta A=2\log(0.8+0.2\sqrt{T/q})$。实现对小对数比使用 `log1p`/`expm1`，其余使用 `logaddexp`；概率计算至少 FP32，FP64 输入保持 FP64。

令冻结 reward 中心和当前学生中心为

$$
C_T=-\mathbb E_q[A_{\kappa,\eta}(\log(T/q))],\qquad
K_p=\operatorname{KL}(q\Vert p),\qquad
u=\log(p/q).
$$

$C_T$ 一般不等于普通教师 KL。只有 $A(r)=r$ 且使用相同求和测度时，才有 $C_T=\operatorname{KL}(q\Vert T)$。估计器对这两个中心的近似方式见下一节。

## 中心估计与动作积分

`objective.estimator.center` 和 `integration` 是两个选择：

| 选择                  | 缓存与运算                                          | 条件                                         |
| --------------------- | --------------------------------------------------- | -------------------------------------------- |
| `center=topj_tail`    | 在冻结锚点 Top-J 上逐项求和，补集聚合为一个 tail 类 | `topj` 为非负整数，不能超过合法词表          |
| `center=full`         | 对合法完整词表计算冻结中心及学生中心                | 缓存完整锚点 log-prob，成本随前缀数×词表增长 |
| `integration=sampled` | 复用 rollout action，使用停止梯度 score surrogate   | 支持两种中心                                 |
| `integration=full`    | 每个已采样前缀枚举完整 action 分布                  | 要求 `center=full`                           |

设 $S=\operatorname{TopJ}(q)$，$R=S^c$，$q_R=\sum_Rq$。Top-J＋tail 的冻结中心为

$$
\widehat C_T=-\sum_{a\in S}q_aA(\log(T_a/q_a))-q_RA(\log(T_R/q_R)).
$$

学生中心为

$$
\widehat K_p=\sum_{a\in S}q_a\log(q_a/p_a)+q_R\log(q_R/p_R).
$$

空 tail 的贡献跳过。该学生中心是分区 KL，满足完整 KL 的下界；对非线性 reward 的冻结中心需按其自身定义分析，不能套用普通 KL 的解释。选定支持集的质量和三个分布各自 Top-J 的 Jaccard 是不同诊断，见[日志与评测](日志与评测.md)。

## Sampled score 更新

对记录动作，三算法的梯度下降系数为

$$
\begin{aligned}
c_{\mathrm{on\_policy}}&=-A-C_T,\\
c_{\mathrm{bpo}}&=(\nu+K_p)/\eta-A-C_T,\\
c_{\mathrm{mdpo}}&=e^\nu(\nu/\eta-A).
\end{aligned}
$$

`topj_tail` 配置使用对应的近似中心。MDPO 系数不使用这两个中心；其 sampled action 概率仍以完整合法词表归一化。日志中的 Top-J 不能解释为只使用 Top-J 动作训练。

实际返回的逐 token 标量为

$$
\ell_i=\operatorname{stopgrad}(c_i)\log p_\theta(a_i\mid s_i).
$$

整个系数停止梯度，并在每次内层前向重新计算。其前向数值是构造梯度的 surrogate，不等于下述条件目标。重要性比率不裁剪；非有限 loss 或系数会抛出错误。

`on_policy` 在每个 fresh rollout batch 只执行一次完整更新；运行配置强制 `inner_steps=1`。MDPO/BPO 允许同一冻结窗口多次更新，但预设 inner 数不能证明已收敛。

## 完整条件目标

完整中心、完整动作积分下，先定义归一化目标

$$
z=\sum_aq_a\exp(\eta A_a),\qquad
h_a=\frac{q_a\exp(\eta A_a)}{z}.
$$

MDPO 返回 $\operatorname{KL}(p\Vert h)/\eta$；BPO 返回中心化对数残差的二次目标：

$$
Q_{\mathrm{BPO}}(p)=\frac1{2\eta}\sum_aq_a\left[\log(p_a/h_a)-\sum_vq_v\log(p_v/h_v)\right]^2.
$$

它们的 `loss_kind` 为 `conditional_objective`。完整积分的 on-policy 仍枚举冻结 score surrogate，`loss_kind=score_surrogate`，没有因此变成可直接比较的条件 KL。

## 缓存、归约与核验

缓存绑定 schema、锚点版本、教师/tokenizer 身份、词表、温度、signal 和 estimator。所有缓存张量无梯度；上下文或版本不匹配应拒绝。换锚点后重新生成缓存，不能只改版本号。

每次 optimizer 更新按全局有效 response token 等权。micro-batch 累积应按实际 token 数加权，而非等权平均各 micro-batch 均值；多卡需与框架的梯度归约配合。优化记录标为 `pre_update`，统计离散程度不等于估计器方差或梯度标准误。

独立数学目标及梯度对照见 [core 测试](../tests/core)、[reference 测试](../tests/reference)和[适配测试](../tests/integrations)。CPU 恒等式、真实 GPU 集成与正式任务效果分别报告；当前证据见[实现验证](experiments/2026-10-15-幂均值镜像蒸馏实现与估计器对照.md)和[版本说明](2026-10-15-MirrorOPD全面重构说明.md)。

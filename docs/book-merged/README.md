# MirrorOPD 新旧书稿单文件合并版

[单文件 LaTeX](2026-10-14-MirrorOPD新旧书稿单文件合并版.tex) 与 [PDF](2026-10-14-MirrorOPD新旧书稿单文件合并版.pdf) 是统一合并正文。全部内容直接写入一个 `.tex`，没有章节级 `\input` 或 `\include`。九章标题保留，便于目录导航；没有新旧两个版本或重复历史附录。

以当前书稿为基础，旧稿已迁移的定义、定理、证明、算法和数值表只保留修订后的版本。旧版修订核验中特有的二动作 Mean 数值例子补入投影章，原论文标签对应关系补在乘子换算处，48 组随机问题配置补入实验证据章。旧稿的重复证明统一引用已有证明，已被修正的结论不再收录。原有两套书稿不变。

这份文件用于集中阅读与编辑，原有当前主稿和历史归档不变。单文件交付按用户要求超过通常的 1000 行限制。样式仍使用 `../book/elegantbook.cls`，图片仍使用 `../../results/`；它是正文单文件，不是包含样式与图片的独立发行包。

在仓库根目录运行以下命令可重新生成和编译。重新生成会覆盖合并文件中的手工编辑，编辑前应保存已有修改。

```bash
python3 scripts/export-merged-book.py
cd docs/book-merged
latexmk -xelatex -interaction=nonstopmode -halt-on-error 2026-10-14-MirrorOPD新旧书稿单文件合并版.tex
```

生成程序递归展开当前主稿，将审阅后的旧稿独有内容插入对应位置，并检查重复标签、缺失引用及残留装配命令。源位置注释保留，便于定位原始维护文件。
